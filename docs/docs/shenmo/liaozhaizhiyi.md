# 聊斋志异

## 作品简介

清代文学家蒲松龄创作的文言短篇小说集，全书共491篇。作品通过花妖狐魅和人的恋爱，揭露了封建统治的黑暗，抨击了科举制度的腐朽，反抗了封建礼教的束缚，具有丰富深刻的思想内容。

## 作者介绍

蒲松龄（1640年—1715年），字留仙，一字剑臣，别号柳泉居士，世称聊斋先生，山东淄川（今山东淄博）人。清代杰出文学家，优秀短篇小说家。他出身于一个逐渐败落的中小地主兼商人家庭，19岁应童子试，接连考取县、府、道三个第一，名震一时。以后屡试不第，直至71岁时才成岁贡生。为生活所迫，他除了应同邑人宝应县知县孙蕙之请，为其做幕宾数年外，主要是在本县西铺村毕际友家做塾师，舌耕笔耘，近42年，直至61岁时方撤帐归家。蒲松龄一生热衷科举，却始终不得志，因此对科举制度的不合理深有体验。他毕生精力完成《聊斋志异》8卷、491篇，约40余万字。内容丰富多彩，故事多采自民间传说和野史轶闻，将花妖狐魅和幽冥世界的事物人格化、社会化，充分表达了作者的爱憎感情和美好理想。

## 文学价值

《聊斋志异》是中国古典文言短篇小说的巅峰之作。作品继承和发展了魏晋志怪小说和唐宋传奇的传统，艺术成就很高。鲁迅在《中国小说史略》中评价其"用传奇法，而以志怪"，准确地概括了这部作品在小说史上的独特地位。郭沫若曾题联赞誉："写鬼写妖高人一等，刺贪刺虐入骨三分"。

作品的艺术特色主要体现在：一是塑造了一系列栩栩如生的花妖狐魅形象，她们美丽、善良、多情，具有鲜明的人性；二是情节曲折离奇，引人入胜；三是语言精炼生动，既有文言的典雅，又有口语的活泼；四是善于运用梦境、幻境等手法，营造浪漫主义的氛围。

## 经典人物

- **聂小倩**：美貌女鬼，被夜叉胁迫害人，后遇宁采臣，被其正直感动，最终脱离魔掌，与宁采臣结为夫妻。是《聊斋》中最著名的女性形象之一。
- **宁采臣**：浙江人，为人慷爽正直，不为财色所动。在金华寺中遇到聂小倩，帮助她脱离苦海，最终与小倩结为夫妻。
- **婴宁**：狐女，天真烂漫，爱笑，性格纯真自然。与王子服相爱，最终成为他的妻子。其形象体现了作者对自然人性的赞美。
- **席方平**：为父报仇的孝子，入地府告状，历经磨难，最终昭雪冤屈。故事深刻揭露了封建官府的黑暗腐败。
- **促织**：成名之子，因父亲被迫交纳促织而投井自尽，魂化促织，帮助父亲渡过难关。故事反映了封建统治对百姓的残酷压迫。
- **崂山道士**：王生慕道求仙，到崂山学道，因吃不了苦而半途而废，最终碰壁而归。故事讽刺了那些好逸恶劳、投机取巧之人。

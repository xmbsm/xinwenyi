# 老残游记

## 作品简介

清末文学家刘鹗创作的中篇小说，全书20回。小说以一位走方郎中老残的游历为主线，通过对老残在游历途中的所见所闻，揭露了清政府的腐败黑暗，反映了晚清社会的种种弊端。

## 作者介绍

刘鹗（1857年—1909年），字铁云，别署洪都百炼生，江苏丹徒（今镇江）人，清末小说家、诗人、收藏家。他出身于官宦世家，但本人科举不顺，曾从事过行医、经商、治河等多种职业。刘鹗博学多才，对数学、医学、水利、金石等都有研究。他积极参与洋务运动，曾参与治理黄河，后因被指控私售仓粟而流放新疆，病逝于迪化（今乌鲁木齐）。除《老残游记》外，他还著有《铁云藏龟》等学术著作，是甲骨文研究的先驱之一。

## 文学价值

《老残游记》是晚清四大谴责小说之一，与《官场现形记》《二十年目睹之怪现状》《孽海花》齐名。小说的独特之处在于以游记形式写社会批判，通过主人公老残的游历足迹，展现了晚清社会的各个侧面，开创了小说创作的新形式。

作品的艺术成就很高，尤其以描写自然风光和音乐著称。第二回中对大明湖、千佛山的描写，以及王小玉说书的描写，都是中国古典小说中的经典段落。小说的语言清新流畅，叙事从容不迫，在晚清小说中别具一格。

作品的思想内容深刻，不仅揭露了贪官污吏的残暴，还批判了清官的刚愎自用，指出"清官"有时比贪官更能危害百姓。这种见解在当时是非常独到和深刻的。

## 经典人物

- **老残（铁英）**：小说主人公，号补残，走方郎中。他以行医为业，游历四方，目睹了晚清社会的种种黑暗，以冷静客观的视角观察和评论社会现实。他是作者的化身，也是小说的叙述者。
- **玙姑**：泰山桃花山的隐士之女，聪慧美丽，精通音律，与老残讨论音乐之道，是小说中理想女性的代表。
- **黄龙子**：泰山隐士，玙姑的伴侣，学识渊博，对时局有独到见解。他与老残的讨论揭示了作者对社会改革的思考。
- **申子平**：山东巡抚衙门幕僚，因黄河决口之事到桃花山求助，引出了老残与黄龙子、玙姑的会面。

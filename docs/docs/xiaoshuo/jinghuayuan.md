# 镜花缘

## 作品简介

清代文人李汝珍创作的长篇小说，全书100回。前半部分描写了唐敖、多九公等人乘船在海外游历的故事，后半部分写了武则天科举选才女，由百花仙子托生的唐小山及其他各花仙子托生的一百位才女考中，并在朝中有所作为的故事。

## 作者介绍

李汝珍（约1763年—1830年），字松石，号松石道人，直隶大兴（今属北京）人，清代小说家。他博学多才，精通音韵学，著有《李氏音鉴》等学术著作。李汝珍早年有过仕途经历，但后半生主要从事文学创作和学术研究。《镜花缘》是他历时十余年创作的长篇小说，集中体现了他的文学才华和思想见解。

## 文学价值

《镜花缘》是一部融幻想、讽刺、游记、才学于一体的长篇小说，具有浓厚的浪漫主义色彩。小说前半部分以唐敖等人海外游历为主线，描绘了君子国、大人国、女儿国、两面国等数十个海外奇国，借这些奇异国度讽喻现实社会的种种弊端，寄托了作者对理想社会的向往。

后半部分以武则天开女科为背景，描写了一百位才女的才华和风采，体现了作者对妇女才能的肯定和尊重，具有进步的女性观。小说还涉及音韵、医卜、星相等学问，展现了作者渊博的学识。

作品的艺术特色在于：想象丰富奇特，构思新颖巧妙；讽刺手法多样，寓庄于谐；人物形象鲜明，尤其是众多才女形象各具特色。

## 经典人物

- **唐敖**：小说主人公之一，才学出众，因科举受挫而随妻兄林之洋出海游历。在海外见识了各种奇风异俗，最终在小蓬莱成仙。他是连接小说前后两部分的关键人物。
- **林之洋**：唐敖的妻兄，商人，性格豪爽幽默，与唐敖、多九公一起出海游历。他的形象为小说增添了许多喜剧色彩。
- **多九公**：年约八旬的老者，博学多闻，见多识广，随唐敖等人一起出海，是游历过程中的向导和解说者。
- **唐小山（百花仙子）**：百花仙子转世，唐敖之女。才貌双全，为寻父亲而海外寻父，后改名唐闺臣，参加女科考试，中第一名才女。
- **阴若花**：女儿国国王，原是牡丹花仙子转世。在女儿国经历中展现了非凡的智慧和勇气。

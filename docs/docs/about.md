# 关于

## 站点介绍

新文艺是一个专注于古典文学的垂直类内容展示与阅读平台。我们致力于免费开放古典文学优质内容，通过结构化分类、便捷检索功能，降低用户阅读和查找经典作品的门槛，助力传统文化普及。

## 核心价值

- **免费开放**：所有内容完全免费，无需注册登录即可浏览全部内容
- **内容全面**：涵盖四大名著、经典诗词、明清小说、神魔志怪、公案侠义等多个品类
- **阅读体验**：简洁优雅的界面设计，专注阅读本身，支持响应式布局
- **传统文化**：助力传统文化普及，降低经典作品阅读门槛

## 内容分类

本站古典文学作品按照以下分类进行组织：

### 四大名著
《红楼梦》《三国演义》《水浒传》《西游记》，中国古典文学巅峰之作。

### 著名诗词
唐诗、宋词、元曲等经典诗词作品，按朝代和作者分类展示。

### 明清小说
晚清谴责小说、历史演义小说、白话短篇小说集等。

### 神魔志怪
《封神演义》《聊斋志异》等神魔志怪类作品。

### 公案侠义
《包公案》《施公案》等公案侠义类小说。

## 技术架构

本站采用纯前端静态架构，使用 VitePress 构建，无需后端服务与数据库，所有内容静态渲染。部署至静态托管平台，依托 CDN 加速，提升全球访问速度与稳定性。

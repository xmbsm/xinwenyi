# 绿衣

**[先秦] 佚名**

## 原文

绿兮衣兮，绿衣黄里。心之忧矣，曷维其已！

绿兮衣兮，绿衣黄裳。心之忧矣，曷维其亡！

绿兮丝兮，女所治兮。我思古人，俾无訧兮！

絺兮绤兮，凄其以风。我思古人，实获我心！

## 注释

- 绿衣：绿色的衣服
- 黄里：黄色的衬里
- 曷维其已：何时才能停止
- 亡：同"忘"，忘记
- 丝：丝织品
- 女：同"汝"，你
- 治：纺织
- 古人：故人，指亡妻
- 俾：使
- 訧：过失
- 絺：细葛布
- 绤：粗葛布
- 凄：凉爽，寒冷
- 实获我心：实在深得我心

## 译文

绿色的衣服啊，绿面黄里。心中的忧愁啊，何时才能停止！

绿色的衣服啊，绿衣黄裳。心中的忧愁啊，何时才能忘记！

绿色的丝啊，是你所纺织。我思念故人，她使我无有过失！

细葛布和粗葛布啊，穿上感到风凉。我思念故人，她实在深得我心！

## 赏析

《绿衣》是《诗经·邶风》中的一首，是一首悼念亡妻的诗歌，是中国文学史上最早的悼亡诗之一。

全诗四章，以亡妻留下的绿衣起兴，睹物思人，表达对亡妻的深切思念。第一章"绿兮衣兮，绿衣黄里"，写绿衣的颜色，绿面黄里，色彩鲜明。"心之忧矣，曷维其已"，看到亡妻的遗物，忧愁无法停止。

第二章"绿衣黄裳"，写绿衣配黄裳，是亡妻生前的穿着。"曷维其亡"，思念之情无法忘怀。

第三章"绿兮丝兮，女所治兮"，写这绿衣的丝是亡妻亲手纺织的。"我思古人，俾无訧兮"，思念亡妻，她生前使自己无有过失。

第四章"絺兮绤兮，凄其以风"，写穿上亡妻留下的葛布衣服，感到风凉。"我思古人，实获我心"，亡妻最了解自己，最能体贴自己的心意。

全诗以衣物为线索，层层深入地表达对亡妻的思念。从颜色到质地，从外表到内涵，思念之情越来越深。这种睹物思人的写法，对后世悼亡诗产生了深远影响。

# 无衣

**[先秦] 佚名**

## 原文

岂曰无衣？与子同袍。王于兴师，修我戈矛。与子同仇！

岂曰无衣？与子同泽。王于兴师，修我矛戟。与子偕作！

岂曰无衣？与子同裳。王于兴师，修我甲兵。与子偕行！

## 注释

- 岂曰：难道说
- 同袍：同穿一件战袍
- 王：周天子
- 兴师：起兵
- 修：修整
- 戈矛：古代兵器
- 同仇：共同的敌人
- 泽：内衣
- 偕作：一起行动
- 裳：下衣，战裙
- 甲兵：铠甲和兵器
- 偕行：一起出征

## 译文

难道说没有衣裳？与你同穿一件战袍。君王要起兵打仗，修整我的戈和矛，与你共同对敌！

难道说没有衣裳？与你同穿一件内衣。君王要起兵打仗，修整我的矛和戟，与你一起行动！

难道说没有衣裳？与你同穿一件战裙。君王要起兵打仗，修整我的铠甲和兵器，与你一起出征！

## 赏析

《无衣》是《诗经·秦风》中的一首，是一首表现秦国军民团结友爱、同仇敌忾的战歌。

全诗三章，采用重章叠句的形式，层层递进地表达了战士们慷慨从军、共赴国难的决心。每章都以"岂曰无衣"的反问起笔，以"与子同袍""与子同泽""与子同裳"表达战友之间亲如兄弟的情谊。

"王于兴师，修我戈矛"，点明出征的原因，表现出战士们积极响应号召的爱国热情。"与子同仇""与子偕作""与子偕行"，从共同的敌人到共同的行动，再到共同出征，层层深入，展现了战士们高昂的斗志和坚定的信念。

全诗语言质朴有力，节奏明快，充满了雄壮激昂的气势，是《诗经》中表现爱国主义精神的代表作。后世常用"同袍""同泽"来比喻战友之间的深厚情谊。

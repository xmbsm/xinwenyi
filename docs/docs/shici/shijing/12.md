# 击鼓

**[先秦] 佚名**

## 原文

击鼓其镗，踊跃用兵。土国城漕，我独南行。

从孙子仲，平陈与宋。不我以归，忧心有忡。

爰居爰处？爰丧其马？于以求之？于林之下。

死生契阔，与子成说。执子之手，与子偕老。

于嗟阔兮，不我活兮。于嗟洵兮，不我信兮。

## 注释

- 镗：击鼓声
- 踊跃：跳跃，形容士气高昂
- 土国：在国内修筑城墙
- 城漕：在漕邑筑城
- 孙子仲：人名，此次出征的统帅
- 平：调和，平息
- 不我以归：不让我回去
- 有忡：忧愁不安的样子
- 爰：在哪里
- 契阔：聚散离合
- 成说：立下誓言
- 偕老：一起到老
- 于嗟：感叹词
- 洵：远
- 信：守信

## 译文

战鼓擂得咚咚响，士兵们跳跃着准备出征。别人在国内修筑城墙，唯独我要向南方行军。

跟随统帅孙子仲，去调解陈国和宋国的纠纷。却不让我回去，使我忧心忡忡。

住在哪里？在哪里？在哪里丢失了战马？到哪里去找它？原来在树林之下。

生死聚散，我曾与你立下誓言：牵着你的手，与你一起白头到老。

唉，离别太遥远了，让我无法活下去。唉，相隔太远了，让我无法信守誓言。

## 赏析

《击鼓》是《诗经·邶风》中的一首，是一首反战的诗歌，表达了士兵对战争的厌恶和对家人的思念。

全诗五章，以士兵的口吻叙述了出征的经过和内心的痛苦。前两章写被迫出征的无奈，"土国城漕，我独南行"，别人在国内服役，自己却要到远方征战，充满了不公平的怨愤。

第三章以寻找丢失的战马为喻，写漂泊无定的生活。第四、五章是全诗的核心，"死生契阔，与子成说。执子之手，与子偕老"，是千古传诵的名句。这几句原是战士之间的誓言，后世多用来表达爱情的坚贞。

结尾"于嗟阔兮，不我活兮"，以悲叹作结，表达了战士对远方亲人的思念和对战争的控诉。全诗情感深沉，语言质朴，是《诗经》中反战诗的代表作。

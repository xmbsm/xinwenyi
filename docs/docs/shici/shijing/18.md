# 摽有梅

**[先秦] 佚名**

## 原文

摽有梅，其实七兮。求我庶士，迨其吉兮。

摽有梅，其实三兮。求我庶士，迨其今兮。

摽有梅，顷筐塈之。求我庶士，迨其谓之。

## 注释

- 摽：坠落
- 梅：梅子
- 其实：它的果实
- 七：十分之七，指梅子还有很多
- 庶士：众多的男子
- 迨：及，趁
- 吉：吉日
- 三：十分之三，指梅子已经少了
- 今：今天
- 顷筐：浅筐
- 塈：取
- 谓之：开口说，指求婚

## 译文

梅子纷纷坠落，树上还有七成。追求我的小伙子，要趁吉日来求婚。

梅子纷纷坠落，树上只剩三成。追求我的小伙子，要趁今天来求婚。

梅子纷纷坠落，用浅筐来拾取。追求我的小伙子，只要开口就可以。

## 赏析

《摽有梅》是《诗经·召南》中的一首，是一首描写女子盼婚的诗歌。

全诗三章，以梅子的坠落比喻青春的流逝。第一章"其实七兮"，梅子还有七成，时间尚充裕，所以希望对方"迨其吉兮"，趁吉日来求婚。第二章"其实三兮"，梅子只剩三成，时间紧迫，所以希望对方"迨其今兮"，今天就求婚。第三章梅子落尽，只能"顷筐塈之"，所以希望对方"迨其谓之"，只要开口就行。

三章层层递进，从"吉兮"到"今兮"再到"谓之"，女子的要求越来越低，但期盼的心情越来越迫切。这种以梅子比喻青春的手法，形象生动，情感真挚。

全诗语言质朴，情感坦率，展现了先秦时期女子对婚姻的主动追求，具有浓郁的民歌色彩。

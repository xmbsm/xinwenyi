# 月出

**[先秦] 佚名**

## 原文

月出皎兮，佼人僚兮。舒窈纠兮，劳心悄兮。

月出皓兮，佼人懰兮。舒忧受兮，劳心慅兮。

月出照兮，佼人燎兮。舒夭绍兮，劳心惨兮。

## 注释

- 皎：明亮
- 佼人：美人
- 僚：同"嫽"，美好
- 舒：举止舒缓的样子
- 窈纠：形容女子体态轻盈柔美
- 劳心：忧心，思念之心
- 悄：忧愁的样子
- 皓：洁白明亮
- 懰：美好
- 忧受：形容步态轻盈
- 慅：忧愁不安
- 燎：明亮，指容光焕发
- 夭绍：形容体态轻盈柔美
- 惨：忧愁的样子

## 译文

月亮出来多么明亮，美人多么美好。她举止轻盈柔美，让我思念得心忧悄悄。

月亮出来多么皎洁，美人多么秀丽。她步态轻盈舒缓，让我思念得心忧不安。

月亮出来照耀大地，美人多么光彩照人。她体态轻盈柔美，让我思念得心忧惨惨。

## 赏析

《月出》是《诗经·陈风》中的一首，是一首描写月下怀人的诗歌，被誉为中国最早的"月下美人"诗。

全诗三章，采用重章叠句的形式，反复咏叹月光下美人的风姿和诗人的思念之情。每章都以"月出"起兴，月光皎洁、皓白、普照，层层递进地渲染出月色的美好，也烘托出美人的风姿。

"佼人僚兮""佼人懰兮""佼人燎兮"，从美好到秀丽再到光彩照人，诗人眼中的美人越来越鲜明生动。"舒窈纠兮""舒忧受兮""舒夭绍兮"，以细腻的笔触描绘出美人轻盈柔美的体态和步态。

"劳心悄兮""劳心慅兮""劳心惨兮"，与前面的美好形成对比，越是赞美美人的风姿，越显出诗人思念的深切和忧愁的浓重。

全诗意境优美，语言清丽，将月光、美人和思念完美地融为一体，对后世咏月怀人的诗词产生了深远影响。

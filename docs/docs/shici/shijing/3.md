# 桃夭

**《诗经·周南》**

## 原文

桃之夭夭，灼灼其华。之子于归，宜其室家。
桃之夭夭，有蕡其实。之子于归，宜其家室。
桃之夭夭，其叶蓁蓁。之子于归，宜其家人。

## 注释

- 夭夭：茂盛而美丽的样子
- 灼灼：鲜明的样子，形容花开繁盛
- 华：同"花"
- 之子：这位姑娘
- 于归：出嫁
- 宜：和顺，使……和睦
- 室家：家庭
- 蕡：果实硕大的样子
- 蓁蓁：树叶茂盛的样子
- 家人：一家人

## 译文

桃花怒放千万朵，色彩鲜艳红似火。这位姑娘要出嫁，喜气洋洋归夫家。
桃花怒放千万朵，果实累累大又多。这位姑娘要出嫁，早生贵子后嗣旺。
桃花怒放千万朵，绿叶茂盛永不落。这位姑娘要出嫁，齐心协手家和睦。

## 赏析

《桃夭》是《诗经·周南》中的名篇，是一首祝贺年轻女子出嫁的贺婚诗。全诗以桃花起兴，以桃花的艳丽比喻新娘的美貌，以桃实的丰硕象征多子多福，以桃叶的茂盛祝愿家庭兴旺。三章结构相似，层层递进，从花到果再到叶，寓意从新婚到生育再到家族繁荣，表达了对新娘的美好祝福。此诗开创了以桃花比喻美人的传统，对后世文学影响深远，"夭桃秾李""人面桃花"等典故皆源于此。

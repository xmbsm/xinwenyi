# 远游

**[战国] [屈原](/authors/quyuan)**

## 原文

悲时俗之迫阨兮，愿轻举而远游。
质菲薄而无因兮，焉讬乘而上浮？

遭沈浊而污秽兮，独郁结其谁语！
夜耿耿而不寐兮，魂营营而至曙。

惟天地之无穷兮，哀人生之长勤。
往者余弗及兮，来者吾不闻。

步徙倚而遥思兮，怊惝怳而乖怀。
意荒忽而流荡兮，心愁悽而增悲。

神儵忽而不反兮，形枯槁而独留。
内惟省以端操兮，求正气之所由。

漠虚静以恬愉兮，澹无为而自得。
闻赤松之清尘兮，愿承风乎遗则。

贵真人之休德兮，美往世之登仙。
与化去而不见兮，名声著而日延。

奇傅说之讬辰星兮，羡韩众之得一。
形穆穆以浸远兮，离人群而遁逸。

因气变而遂曾举兮，忽神奔而鬼怪。
时髣髴以遥见兮，精皎皎以往来。

绝氛埃而淑尤兮，终不反其故都。
免众患而不惧兮，世莫知其所如。

## 译文

（译文较长，从略。全诗讲述屈原在世俗逼迫下，渴望远游求仙，超脱尘世，最终达到精神自由境界的过程。）

## 赏析

《远游》是《楚辞》中的一篇，是屈原晚年的作品。全诗以远游求仙为线索，表达了诗人对世俗的不满和对精神自由的追求。

"悲时俗之迫阨兮，愿轻举而远游"，开篇即点明主题，因世俗逼迫而渴望远游。"质菲薄而无因兮，焉讬乘而上浮"，感叹自己资质浅薄，无法飞升。

"遭沈浊而污秽兮，独郁结其谁语"，写世俗的污浊和内心的孤独。"惟天地之无穷兮，哀人生之长勤"，以天地的无穷对比人生的辛劳，表达对生命短暂的感慨。

"漠虚静以恬愉兮，澹无为而自得"，写通过虚静无为达到内心的恬静愉悦。"闻赤松之清尘兮，愿承风乎遗则"，表达对仙人赤松子的仰慕。

"贵真人之休德兮，美往世之登仙"，赞美仙人的美德和登仙的美好。"因气变而遂曾举兮，忽神奔而鬼怪"，写通过修炼，最终达到精神自由、超脱尘世的境界。

结尾"绝氛埃而淑尤兮，终不反其故都。免众患而不惧兮，世莫知其所如"，写超脱尘世后，不再返回故都，免除众患，世人不知其所往。

全诗想象丰富，意境高远，是屈原浪漫主义诗歌的代表作之一，对后世游仙诗产生了深远影响。

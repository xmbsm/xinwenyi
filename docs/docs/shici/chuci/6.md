# 九歌·东君

**[战国] [屈原](/authors/quyuan)**

## 原文

暾将出兮东方，照吾槛兮扶桑。抚余马兮安驱，夜皎皎兮既明。驾龙辀兮乘雷，载云旗兮委蛇。长太息兮将上，心低徊兮顾怀。羌声色兮娱人，观者憺兮忘归。

緪瑟兮交鼓，箫钟兮瑶虡。鸣篪兮吹竽，思灵保兮贤姱。翾飞兮翠曾，展诗兮会舞。应律兮合节，灵之来兮蔽日。

青云衣兮白霓裳，举长矢兮射天狼。操余弧兮反沦降，援北斗兮酌桂浆。撰余辔兮高驼翔，杳冥冥兮以东行。

## 译文

太阳将从东方升起，照耀着我的栏杆和扶桑。安抚我的马缓缓前行，夜色渐明，天已破晓。驾着龙车乘着雷声，载着云旗蜿蜒前行。长叹一声将要上升，心中徘徊眷恋。那美妙的声色使人愉悦，观看的人沉醉忘归。

张紧瑟弦交替击鼓，敲击玉钟，吹奏篪竽，思念那美好的巫师。像翠鸟一样轻快地飞舞，展开诗篇合着舞蹈。合乎音律合乎节拍，神灵到来遮蔽了太阳。

穿着青云衣白霓裳，举起长箭射向天狼。拿起我的弓返回降落，拿起北斗酌饮桂花酒。握住马缰高高飞翔，在昏暗中东行而去。

## 赏析

这首诗是《九歌》中的一篇，是祭祀太阳神的乐歌，描写了太阳东升西落的运行过程，以及祭祀时的歌舞场面。

第一段写太阳升起。"暾将出兮东方"，写太阳从东方升起。"照吾槛兮扶桑"，写太阳照耀着扶桑。"抚余马兮安驱"，写太阳神安抚马匹缓缓前行。"夜皎皎兮既明"，写夜色渐明，天已破晓。

接着写太阳神的威仪。"驾龙辀兮乘雷"，写太阳神驾龙车、乘雷声。"载云旗兮委蛇"，写云旗蜿蜒。"长太息兮将上"，写太阳神长叹一声将要上升。"羌声色兮娱人"，写祭祀时的歌舞使人愉悦。

第二段写祭祀的歌舞。"緪瑟兮交鼓"，写瑟鼓齐鸣。"箫钟兮瑶虡"，写钟鼓齐奏。"鸣篪兮吹竽"，写各种乐器合奏。"翾飞兮翠曾"，写舞者像翠鸟一样飞舞。"应律兮合节"，写歌舞合乎音律节拍。

第三段写太阳西落。"青云衣兮白霓裳"，写太阳神的服饰。"举长矢兮射天狼"，写太阳神射天狼星，象征驱除灾祸。"操余弧兮反沦降"，写太阳神返回降落。"援北斗兮酌桂浆"，写太阳神拿起北斗酌酒。"杳冥冥兮以东行"，写太阳在昏暗中东行，准备第二天的升起。

全诗想象丰富，气势磅礴，将太阳神的威仪和祭祀的盛况描绘得如诗如画。

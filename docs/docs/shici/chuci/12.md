# 卜居

**[战国] [屈原](/authors/quyuan)**

## 原文

屈原既放，三年不得复见。竭知尽忠，而蔽障于谗。心烦虑乱，不知所从。

乃往见太卜郑詹尹曰："余有所疑，愿因先生决之。"詹尹乃端策拂龟，曰："君将何以教之？"

屈原曰："吾宁悃悃款款，朴以忠乎？将送往劳来，斯无穷乎？

宁诛锄草茅，以力耕乎？将游大人，以成名乎？

宁正言不讳，以危身乎？将从俗富贵，以偷生乎？

宁超然高举，以保真乎？将哫訾栗斯，喔咿儒儿，以事妇人乎？

宁廉洁正直，以自清乎？将突梯滑稽，如脂如韦，以洁楹乎？

宁昂昂若千里之驹乎？将泛泛若水中之凫，与波上下，偷以全吾躯乎？

宁与骐骥亢轭乎？将随驽马之迹乎？宁与黄鹄比翼乎？将与鸡鹜争食乎？

此孰吉孰凶？何去何从？世溷浊而不清：蝉翼为重，千钧为轻；黄钟毁弃，瓦釜雷鸣；谗人高张，贤士无名。吁嗟默默兮，谁知吾之廉贞！"

詹尹乃释策而谢曰："夫尺有所短，寸有所长；物有所不足，智有所不明；数有所不逮，神有所不通。用君之心，行君之意。龟策诚不能知此事。"

## 注释

- 竭知：竭尽才智
- 蔽障：蒙蔽
- 太卜：掌管占卜的官
- 端策拂龟：摆正蓍草，拂净龟壳，准备占卜
- 悃悃款款：忠诚老实的样子
- 朴以忠：朴实而忠诚
- 送往劳来：应酬往来
- 斯无穷：这样没有尽头
- 游大人：结交权贵
- 超然高举：超脱世俗，保持高洁
- 保真：保持本性
- 哫訾栗斯：阿谀奉承的样子
- 喔咿儒儿：强颜欢笑的样子
- 突梯滑稽：圆滑处世
- 如脂如韦：像油脂一样光滑，像熟牛皮一样柔软，比喻善于迎合
- 洁楹：度量屋柱，比喻迎合世俗
- 昂昂：昂首挺胸的样子
- 泛泛：漂浮的样子
- 凫：野鸭
- 骐骥：骏马
- 亢轭：并驾齐驱
- 驽马：劣马
- 黄鹄：天鹅
- 鹜：鸭子
- 千钧：极重的分量，一钧三十斤
- 黄钟：古代音律之一，比喻贤人
- 瓦釜：陶制的锅，比喻小人
- 高张：得势嚣张

## 译文

屈原被流放后，三年没能再见到楚王。他竭尽才智忠心耿耿，却被谗言所蒙蔽。心烦意乱，不知该何去何从。

于是他去见太卜郑詹尹说："我有疑惑，希望借助先生来决断。"詹尹便摆正蓍草拂净龟壳，说："您有什么要指教的呢？"

屈原说："我宁愿忠诚老实、朴实而忠诚呢？还是迎来送往、永无休止地应酬呢？

宁愿锄草开荒、努力耕作呢？还是结交权贵、来成就名声呢？

宁愿直言不讳、危及自身呢？还是追随世俗、追求富贵、苟且偷生呢？

宁愿超脱世俗、保持高洁、保全本性呢？还是阿谀奉承、强颜欢笑、去侍奉权贵呢？

宁愿廉洁正直、保持清白呢？还是圆滑处世、像油脂一样光滑、像熟牛皮一样柔软、去迎合世俗呢？

宁愿昂首挺胸像千里骏马呢？还是漂浮不定像水中的野鸭，随波逐流、苟且保全身躯呢？

宁愿与骏马并驾齐驱呢？还是跟随劣马的足迹呢？宁愿与天鹅比翼高飞呢？还是与鸡鸭争食呢？

这些哪个吉利哪个凶险？我该何去何从？世道混浊不清：蝉翼被认为沉重，千钧被认为轻飘；黄钟被毁弃，瓦锅却雷鸣般响亮；谗人得势嚣张，贤士却默默无闻。唉，沉默吧，有谁知道我的廉洁忠贞！"

詹尹于是放下蓍草辞谢说："尺有所短，寸有所长；事物总有不足，智慧也有不明；术数也有达不到的，神灵也有不通晓的。用您的心，行您的意。龟壳和蓍草确实不能知道这些事。"

## 赏析

《卜居》是《楚辞》中的一篇，采用问答体，通过屈原与太卜郑詹尹的对话，表达了屈原在黑暗现实面前的困惑和对人生道路的选择。

全篇以八组对比设问，将两种截然不同的人生态度并列呈现：一种是忠诚正直、廉洁清高、超然物外；另一种是阿谀奉承、圆滑世故、追逐富贵。每一组对比都鲜明强烈，表达了屈原对前者的坚守和对后者的鄙视。

"蝉翼为重，千钧为轻；黄钟毁弃，瓦釜雷鸣；谗人高张，贤士无名"，以形象的比喻控诉了是非颠倒、黑白混淆的黑暗现实。这几句成为后世批判社会不公的经典语汇。

结尾郑詹尹的回答"用君之心，行君之意"，实际上是对屈原选择的肯定。卜筮无法决断，因为这不是吉凶的问题，而是人格的选择。屈原早已做出了自己的选择，卜问只是他内心矛盾的宣泄。

全文气势磅礴，对比鲜明，是《楚辞》中独具特色的篇章。

# 九歌·湘君

**[战国] [屈原](/authors/quyuan)**

## 原文

君不行兮夷犹，蹇谁留兮中洲？美要眇兮宜修，沛吾乘兮桂舟。

令沅湘兮无波，使江水兮安流。望夫君兮未来，吹参差兮谁思？

驾飞龙兮北征，邅吾道兮洞庭。薜荔柏兮蕙绸，荪桡兮兰旌。

望涔阳兮极浦，横大江兮扬灵。扬灵兮未极，女婵媛兮为余太息。

横流涕兮潺湲，隐思君兮陫侧。桂櫂兮兰枻，斫冰兮积雪。

采薜荔兮水中，搴芙蓉兮木末。心不同兮媒劳，恩不甚兮轻绝。

石濑兮浅浅，飞龙兮翩翩。交不忠兮怨长，期不信兮告余以不闲。

鼂骋骛兮江皋，夕弭节兮北渚。鸟次兮屋上，水周兮堂下。

捐余玦兮江中，遗余佩兮醴浦。采芳洲兮杜若，将以遗兮下女。

时不可兮再得，聊逍遥兮容与。

- 宜修：修饰得体
- 沛：船行迅速的样子
- 桂舟：用桂木做的船
- 参差：排箫，乐器名
- 飞龙：快船
- 邅：回转
- 薜荔：香草名
- 柏：通"箔"，帘子
- 蕙绸：用蕙草装饰的帷帐
- 荪桡：用荪草装饰的船桨
- 兰旌：用兰草装饰的旗帜
- 涔阳：地名，在今湖南澧县
- 极浦：遥远的水边
- 扬灵：扬帆前行
- 婵媛：牵挂的样子
- 潺湲：水流的样子，这里形容泪水
- 陫侧：内心悲痛
- 櫂、枻：船桨
- 斫冰兮积雪：形容在冰雪中划船前行
- 石濑：石滩上的急流
- 浅浅：水流湍急的样子
- 鼂：同"朝"，早晨
- 弭节：停船
- 次：栖息
- 玦：环形有缺口的玉器
- 醴浦：澧水之滨
- 杜若：香草名
- 下女：侍女
- 容与：从容徘徊的样子

## 译文

您为什么犹豫不前，是谁把您留在水洲之中？我修饰得美好得体，迅速地乘上桂木做的船。

让沅水和湘水不要起波浪，让江水安稳地流淌。望着您啊您却没有来，吹起排箫啊我在思念谁？

驾着快船向北方行进，回转我的道路经过洞庭。用薜荔做帘子蕙草做帐，用荪草做桨兰草做旗。

远望涔阳在那遥远的水边，横渡大江扬帆前行。扬帆前行还没有到达，侍女们牵挂着我为我叹息。

泪流满面啊涕泗横流，暗暗思念您啊内心悲痛。桂木做桨兰木做舵，劈开冰雪啊奋勇前行。

到水中去采摘薜荔，到树梢去攀摘芙蓉。心意不同啊媒人徒劳，恩情不深啊轻易断绝。

石滩上的急流浅浅流淌，快船啊轻快地飞翔。交往不忠诚啊怨恨深长，约定不守信用啊告诉我没有空闲。

早晨在江边奔驰，傍晚在北渚停船。鸟儿栖息在屋上，流水环绕在堂下。

把玉玦抛入江中，把玉佩留在澧水之滨。到芳洲采摘杜若，将要送给身边的侍女。

时光一去不复返啊，姑且从容徘徊吧。

## 赏析

《湘君》是《九歌》中的一篇，是祭祀湘水之神湘君的乐歌。全诗以湘夫人的口吻，抒写了对湘君的思念和期盼。

诗中描绘了湘夫人精心打扮、乘船迎接湘君的情景。她装饰桂舟、吹奏排箫，在洞庭湖上翘首以盼，但湘君始终未至。诗中"令沅湘兮无波，使江水兮安流"，表达了湘夫人希望水路平静、湘君顺利到来的美好愿望。

"采薜荔兮水中，搴芙蓉兮木末"，以不可能做到的事情比喻追求的徒劳，暗示了湘君与湘夫人之间的隔阂。"心不同兮媒劳，恩不甚兮轻绝"，道出了爱情中的无奈与哀怨。

结尾"捐余玦兮江中，遗余佩兮醴浦"，以抛弃信物的动作表达了失望之情，但"时不可兮再得，聊逍遥兮容与"，最终以豁达的态度自我宽慰。

全诗想象丰富，情感细腻，将神话传说与人间情爱完美融合，是《九歌》中的名篇。

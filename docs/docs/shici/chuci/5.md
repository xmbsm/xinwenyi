# 九歌·国殇

**[战国] [屈原](/authors/quyuan)**

## 原文

操吴戈兮被犀甲，车错毂兮短兵接。旌蔽日兮敌若云，矢交坠兮士争先。凌余阵兮躐余行，左骖殪兮右刃伤。霾两轮兮絷四马，援玉枹兮击鸣鼓。天时怼兮威灵怒，严杀尽兮弃原野。

出不入兮往不反，平原忽兮路超远。带长剑兮挟秦弓，首身离兮心不惩。诚既勇兮又以武，终刚强兮不可凌。身既死兮神以灵，子魂魄兮为鬼雄。

## 注释

- 国殇：为国捐躯的将士
- 操：手持
- 吴戈：吴国制造的戈，泛指锋利的武器
- 被：通"披"
- 犀甲：犀牛皮做的铠甲
- 车错毂：战车的车轮交错，形容战斗激烈
- 短兵：刀剑等短兵器
- 旌：旗帜
- 矢交坠：箭矢交相坠落
- 凌：侵犯
- 躐：践踏
- 行：行列
- 骖：驾车的马
- 殪：死亡
- 霾：通"埋"
- 絷：拴住
- 援：拿起
- 玉枹：玉饰的鼓槌
- 怼：怨恨
- 威灵：神灵
- 严杀：残酷的杀戮
- 忽：辽阔
- 超远：遥远
- 挟：夹在腋下
- 秦弓：秦国制造的弓，泛指良弓
- 首身离：身首异处
- 惩：恐惧
- 武：武艺
- 凌：侵犯
- 神以灵：精神不死
- 鬼雄：鬼中的英雄

## 译文

手持吴戈身披犀甲，战车交错短兵相接。旗帜蔽日敌人如云，箭矢交相坠落将士争先。敌人侵犯我阵践踏我行，左骖战死右骖受伤。埋住车轮拴住马，拿起玉槌敲响战鼓。天怨神怒，残酷的杀戮后将士弃于原野。

出征不再归来，平原辽阔路途遥远。身带长剑腋下挟弓，身首分离心也不惧。确实勇敢又威武，始终刚强不可侵犯。身虽死精神不死，你们的魂魄是鬼中的英雄。

## 赏析

这首诗是《九歌》中的一篇，是屈原为祭祀为国捐躯的将士所作的挽歌，是中国文学史上最早描写战争和歌颂烈士的作品。

上篇描写战争的激烈场面。"操吴戈兮被犀甲"，写将士的装束。"车错毂兮短兵接"，写战斗的激烈。"旌蔽日兮敌若云"，以夸张的手法写敌人之多。"矢交坠兮士争先"，写将士的英勇。

接着写战斗的残酷。"凌余阵兮躐余行"，写敌人进攻之猛。"左骖殪兮右刃伤"，写伤亡之惨重。"霾两轮兮絷四马"，写将士死战不退的决心。"援玉枹兮击鸣鼓"，写战至最后一刻的壮烈。

下篇歌颂烈士的精神。"出不入兮往不反"，写将士视死如归。"带长剑兮挟秦弓，首身离兮心不惩"，写将士虽死犹勇。"诚既勇兮又以武，终刚强兮不可凌"，直接赞美将士的勇敢和刚强。

最后"身既死兮神以灵，子魂魄兮为鬼雄"，是全诗的主旨所在。将士虽然身死，但精神不死，他们的魂魄是鬼中的英雄。这种对烈士精神的赞美，激励着后人为国捐躯。

全诗气势磅礴，情感激昂，将战争的残酷和烈士的英勇表现得淋漓尽致，是中国文学史上爱国主义的经典之作。

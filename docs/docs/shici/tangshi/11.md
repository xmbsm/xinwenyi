# 凉州词

**[唐] [王之涣](/authors/wangzhihuan)**

## 原文

黄河远上白云间，一片孤城万仞山。
羌笛何须怨杨柳，春风不度玉门关。

## 注释

- 凉州词：唐代乐府曲名，多写边塞风光和军旅生活
- 黄河远上：一作"黄沙直上"，形容黄河源远流长，直上云端
- 白云间：形容黄河源头高远，仿佛流入白云之中
- 孤城：指玉门关，在今甘肃省敦煌市西北
- 万仞山：形容山势极高，仞是古代长度单位
- 羌笛：古代羌族的一种乐器
- 杨柳：指《折杨柳》曲，乐府横吹曲名，古人送别时吹奏
- 怨杨柳：吹奏《折杨柳》曲表达离别之怨
- 度：吹过
- 玉门关：汉代设置的边关，是古代通往西域的要道

## 译文

黄河源远流长，仿佛直上白云之间。一座孤城矗立在万仞高山之中。羌笛何必吹奏《折杨柳》来哀怨离别呢，春风是吹不过玉门关的。

## 赏析

这首诗是王之涣的边塞诗代表作，描写了边塞的苍凉景象和戍边将士的思乡之情，是唐人绝句中的精品。

首句"黄河远上白云间"，写黄河的源远流长。诗人以夸张的手法，将黄河写得仿佛从白云间奔流而下，既写出了黄河的雄伟气势，又暗示了边塞的遥远和荒凉。

次句"一片孤城万仞山"，写玉门关的孤危地势。"一片孤城"与"万仞山"形成鲜明对比，突出了边塞城池的孤独和险要，也暗示了戍边将士的艰苦生活。

后两句"羌笛何须怨杨柳，春风不度玉门关"，是全诗的精华所在。诗人以羌笛吹奏《折杨柳》曲起兴，写戍边将士的思乡之情。"春风不度玉门关"一句，既写出了边塞的荒凉寒冷，又暗示了朝廷的恩泽不及边塞，含蓄地表达了对戍边将士的同情。

全诗意境雄浑，语言凝练，将边塞的苍凉、将士的思乡和对朝廷的委婉批评融为一体，是盛唐边塞诗的代表作。

# 登鹳雀楼

**[唐] [王之涣](/authors/wangzhihuan)**

## 原文

白日依山尽，黄河入海流。
欲穷千里目，更上一层楼。

## 注释

- 白日：太阳
- 依：依傍，靠着
- 尽：消失
- 穷：尽，使达到极点
- 千里目：眼界宽阔

## 译文

夕阳依傍着西山慢慢地沉没，滔滔黄河朝着东海汹涌奔流。若想把千里的风光景物看够，那就要登上更高的一层城楼。

## 赏析

这首诗写诗人在登高望远中表现出来的不凡的胸襟抱负，反映了盛唐时期人们积极向上的进取精神。前两句写所见，用极简练的笔墨描绘了祖国河山的壮丽景色；后两句写所想，道出了要站得高才看得远的哲理。全诗气势磅礴，意境深远，千百年来一直激励着中华民族昂扬向上。

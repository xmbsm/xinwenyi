# 无题

**唐 李商隐**

## 原文

相见时难别亦难，东风无力百花残。
春蚕到死丝方尽，蜡炬成灰泪始干。

## 注释

- 东风：春风。
- 丝：谐音"思"，双关语。
- 蜡炬：蜡烛。

## 译文

相见很难，离别更难，春风无力，百花凋零。春蚕直到死时，思念的丝才吐尽；蜡烛燃成灰烬，离别的泪才干涸。

## 赏析

这首诗以"无题"为名，抒发了深沉的离别之情与相思之苦。诗中运用春蚕、蜡炬等意象，将抽象的情感化为具体可感的形象，成为千古传诵的爱情名句。

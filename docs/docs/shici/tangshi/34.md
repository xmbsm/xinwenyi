# 相思

**唐 王维**

## 原文

红豆生南国，春来发几枝。
愿君多采撷，此物最相思。

## 注释

- 红豆：又名相思子，色红而光泽，象征爱情或友情。
- 采撷：采摘。

## 译文

红豆生长在南方，春天来了又发出多少新枝。希望你多多采摘，因为这小小的红豆最能代表相思之情。

## 赏析

这首诗语言朴素自然，借红豆寄托相思之情，成为表达思念之情的经典之作。全诗含蓄委婉，余味悠长，体现了王维诗歌"诗中有画"的独特风格。

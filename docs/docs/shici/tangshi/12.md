# 送元二使安西

**[唐] [王维](/authors/wangwei)**

## 原文

渭城朝雨浥轻尘，客舍青青柳色新。
劝君更尽一杯酒，西出阳关无故人。

## 注释

- 元二：诗人的朋友，排行第二，名字不详
- 使：出使
- 安西：唐代安西都护府，在今新疆库车县一带
- 渭城：秦代咸阳城，汉代改称渭城，在今陕西省西安市西北
- 浥：湿润
- 轻尘：地面的尘土
- 客舍：旅馆
- 柳色新：柳树的颜色清新翠绿
- 更尽：再喝完
- 阳关：在今甘肃省敦煌市西南，是古代通往西域的关口
- 故人：老朋友

## 译文

渭城早晨的细雨湿润了地面的尘土，旅馆周围的柳树显得格外清新翠绿。劝您再喝完这一杯酒，向西出了阳关之后就没有老朋友了。

## 赏析

这首诗是王维送别友人出使安西时所作，是唐代送别诗的千古绝唱，后来被谱入乐府，成为送别时必唱的《阳关三叠》。

首句"渭城朝雨浥轻尘"，写送别时的环境。早晨的细雨湿润了尘土，空气清新，为送别营造了一种清新而略带忧伤的氛围。

次句"客舍青青柳色新"，写送别时的景物。"客舍"点明送别的地点，"柳色新"既写出了春天的生机，又暗含"柳"与"留"的谐音，表达了挽留之情。古人有折柳送别的习俗，柳树的意象在这里具有双重含义。

后两句"劝君更尽一杯酒，西出阳关无故人"，是全诗的主旨所在。诗人以朴素的语言，表达了对友人的深情厚谊。"更尽一杯酒"，既是对友人的祝福，也是对离别的不舍。"西出阳关无故人"，则点明了离别后的孤独，阳关之外是荒凉的西域，友人将独自面对未知的旅程。

全诗语言平淡自然，却蕴含着深厚的情感，将离别之情写得真挚动人，成为千古传诵的送别名篇。

# 黄鹤楼

**[唐] [崔颢](/authors/cuihao)**

## 原文

昔人已乘黄鹤去，此地空余黄鹤楼。
黄鹤一去不复返，白云千载空悠悠。
晴川历历汉阳树，芳草萋萋鹦鹉洲。
日暮乡关何处是？烟波江上使人愁。

## 注释

- 昔人：指传说中的仙人子安或费祎，曾乘黄鹤过此
- 黄鹤楼：故址在今湖北武汉长江大桥武昌桥头
- 悠悠：飘荡的样子
- 晴川：阳光照耀下的江面
- 历历：清晰可数的样子
- 汉阳：今武汉汉阳区
- 萋萋：草木茂盛的样子
- 鹦鹉洲：长江中的沙洲，今已不存
- 乡关：故乡

## 译文

传说中的仙人早已乘黄鹤离去，这里只留下空荡荡的黄鹤楼。黄鹤一去再也没有回来，千百年来只有白云在空中悠悠飘荡。阳光照耀下汉阳的树木清晰可见，鹦鹉洲上芳草长得十分茂盛。天色已晚，我的故乡在哪里呢？只见江上烟波浩渺，让人愁绪满怀。

## 赏析

这首诗是崔颢的代表作，被誉为"唐人七律第一"，连李白登黄鹤楼时也曾感叹"眼前有景道不得，崔颢题诗在上头"。

前四句写黄鹤楼的传说和登楼所见，充满怀古之思。"昔人已乘黄鹤去，此地空余黄鹤楼"，以传说起笔，营造出一种空灵缥缈的意境。"黄鹤一去不复返，白云千载空悠悠"，由古及今，感叹时光流逝、世事变迁，寄寓着诗人对人生短暂的感慨。

后四句写登楼远眺所见的实景和由此引发的乡愁。"晴川历历汉阳树，芳草萋萋鹦鹉洲"，对仗工整，色彩鲜明，描绘出一幅开阔明丽的江景图。尾联"日暮乡关何处是？烟波江上使人愁"，由景入情，点明主旨，以苍茫的暮色和浩渺的烟波烘托出浓浓的思乡之情。

全诗虚实结合，情景交融，既有飘逸的浪漫色彩，又有深沉的现实感慨，堪称唐诗中的绝唱。

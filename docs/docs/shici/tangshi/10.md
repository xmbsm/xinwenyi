# 出塞

**[唐] [王昌龄](/authors/wangchangling)**

## 原文

秦时明月汉时关，万里长征人未还。
但使龙城飞将在，不教胡马度阴山。

## 注释

- 出塞：出关塞，指到边疆戍守
- 秦时明月汉时关：秦汉时的明月和关隘，指代自古以来边塞的景物
- 万里长征：长途跋涉到边疆征战
- 人未还：出征的人还没有回来
- 但使：只要
- 龙城飞将：指汉代名将李广，匈奴称他为"飞将军"
- 不教：不让
- 胡马：指匈奴的战马，代指匈奴军队
- 阴山：在今内蒙古自治区，是古代中原王朝与匈奴的界山

## 译文

秦汉时的明月照耀着秦汉时的关隘，万里长征的将士们至今还没有归来。只要有像李广那样的飞将军在，就不会让匈奴的战马越过阴山。

## 赏析

这首诗是王昌龄的边塞诗代表作，表达了对边疆将士的同情和对良将的渴望，被誉为唐人七绝的压卷之作。

首句"秦时明月汉时关"，运用互文手法，将秦汉连在一起，写出了边塞历史的悠久。明月和关隘都是边塞的典型意象，诗人将它们与秦汉联系起来，营造出一种雄浑苍茫的意境。

次句"万里长征人未还"，写边塞战争的漫长和残酷。"万里"极言征途之远，"人未还"则暗示了战争的惨烈和将士的牺牲，表达了诗人对征人的深切同情。

后两句"但使龙城飞将在，不教胡马度阴山"，是全诗的主旨所在。诗人借汉代名将李广的典故，表达了对良将的渴望和对和平的向往。只要有像李广那样的名将镇守边关，外敌就不敢入侵，百姓就能安居乐业。

全诗气势雄浑，意境深远，将历史的沧桑、战争的残酷和对和平的渴望融为一体，体现了盛唐边塞诗的典型风格。

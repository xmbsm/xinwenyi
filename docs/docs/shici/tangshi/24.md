# 登高

**[唐] [杜甫](/authors/dufu)**

## 原文

风急天高猿啸哀，渚清沙白鸟飞回。
无边落木萧萧下，不尽长江滚滚来。
万里悲秋常作客，百年多病独登台。
艰难苦恨繁霜鬓，潦倒新停浊酒杯。

## 注释

- 猿啸：猿猴的啼叫声
- 渚：水中小块陆地
- 鸟飞回：鸟儿在风中盘旋飞翔
- 落木：落叶
- 萧萧：形容落叶的声音
- 滚滚：形容江水奔腾不息
- 万里：指远离故乡
- 悲秋：因秋景而悲伤
- 作客：客居他乡
- 百年：一生，这里指晚年
- 独登台：独自登上高台
- 艰难：指时局艰难和人生坎坷
- 苦恨：深恨
- 繁霜鬓：白发增多
- 潦倒：失意颓丧
- 新停：刚刚停止
- 浊酒杯：指饮酒

## 译文

秋风急骤，天空高远，猿猴的啼叫声凄厉悲哀。水清沙白的小洲上，鸟儿在风中盘旋飞翔。无边无际的落叶萧萧飘落，奔腾不息的长江滚滚而来。远离故乡万里，悲叹秋天的萧瑟，长年客居他乡；一生多病，如今独自登上高台。时局艰难，深恨白发日益增多；失意颓丧，刚刚戒断了浊酒。

## 赏析

这首诗是杜甫晚年流寓夔州时所作，被誉为"古今七言律诗第一"。全诗通过登高所见所感，抒发了诗人长年漂泊、老病孤愁的复杂情感。

前四句写景，"风急天高猿啸哀，渚清沙白鸟飞回"，以六个意象勾勒出秋日登高所见的萧瑟景象。"无边落木萧萧下，不尽长江滚滚来"，是千古名句，以宏大的气势写出了秋天的壮阔景象。落叶无边，江水不尽，既写出了自然界的永恒，也暗示了人生的短暂。

后四句抒情，"万里悲秋常作客，百年多病独登台"，将写景与抒情融为一体。"万里"写空间之远，"百年"写时间之长，"悲秋""作客""多病""独登台"，层层叠加，将诗人的悲苦之情推向极致。

"艰难苦恨繁霜鬓，潦倒新停浊酒杯"，写诗人因国难家愁而白发日增，因多病而不得不戒酒，更添一层悲凉。全诗八句皆对，对仗工整，意境雄浑，情感深沉，是杜甫七律的代表作。

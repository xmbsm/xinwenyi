# 悯农

**[唐] [李绅](/authors/lishen)**

## 原文

锄禾日当午，汗滴禾下土。
谁知盘中餐，粒粒皆辛苦。

## 注释

- 悯：怜悯、同情
- 禾：谷类作物的统称
- 日当午：正午时分，太阳正当头顶
- 餐：饭食

## 译文

农民在正午烈日的暴晒下锄禾，汗水从身上滴落在禾苗生长的土地上。又有谁知道盘中的饭食，每一粒都是农民辛苦劳作得来的呢？

## 赏析

这首诗是李绅《悯农二首》中的第二首，语言朴素自然，却蕴含着深刻的思想内涵。诗人以白描手法，描绘了农民在烈日下辛勤劳作的场景，进而引发出对粮食来之不易的感慨。

前两句"锄禾日当午，汗滴禾下土"，用简练的笔墨勾勒出农民劳作的艰辛画面。正午时分，烈日当空，农民仍在田间挥汗劳作，汗水滴入泥土，与禾苗融为一体。这一细节描写生动传神，令人动容。

后两句"谁知盘中餐，粒粒皆辛苦"，由景入情，由事入理，以反问的语气提醒人们珍惜粮食，尊重劳动。这两句诗因其深刻的思想性和通俗易懂的表达，成为流传千古的名句，至今仍具有深刻的教育意义。

# 春晓

**[唐] [孟浩然](/authors/menghaoran)**

## 原文

春眠不觉晓，处处闻啼鸟。
夜来风雨声，花落知多少。

## 注释

- 晓：天亮
- 闻：听见
- 啼鸟：鸟啼，鸟的叫声

## 译文

春天的夜晚睡得很香甜，不知不觉天就亮了。醒来时到处都能听到鸟儿欢快的鸣叫声。回想起昨夜的风雨声，不知道有多少花朵被打落了。

## 赏析

这首诗是诗人隐居在鹿门山时所作，意境十分优美。诗人抓住春晨生活的一刹那，描写了春睡香甜、鸟鸣悦耳、风雨过后落花满地的情景，表达了对春天的热爱和对春光流逝的淡淡惋惜。全诗语言清新自然，韵味无穷，是脍炙人口的咏春名篇。

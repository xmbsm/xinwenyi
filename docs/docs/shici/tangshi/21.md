# 别董大

**[唐] [高适](/authors/gaoshi)**

## 原文

千里黄云白日曛，北风吹雁雪纷纷。
莫愁前路无知己，天下谁人不识君。

## 注释

- 董大：董庭兰，当时著名的琴师
- 黄云：夕阳下的云彩呈黄色
- 曛：昏暗
- 前路：前方的路程
- 知己：知心朋友
- 谁人：哪个人
- 君：您，指董大

## 译文

千里黄云遮天蔽日，天色昏暗，北风呼啸，大雁南飞，大雪纷纷扬扬。不要担心前方路上没有知心朋友，天下有哪个人不认识您呢？

## 赏析

这首诗是高适送别友人董庭兰时所作，是一首充满豪迈气概的送别诗。与一般送别诗的悲戚缠绵不同，这首诗以开阔的胸襟和昂扬的格调，表达了对友人的鼓励和赞美。

前两句写景，"千里黄云白日曛，北风吹雁雪纷纷"，描绘出一幅苍茫壮阔的冬日送别图。黄云、白日、北风、大雁、飞雪，构成了一幅雄浑而略带凄凉的画面，为送别营造了背景。

后两句抒情，"莫愁前路无知己，天下谁人不识君"，是千古传诵的名句。诗人以豪迈的语气安慰友人，不要担心前路没有知己，以您的才华和名声，天下有谁不认识您呢？这既是对友人的高度赞美，也是对友人的真诚鼓励，充满了自信和力量。

全诗语言质朴，格调高昂，是盛唐送别诗中的佳作，充分体现了盛唐诗人开阔的胸襟和乐观的精神风貌。

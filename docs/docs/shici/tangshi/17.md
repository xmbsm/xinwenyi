# 山居秋暝

**[唐] [王维](/authors/wangwei)**

## 原文

空山新雨后，天气晚来秋。
明月松间照，清泉石上流。
竹喧归浣女，莲动下渔舟。
随意春芳歇，王孙自可留。

## 注释

- 暝：日落时分，天色将晚
- 空山：幽静的山林
- 新雨：刚下过的雨
- 浣女：洗衣的女子
- 随意：任凭
- 春芳：春天的花草
- 歇：消散、逝去
- 王孙：原指贵族子弟，这里指诗人自己

## 译文

空旷的山林刚刚下过一场雨，傍晚时分秋意更浓。皎洁的月光透过松林洒下，清澈的泉水在山石上潺潺流淌。竹林中传来欢声笑语，那是洗衣的女子归来了；荷叶纷纷摇动，那是渔舟顺流而下。任凭春天的芳华消逝吧，这秋日的山林依然值得我留连。

## 赏析

这首诗是王维山水田园诗的代表作，描绘了秋雨初晴后山村的旖旎风光和山居村民的淳朴生活，表现了诗人寄情山水田园、对隐居生活怡然自得的满足心情。

首联"空山新雨后，天气晚来秋"，点明时间、地点和季节，勾勒出雨后空山的清新景象。颔联"明月松间照，清泉石上流"，是千古名句，月光与松林、清泉与山石相互映衬，构成一幅清幽明净的山水画卷。

颈联"竹喧归浣女，莲动下渔舟"，由景及人，以动衬静。竹林中的喧笑声和荷叶的摇动，反衬出山林的幽静，也展现了山村生活的生机与活力。尾联"随意春芳歇，王孙自可留"，化用《楚辞》典故，表达了诗人对山居秋景的喜爱和归隐之志。

全诗诗中有画，画中有诗，充分体现了王维"诗中有画"的艺术特色。

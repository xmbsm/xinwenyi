# 月下独酌

**[唐] [李白](/authors/libai)**

## 原文

花间一壶酒，独酌无相亲。
举杯邀明月，对影成三人。
月既不解饮，影徒随我身。
暂伴月将影，行乐须及春。
我歌月徘徊，我舞影零乱。
醒时同交欢，醉后各分散。
永结无情游，相期邈云汉。

## 注释

- 独酌：独自饮酒
- 无相亲：没有亲近的人相伴
- 邀：邀请
- 对影：对着自己的影子
- 三人：指诗人、月亮和影子
- 解饮：懂得饮酒
- 徒：白白地
- 将：和，与
- 及春：趁着春光
- 徘徊：来回移动
- 零乱：散乱
- 交欢：一起欢乐
- 无情游：忘却世俗情虑的交往
- 相期：相约
- 邈：遥远
- 云汉：银河

## 译文

在花丛中摆上一壶酒，独自饮酒，没有亲近的人相伴。举起酒杯邀请明月，加上自己的影子，就成了三个人。月亮本来就不懂饮酒，影子也只是白白地跟随我的身体。暂且与月亮和影子为伴，行乐要趁着春光。我唱歌时月亮在天空徘徊，我跳舞时影子在地上零乱。清醒时一起欢乐，醉酒后各自分散。愿永远结下这忘却世俗情虑的游伴之约，相约在遥远的银河之上再见。

## 赏析

这首诗是李白在长安时所作，描写了诗人月下独酌的情景，表现了诗人孤独寂寞而又旷达自适的复杂心情。

"花间一壶酒，独酌无相亲"，开篇点出独酌的孤独。但诗人并不沉溺于孤独，而是展开奇妙的想象："举杯邀明月，对影成三人"，将月亮和影子都当作陪伴自己的朋友，化孤独为热闹。这一想象新奇独特，成为千古名句。

"月既不解饮，影徒随我身"，写月亮和影子的"无情"，它们虽然陪伴着诗人，却不能真正理解诗人的心意。但诗人并不因此沮丧，"暂伴月将影，行乐须及春"，既然有伴，姑且及时行乐。

"我歌月徘徊，我舞影零乱"，写诗人载歌载舞，月亮和影子也随之而动，构成一幅奇妙的画面。"醒时同交欢，醉后各分散"，写清醒时的欢乐和醉后的分离，暗示了这种陪伴的虚幻。

结尾"永结无情游，相期邈云汉"，以浪漫的想象收束全诗。诗人愿与月亮、影子结下永恒的友谊，相约在银河之上再见。这既是对孤独的超越，也是对理想境界的向往。

全诗想象奇特，意境优美，将孤独与旷达、现实与幻想完美地融为一体，充分体现了李白浪漫主义的艺术风格。

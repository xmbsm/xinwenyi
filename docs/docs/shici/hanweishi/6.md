# 白马篇

**[魏] [曹植](/authors/caozhi)**

## 原文

白马饰金羁，连翩西北驰。
借问谁家子，幽并游侠儿。
少小去乡邑，扬声沙漠垂。
宿昔秉良弓，楛矢何参差。
控弦破左的，右发摧月支。
仰手接飞猱，俯身散马蹄。
狡捷过猴猿，勇剽若豹螭。
边城多警急，虏骑数迁移。
羽檄从北来，厉马登高堤。
长驱蹈匈奴，左顾凌鲜卑。
弃身锋刃端，性命安可怀？
父母且不顾，何言子与妻！
名编壮士籍，不得中顾私。
捐躯赴国难，视死忽如归。

## 注释

- 金羁：金色的马笼头
- 连翩：飞驰的样子
- 幽并：幽州和并州，今河北、山西一带，古代多出游侠之士
- 游侠儿：重义轻生、勇于急人之难的青年
- 扬声：扬名
- 垂：同"陲"，边疆
- 宿昔：一向，平素
- 秉：持，拿
- 楛矢：用楛木做杆的箭
- 参差：长短不齐的样子
- 控弦：拉弓
- 的：箭靶
- 月支：箭靶名
- 接：迎射飞射而来的物体
- 猱：猿类动物，善攀援腾跃
- 散：射碎
- 马蹄：箭靶名
- 剽：轻快，敏捷
- 螭：传说中一种无角的龙
- 羽檄：插有羽毛的紧急军事文书
- 厉马：策马，催马
- 蹈：践踏，此处指冲锋陷阵
- 凌：压制，制服
- 怀：顾惜
- 籍：名册
- 中顾：内心顾念

## 译文

白马配着金色的笼头，向西北方向飞驰而去。
请问这是谁家的少年？是幽州并州的游侠儿。
从小就离开了家乡，在沙漠边疆扬名立万。
一向手持良弓，楛木箭杆长短不齐。
拉弓射破左边的靶子，向右发箭摧毁月支靶。
仰身迎射飞跃的猿猱，俯身射碎马蹄靶。
身手矫健超过猴猿，勇猛轻捷如同豹螭。

边城多有紧急警报，敌虏骑兵频繁调动。
插着羽毛的紧急文书从北方传来，催马登上高高的堤岸。
长驱直入践踏匈奴阵地，向左回师压制鲜卑。
投身在刀锋刀刃之上，性命怎能顾惜？
父母尚且顾不上，何况妻子儿女！
名字编在壮士的名册上，心中不能顾及私情。
捐献身躯奔赴国难，看待死亡就像回家一样平常。

## 赏析

《白马篇》是曹植的代表作之一，属乐府《杂曲歌·齐瑟行》。这首诗塑造了一位武艺超群、忠勇爱国的边塞游侠形象，寄托了诗人建功立业的理想抱负。

诗的前半部分着力描写游侠儿的高超武艺。"白马饰金羁，连翩西北驰"，开篇即以骏马飞驰的英姿抓住读者。"控弦破左的，右发摧月支。仰手接飞猱，俯身散马蹄"，通过一连串精彩的射术描写，展现了主人公出神入化的武艺。"狡捷过猴猿，勇剽若豹螭"，以比喻手法进一步突出其身手矫健、勇猛过人。

后半部分转入描写游侠儿的爱国情怀。"羽檄从北来，厉马登高堤"，国家有难，义无反顾。"长驱蹈匈奴，左顾凌鲜卑"，冲锋陷阵，所向披靡。"弃身锋刃端，性命安可怀？父母且不顾，何言子与妻！"，将个人生死、家庭亲情置之度外，展现出崇高的牺牲精神。

末句"捐躯赴国难，视死忽如归"是全诗的点睛之笔，将爱国豪情推向极致。这既是游侠儿的铮铮誓言，也是曹植本人渴望为国建功立业、不惜牺牲生命的真实写照。

全诗人物形象鲜明，节奏明快，语言雄健，充分体现了曹植"骨气奇高，词采华茂"的艺术风格。

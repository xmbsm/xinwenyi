# 燕歌行

**[魏] [曹丕](/authors/caopi)**

## 原文

秋风萧瑟天气凉，草木摇落露为霜。
群燕辞归鹄南翔，念君客游思断肠。
慊慊思归恋故乡，君何淹留寄他方？
贱妾茕茕守空房，忧来思君不敢忘，不觉泪下沾衣裳。
援琴鸣弦发清商，短歌微吟不能长。
明月皎皎照我床，星汉西流夜未央。
牵牛织女遥相望，尔独何辜限河梁。

## 注释

- 燕歌行：乐府旧题，属《相和歌·平调曲》
- 萧瑟：草木被秋风吹动的声音
- 摇落：凋残零落
- 鹄：天鹅
- 念君：思念夫君
- 慊慊：空虚不满的样子，形容思归之情
- 淹留：久留
- 贱妾：古代妇女自称的谦词
- 茕茕：孤独的样子
- 援：取，拿
- 清商：乐调名，音调短促凄清
- 微吟：低声吟唱
- 星汉西流：银河向西移动，表示夜深
- 未央：未尽
- 牵牛织女：指牵牛星和织女星
- 尔：你们
- 辜：罪过
- 限河梁：被银河上的桥梁阻隔，传说牵牛织女被银河阻隔，每年七夕才能相会

## 译文

秋风萧瑟，天气渐渐转凉，草木凋残零落，白露凝结成霜。
燕子辞别北方归去，天鹅向南飞翔，思念远游在外的夫君，令人愁肠寸断。
你满怀思归之情眷恋故乡，为何还要久留在他乡？
我孤独地守着空房，忧愁袭来，思念你而不敢忘怀，不知不觉泪水沾湿了衣裳。
取琴弹奏，发出凄清的商调，短歌低吟，难以唱出悠长的曲调。
明亮的月光皎洁地照在我的床上，银河西移，长夜未尽。
牵牛星和织女星遥遥相望，你们究竟有什么罪过，被这银河上的桥梁所阻隔？

## 赏析

《燕歌行》是曹丕的代表作，是中国文学史上现存最早最完整的七言诗。这首诗以思妇的口吻，抒发了对远方游子的深切思念，开创了七言闺怨诗的先河。

诗的前三句写景，"秋风萧瑟天气凉，草木摇落露为霜"，以典型的秋景起兴，渲染出凄凉萧瑟的氛围。"群燕辞归鹄南翔"，候鸟尚且知归，反衬出游子不归的惆怅。

"念君客游思断肠"点明主旨，直抒胸臆。接着以思妇的口吻追问："慊慊思归恋故乡，君何淹留寄他方？"既表达了对丈夫的理解，又流露出深深的哀怨。

"贱妾茕茕守空房"以下，转入对思妇独处空房情景的描写。"忧来思君不敢忘，不觉泪下沾衣裳"，将思念之情推向高潮。援琴弹奏，本想排遣忧愁，但清商之音短促凄清，反而更添愁绪。

最后四句以景结情，"明月皎皎照我床，星汉西流夜未央"，月光照床，星河西移，长夜漫漫，更衬托出思妇的孤独难耐。"牵牛织女遥相望，尔独何辜限河梁"，以牵牛织女的神话作结，既是对天上双星的同情，也是对人间离别之苦的感叹。

全诗语言清丽，情感细腻，音韵和谐，充分展现了曹丕诗歌"婉约"的艺术风格。

# 浣溪沙·一曲新词酒一杯

**[宋] [晏殊](/authors/yanshu)**

## 原文

一曲新词酒一杯，去年天气旧亭台。夕阳西下几时回？

无可奈何花落去，似曾相识燕归来。小园香径独徘徊。

## 注释

- 浣溪沙：词牌名
- 新词：新填的词
- 旧亭台：昔日的亭台
- 几时回：什么时候回来
- 无可奈何：没有办法
- 似曾相识：好像曾经认识
- 香径：落花飘香的小路
- 徘徊：来回走动

## 译文

听一曲新填的词，饮一杯美酒，天气还是去年的天气，亭台还是旧日的亭台。夕阳西下，什么时候才能再回来呢？

花儿凋落让人无可奈何，那归来的燕子似曾相识。我独自在落花飘香的小路上来回徘徊。

## 赏析

这首词是晏殊的代表作，表达了词人对时光流逝的感慨和对美好事物的留恋。

上片写眼前景，"一曲新词酒一杯"，以轻松的笔调起笔，写饮酒听歌的闲适生活。但"去年天气旧亭台"一句，点明景物依旧而时光已逝，暗含物是人非之感。"夕阳西下几时回"，以反问的语气表达对时光不再的惋惜。

下片"无可奈何花落去，似曾相识燕归来"，是千古传诵的名句。花落去是自然规律，人力无法挽回，故曰"无可奈何"；燕归来是季节轮回，带来一丝慰藉，故曰"似曾相识"。这一去一来，一失一得，蕴含着深刻的哲理：美好事物的消逝固然令人惋惜，但生活中仍有新的希望。结尾"小园香径独徘徊"，以词人独自徘徊的身影收束全词，余韵悠长。

全词语言清丽，意境优美，于平淡中见深情，充分体现了晏殊词"温润秀洁"的艺术风格。

# 声声慢·寻寻觅觅

**宋 李清照**

## 原文

寻寻觅觅，冷冷清清，凄凄惨惨戚戚。乍暖还寒时候，最难将息。三杯两盏淡酒，怎敌他、晚来风急？雁过也，正伤心，却是旧时相识。
满地黄花堆积，憔悴损，如今有谁堪摘？守着窗儿，独自怎生得黑？梧桐更兼细雨，到黄昏、点点滴滴。这次第，怎一个愁字了得！

## 注释

- 将息：调养休息。
- 次第：情形、光景。

## 译文

寻寻觅觅，冷冷清清，凄凄惨惨悲戚。乍暖还寒的时节，最难调养休息。几杯淡酒，怎能抵挡傍晚的急风？大雁飞过，正伤心时，发现却是旧日相识。
满地菊花堆积，已经憔悴枯萎，如今还有谁堪采摘？守着窗户，独自怎样才能熬到天黑？梧桐叶上又落下细雨，到黄昏时分，点点滴滴。这般光景，怎一个愁字能概括得了！

## 赏析

这首词是李清照晚年的代表作，开篇连用七组叠字，奇绝千古。全词通过描写秋日凄清的景象，抒发了国破家亡、身世飘零的深重哀愁，情感真挚动人，是婉约词的巅峰之作。

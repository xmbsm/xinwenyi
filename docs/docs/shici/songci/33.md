# 鹧鸪天·代人赋

**宋 辛弃疾**

## 原文

陌上柔桑破嫩芽，东邻蚕种已生些。平冈细草鸣黄犊，斜日寒林点暮鸦。
山远近，路横斜，青旗沽酒有人家。城中桃李愁风雨，春在溪头荠菜花。

## 注释

- 陌上：田间小路。
- 青旗：酒旗，古代酒店的标志。
- 荠菜：一种野菜，春天开花。

## 译文

田间小路上的柔桑冒出了嫩芽，东邻的蚕种已经孵化出一些。平坦的山冈上，细草间黄牛犊在鸣叫，夕阳下的寒林中点缀着归巢的乌鸦。
远山近岭，道路横斜，酒旗招展处有人家。城中的桃李正为风雨发愁，而春天却在溪头的荠菜花上。

## 赏析

这首词描绘了乡村早春的风光，清新自然，充满生机。结尾以城中桃李与溪头荠菜对比，表达了对田园生活的热爱和对淳朴自然的赞美，体现了词人豁达的人生态度。

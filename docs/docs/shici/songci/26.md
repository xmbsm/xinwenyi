# 踏莎行·郴州旅舍

**[宋] [秦观](/authors/qinguan)**

## 原文

雾失楼台，月迷津渡。桃源望断无寻处。可堪孤馆闭春寒，杜鹃声里斜阳暮。

驿寄梅花，鱼传尺素。砌成此恨无重数。郴江幸自绕郴山，为谁流下潇湘去？

## 注释

- 踏莎行：词牌名
- 郴州：今湖南郴州
- 津渡：渡口
- 桃源：桃花源，陶渊明笔下的理想境界
- 望断：望尽，望不到
- 可堪：怎能忍受
- 孤馆：孤寂的客舍
- 杜鹃：杜鹃鸟，叫声似"不如归去"
- 驿寄梅花：通过驿站寄送梅花，典出陆凯寄梅给范晔
- 鱼传尺素：通过鱼腹传递书信，古代传说
- 砌：堆积
- 无重数：数不尽
- 郴江：流经郴州的江水
- 幸自：本自
- 潇湘：潇水和湘水，在湖南

## 译文

雾气遮蔽了楼台，月色迷离了渡口。望尽天涯，桃花源无处可寻。怎能忍受孤寂的客舍中春寒紧闭，在杜鹃的啼叫声中，夕阳渐渐西沉。通过驿站寄来梅花，通过鱼腹传递书信。堆积成这无尽的离恨，数也数不清。郴江本自环绕着郴山，却为谁流下潇湘而去呢？

## 赏析

这首词是秦观被贬郴州时所作，表达了词人在贬谪途中的孤寂和哀怨。

"雾失楼台，月迷津渡"，开篇即以朦胧的景象营造出迷茫的氛围。楼台被雾遮蔽，渡口被月迷离，象征着词人前途的迷茫。"桃源望断无寻处"，写词人对理想境界的向往和失望，桃花源无处可寻，正如词人找不到精神的归宿。

"可堪孤馆闭春寒，杜鹃声里斜阳暮"，写客舍中的孤寂。孤馆、春寒、杜鹃、斜阳，这些意象叠加在一起，构成一幅凄清的画面。杜鹃的啼叫声似"不如归去"，更添思乡之情。

"驿寄梅花，鱼传尺素"，写亲友的来信。但这些书信反而勾起了更多的离恨，"砌成此恨无重数"，离恨如砖石般堆积，数也数不清。

"郴江幸自绕郴山，为谁流下潇湘去"，是千古名句。郴江本应环绕郴山，却为何要流向潇湘呢？以江水的不合常理，比喻自己被贬谪的不公和无奈。这一问，将词人的哀怨推向了极致。

# 渔家傲·秋思

**[宋] [范仲淹](/authors/fanzhongyan)**

## 原文

塞下秋来风景异，衡阳雁去无留意。四面边声连角起，千嶂里，长烟落日孤城闭。

浊酒一杯家万里，燕然未勒归无计。羌管悠悠霜满地，人不寐，将军白发征夫泪。

## 注释

- 渔家傲：词牌名
- 塞下：边塞地区
- 衡阳雁去：传说大雁南飞至衡阳回雁峰而止
- 边声：边塞特有的风声、马嘶声等
- 角：军中号角
- 千嶂：层峦叠嶂
- 长烟：荒漠上的直烟
- 孤城闭：孤城城门紧闭
- 燕然未勒：典出窦宪破匈奴后登燕然山刻石记功，指功业未成
- 归无计：无法归去
- 羌管：羌笛
- 悠悠：形容笛声悠长
- 寐：入睡
- 征夫：出征的士兵

## 译文

边塞的秋天到来，风景与内地大不相同，大雁向衡阳飞去，毫无留恋之意。四面边塞的风声与军中号角声一起响起，在层峦叠嶂之中，长烟直上，落日西沉，孤城城门紧闭。一杯浊酒，思念万里之外的家乡，但功业未成，无法归去。羌笛声声悠长，寒霜铺满大地，人们无法入睡，将军已是白发苍苍，征夫们泪流满面。

## 赏析

这首词是范仲淹镇守西北边塞时所作，是宋代豪放词的先声，开创了边塞词的新风格。

上片写景，"塞下秋来风景异"，一个"异"字，点明边塞秋景与内地的不同。"衡阳雁去无留意"，写大雁南飞，连大雁都不愿停留，更何况人呢？"四面边声连角起，千嶂里，长烟落日孤城闭"，以雄浑的笔触描绘出边塞的壮阔景象和紧张的军事氛围。千嶂、长烟、落日、孤城，构成一幅苍凉而壮美的画面。

下片抒情，"浊酒一杯家万里"，写将士们的思乡之情。"燕然未勒归无计"，用窦宪刻石记功的典故，表达了功业未成、无法归家的无奈。"羌管悠悠霜满地"，以悠扬的笛声和满地的寒霜，烘托出凄清的氛围。

"人不寐，将军白发征夫泪"，是全词的高潮。将军白发苍苍，征夫泪流满面，他们为国守边，付出了青春和热血。这一画面既悲壮又感人，充分体现了范仲淹"先天下之忧而忧"的情怀。

# 永遇乐·京口北固亭怀古

**[宋] [辛弃疾](/authors/xinqiji)**

## 原文

千古江山，英雄无觅孙仲谋处。舞榭歌台，风流总被雨打风吹去。斜阳草树，寻常巷陌，人道寄奴曾住。想当年，金戈铁马，气吞万里如虎。

元嘉草草，封狼居胥，赢得仓皇北顾。四十三年，望中犹记，烽火扬州路。可堪回首，佛狸祠下，一片神鸦社鼓。凭谁问：廉颇老矣，尚能饭否？

## 注释

- 京口：今江苏镇江
- 北固亭：在镇江东北北固山上
- 孙仲谋：孙权，字仲谋，三国时吴国君主
- 寄奴：南朝宋武帝刘裕的小名
- 元嘉：南朝宋文帝刘义隆的年号
- 封狼居胥：指霍去病追击匈奴至狼居胥山，封山而还
- 佛狸：北魏太武帝拓跋焘的小名
- 神鸦社鼓：祭祀时的鼓声和吃祭品的乌鸦
- 廉颇：战国时赵国名将

## 译文

历经千古的江山，再也找不到像孙权那样的英雄。当年的舞榭歌台，那些风流韵事都被岁月的风雨吹打殆尽。斜阳照在草树之间，那普通的街巷，人们说就是刘裕曾经居住的地方。回想当年，他率领金戈铁马，气势如猛虎，吞并万里河山。

刘义隆草率北伐，想建立像霍去病封狼居胥那样的功业，却落得仓皇败退。四十三年过去了，遥望中原，我仍然记得扬州路上的烽火连天。怎能回首往事，那佛狸祠下，一片乌鸦争食祭品、社鼓咚咚的景象。还有谁会问：廉颇老了，还能吃饭吗？

## 赏析

这首词是辛弃疾六十六岁任镇江知府时所作，借古讽今，表达了词人壮志难酬的悲愤和对国家命运的深切忧虑。

上片怀古，追慕孙权、刘裕两位英雄人物。"千古江山，英雄无觅孙仲谋处"，开篇即气势雄浑，感叹英雄难觅。"想当年，金戈铁马，气吞万里如虎"，高度概括了刘裕北伐的赫赫战功，寄寓了词人对英雄事业的向往。

下片讽今，借刘义隆草率北伐失败的教训，警告当朝统治者不要轻举妄动。"元嘉草草，封狼居胥，赢得仓皇北顾"，用典故暗讽南宋朝廷的冒进政策。"四十三年，望中犹记，烽火扬州路"，回忆自己当年抗金的经历，感慨时光流逝而壮志未酬。结尾"凭谁问：廉颇老矣，尚能饭否？"以廉颇自比，表达了词人虽年老而壮志不减，却无人赏识的悲愤。

全词用典精当，意境雄浑，是辛弃疾豪放词的代表作之一。

# 破阵子·为陈同甫赋壮词以寄之

**[宋] [辛弃疾](/authors/xinqiji)**

## 原文

醉里挑灯看剑，梦回吹角连营。八百里分麾下炙，五十弦翻塞外声，沙场秋点兵。

马作的卢飞快，弓如霹雳弦惊。了却君王天下事，赢得生前身后名。可怜白发生！

## 注释

- 破阵子：词牌名
- 陈同甫：陈亮，字同甫，南宋思想家、文学家，辛弃疾的好友
- 挑灯：拨亮灯火
- 吹角连营：各个军营接连吹起号角
- 八百里：指牛，典出《世说新语》
- 麾下：部下
- 炙：烤肉
- 五十弦：指瑟，这里泛指乐器
- 翻：演奏
- 塞外声：边塞的军乐
- 点兵：检阅军队
- 的卢：一种快马，传说刘备骑的卢马跃过檀溪
- 霹雳：雷声，形容弓弦响声如雷
- 了却：完成
- 天下事：指收复失地、统一国家的大业

## 译文

醉酒后拨亮灯火细看宝剑，梦中回到了号角连营的战场。把烤牛肉分给部下，乐器演奏着边塞的军歌，秋天在战场上检阅军队。

战马像的卢一样飞快，弓弦像霹雳一样震响。完成了君王收复天下的大业，赢得了生前和死后的美名。可惜如今已经白发丛生！

## 赏析

这首词是辛弃疾寄给好友陈亮的壮词，通过回忆当年的军旅生活，表达了词人壮志难酬的悲愤之情。

上片写梦境中的军旅生活。"醉里挑灯看剑"，开篇就展现了一个壮志未酬的英雄形象。"梦回吹角连营"，写词人梦中回到了当年的军营。"八百里分麾下炙，五十弦翻塞外声，沙场秋点兵"，描绘了壮丽的军营生活场景，将士们分食烤肉，军乐激昂，秋天检阅军队，气势磅礴。

下片写战斗场面和壮志难酬的悲愤。"马作的卢飞快，弓如霹雳弦惊"，以夸张的手法写战斗的激烈。"了却君王天下事，赢得生前身后名"，写词人当年的雄心壮志。然而结尾"可怜白发生"一句，突然转折，将前面的豪情壮志全部打破，表达了词人壮志未酬、年华老去的悲愤。

全词气势磅礴，豪情万丈，结尾却陡然跌落，形成强烈的对比，将词人的爱国热情和壮志难酬的悲愤表现得淋漓尽致。

# 扬州慢·淮左名都

**[宋] [姜夔](/authors/jiangkui)**

## 原文

淮左名都，竹西佳处，解鞍少驻初程。过春风十里，尽荠麦青青。自胡马窥江去后，废池乔木，犹厌言兵。渐黄昏，清角吹寒，都在空城。

杜郎俊赏，算而今、重到须惊。纵豆蔻词工，青楼梦好，难赋深情。二十四桥仍在，波心荡、冷月无声。念桥边红药，年年知为谁生？

## 注释

- 扬州慢：词牌名，姜夔自创
- 淮左：淮河东面，宋代扬州属淮南东路
- 竹西：竹西亭，在扬州北门外
- 解鞍：下马休息
- 初程：旅途的第一段路程
- 春风十里：指扬州昔日繁华的街道，语出杜牧"春风十里扬州路"
- 荠麦：荠菜和麦子
- 胡马窥江：指金兵南侵
- 废池：废弃的池苑
- 乔木：高大的古树
- 厌言兵：厌恶谈论战争
- 清角：凄清的号角声
- 杜郎：指杜牧，唐代诗人，曾在扬州任职
- 俊赏：善于游赏
- 豆蔻：杜牧诗"娉娉袅袅十三余，豆蔻梢头二月初"
- 青楼梦：杜牧诗"十年一觉扬州梦，赢得青楼薄幸名"
- 二十四桥：扬州名胜
- 红药：红芍药

## 译文

淮南东路的名都扬州，竹西亭的佳美之处，我在旅途初段下马稍作停留。走过昔日春风十里的繁华街道，如今尽是青青的荠麦。自从金兵南侵之后，废弃的池苑、高大的古树，都厌恶谈论战争。渐渐到了黄昏，凄清的号角声在寒风中回荡，整个城市一片空寂。

杜牧当年善于游赏，算起来如果今天重到扬州，一定会感到震惊。纵然有写"豆蔻"的工巧词句，有"青楼梦"的曼妙情怀，也难以表达我此刻的深沉悲痛。二十四桥依然存在，水波荡漾，冷月无声。想那桥边的红芍药，年年盛开，又知道是为谁而生呢？

## 赏析

这首词是姜夔经过扬州时所作。当时扬州刚经历过金兵的劫掠，昔日繁华的名都变成了一片废墟。词人感时伤世，写下了这首沉痛悲凉的词作。

上片写扬州的残破景象。"淮左名都，竹西佳处"，先点出扬州昔日的繁华。但"过春风十里，尽荠麦青青"，昔日繁华的街道如今长满了野草，形成强烈的对比。"自胡马窥江去后，废池乔木，犹厌言兵"，连废弃的池苑和古树都厌恶战争，更何况人呢？"渐黄昏，清角吹寒，都在空城"，以凄清的号角声和空寂的城市，营造出悲凉的气氛。

下片借杜牧的典故抒发感慨。杜牧曾在扬州写下许多风流诗篇，但如果他今天重到扬州，一定会震惊于这里的残破。"纵豆蔻词工，青楼梦好，难赋深情"，再好的文才也难以表达此刻的悲痛。

"二十四桥仍在，波心荡、冷月无声"，二十四桥依旧，但已无人欣赏，只有冷月无声地映照在水中。"念桥边红药，年年知为谁生"，以问句作结，红芍药年年盛开，却无人欣赏，寄托了词人对国事的深切忧虑。

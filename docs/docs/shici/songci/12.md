# 卜算子·咏梅

**[宋] [陆游](/authors/luyou)**

## 原文

驿外断桥边，寂寞开无主。已是黄昏独自愁，更着风和雨。

无意苦争春，一任群芳妒。零落成泥碾作尘，只有香如故。

## 注释

- 卜算子：词牌名
- 驿：驿站
- 断桥：残破的桥
- 无主：无人过问
- 更着：又遭受
- 苦争春：苦苦与百花争春
- 一任：任凭
- 群芳：百花
- 妒：嫉妒
- 零落：凋谢
- 碾：轧碎
- 如故：依旧，仍然

## 译文

在驿站外的断桥边，梅花寂寞地开放，无人过问。已经是黄昏时分，独自忧愁，又遭受着风雨的摧残。

梅花无意苦苦与百花争春，任凭百花去嫉妒。即使凋谢落地，被轧碎成泥尘，只有那清香依旧如故。

## 赏析

这首词是陆游的代表作，以梅花自喻，表达了词人高洁不屈的品格和坚贞不渝的气节。

上片写梅花的孤独和艰难处境。"驿外断桥边，寂寞开无主"，写梅花生长在荒僻之地，无人欣赏。"已是黄昏独自愁，更着风和雨"，写梅花在黄昏时分独自忧愁，又遭受风雨的摧残。这里的梅花，正是词人自身的写照，暗示了词人在政治上的孤独和遭受的打击。

下片写梅花的高洁品格。"无意苦争春，一任群芳妒"，写梅花不与百花争艳，任凭百花嫉妒。这表现了词人不与世俗同流合污的高洁品格。"零落成泥碾作尘，只有香如故"，是全词的名句。即使梅花凋谢落地，被碾碎成泥尘，它的清香依旧不变。这表达了词人即使遭受打击、身处逆境，也绝不改变高洁品格的坚定信念。

全词托物言志，以梅花的高洁象征自己的品格，语言朴素，意境深远，是咏梅词中的千古绝唱。

# 苏幕遮·怀旧

**[宋] [范仲淹](/authors/fanzhongyan)**

## 原文

碧云天，黄叶地，秋色连波，波上寒烟翠。山映斜阳天接水，芳草无情，更在斜阳外。

黯乡魂，追旅思，夜夜除非，好梦留人睡。明月楼高休独倚，酒入愁肠，化作相思泪。

## 注释

- 苏幕遮：词牌名
- 碧云天：蓝天白云
- 寒烟翠：带着寒意的翠绿烟雾
- 山映斜阳：山峦映照在夕阳中
- 芳草无情：芳草不懂得人的情感
- 黯乡魂：因思念家乡而心神沮丧
- 追旅思：羁旅的愁思缠绕不休
- 除非：只有
- 好梦：美梦
- 愁肠：充满忧愁的心肠

## 译文

碧蓝的天空飘着白云，黄叶落满大地，秋色与江水相连，江面上笼罩着翠绿的寒烟。山峦映照着斜阳，天空与江水相接，那无情的芳草，一直延伸到斜阳之外。

思念家乡让人黯然神伤，羁旅的愁思日夜缠绕。每天晚上只有做好梦才能让人安睡。明月高照，不要独自倚靠高楼，酒入愁肠，都化作了相思的泪水。

## 赏析

这首词是范仲淹的代表作，表达了词人羁旅他乡时对故乡和亲人的深切思念。

上片写景，"碧云天，黄叶地"，以鲜明的色彩对比勾勒出秋日黄昏的壮阔景象。"秋色连波，波上寒烟翠"，将秋色、江水、寒烟融为一体，营造出一种苍茫而略带凄清的意境。"山映斜阳天接水"，写远山、斜阳、天空、江水交相辉映的宏阔画面。"芳草无情，更在斜阳外"，以芳草的无情反衬人的有情，那延伸到天涯的芳草，正如词人绵延不绝的乡愁。

下片抒情，"黯乡魂，追旅思"，直抒胸臆，点明主旨。"夜夜除非，好梦留人睡"，写词人因思乡而夜不能寐，只有在梦中才能暂时解脱。"明月楼高休独倚"，以劝诫的语气写独处高楼的孤寂。结尾"酒入愁肠，化作相思泪"，将借酒浇愁而愁更愁的情感推向高潮，以形象的比喻收束全词。

全词意境开阔，情感真挚，将壮阔的秋景与深挚的乡愁完美结合，是宋代羁旅词中的佳作。

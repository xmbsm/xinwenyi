# 清江引·秋居

**[元] [吴西逸](/authors/wuxiyi)**

## 原文

白雁乱飞秋似雪，清露生凉夜。扫却石边云，醉踏松根月。星斗满天人睡也。

## 注释

- 清江引：曲牌名
- 白雁：白色的雁
- 秋似雪：秋天的白雁像雪一样纷飞
- 清露：清凉的露水
- 扫却：拂去
- 石边云：石头边的云雾
- 松根月：松树根旁的月光

## 译文

白雁纷飞，如同秋天的白雪；清凉的露水使夜晚更加凉爽。拂去石头边的云雾，醉意中踏着松树根旁的月光。满天星斗，人儿安然入睡。

## 赏析

这首曲是吴西逸的代表作，描绘了秋日山居的闲适生活。

"白雁乱飞秋似雪"，以比喻开篇，写白雁纷飞如白雪，是秋日特有的景象。"清露生凉夜"，写秋夜的清凉，露水使空气更加清新。

"扫却石边云"，写拂去石头边的云雾，是山居生活的细节。"醉踏松根月"，写醉意中踏着月光，在松树下行走，意境优美而浪漫。

"星斗满天人睡也"，以宁静的夜晚作结。满天星斗，人儿安然入睡，是一种与世无争的闲适和自在。

全曲语言清丽，意境闲适，将秋日的山居生活描绘得如诗如画，是元代散曲中写隐逸生活的佳作。

# 水仙子·寻梅

**[元] [乔吉](/authors/qiaoji)**

## 原文

冬前冬后几村庄，溪北溪南两履霜，树头树底孤山上。冷风来何处香？忽相逢缟袂绡裳。酒醒寒惊梦，笛凄春断肠，淡月昏黄。

## 注释

- 水仙子：曲牌名
- 两履霜：双脚沾满霜雪
- 孤山：杭州西湖中的孤山，以梅花著名
- 缟袂：白色的衣袖，比喻梅花
- 绡裳：轻纱的衣裳，比喻梅花
- 酒醒寒惊梦：从醉梦中醒来，感到寒冷
- 笛凄：凄凉的笛声
- 淡月昏黄：淡淡的月光昏黄不明

## 译文

冬至前后，走过几个村庄；溪水南北，双脚沾满霜雪；在树头树底、孤山之上寻找。冷风吹来，何处有香气？忽然相逢那如白衣轻纱般的梅花。酒醒后寒意惊破梦境，凄凉的笛声令人断肠，淡淡的月光昏黄不明。

## 赏析

这首曲是乔吉的代表作，描绘了寻梅的过程和赏梅的感慨。

"冬前冬后几村庄，溪北溪南两履霜"，写寻梅的艰辛。冬至前后，走过多个村庄，溪水南北，双脚沾满霜雪，可见寻梅之不易。

"树头树底孤山上"，写寻梅的地点。孤山是杭州著名的赏梅胜地，词人在树头树底仔细寻找。"冷风来何处香"，以嗅觉写梅花的幽香，冷风中飘来淡淡的香气。

"忽相逢缟袂绡裳"，写终于找到梅花。以"缟袂绡裳"比喻梅花，形象优美。"酒醒寒惊梦，笛凄春断肠"，写赏梅时的复杂心情。酒醒后的寒冷、凄凉的笛声，都让人感到一种莫名的悲伤。

"淡月昏黄"，以景作结，淡淡的月光昏黄不明，正如词人朦胧的心境。

全曲语言清丽，意境优美，将寻梅的艰辛和赏梅的感慨完美地融为一体。

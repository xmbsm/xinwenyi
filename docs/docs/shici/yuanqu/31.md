# 殿前欢·懒云窝

**[元] [阿里西瑛](/authors/alixiying)**

## 原文

懒云窝，醒时诗酒醉时歌。瑶琴不理抛书卧，无梦南柯。得清闲尽快活。

## 注释

- 殿前欢：曲牌名
- 懒云窝：作者的书斋名
- 瑶琴：玉琴
- 抛书卧：扔下书躺下
- 南柯：南柯一梦，比喻富贵荣华如梦
- 清闲：清静闲适

## 译文

在懒云窝中，清醒时吟诗饮酒，醉后放声高歌。玉琴不理，扔下书躺下，不做那南柯美梦。得清闲就尽快活。

## 赏析

这首曲是阿里西瑛的代表作，表达了词人对清闲自在生活的追求。

"懒云窝，醒时诗酒醉时歌"，开篇即点明主题。懒云窝是作者的书斋，"醒时诗酒醉时歌"，写一种随性自在的生活状态，清醒时饮酒作诗，醉后放声高歌。

"瑶琴不理抛书卧"，写连瑶琴也懒得理会，扔下书便躺下，是一种彻底的放松。"无梦南柯"，写不做那富贵荣华的美梦，表达了对功名利禄的淡泊。

"得清闲尽快活"，以直白的语言作结，点明主旨：得到了清闲，就要尽情享受快活。这种率真坦荡的人生态度，是元代散曲中常见的主题。

全曲语言质朴，意境闲适，将词人对自由生活的向往表现得淋漓尽致。

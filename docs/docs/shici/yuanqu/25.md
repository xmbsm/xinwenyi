# 天净沙·冬

**[元] [白朴](/authors/baipu)**

## 原文

一声画角谯门，半庭新月黄昏，雪里山前水滨。竹篱茅舍，淡烟衰草孤村。

## 注释

- 画角：军中乐器，声音凄厉
- 谯门：城门上的瞭望楼
- 半庭：半个庭院
- 水滨：水边
- 竹篱：竹编的篱笆
- 茅舍：茅草屋
- 衰草：枯萎的草

## 译文

城门谯楼上一声画角吹响，半个庭院照着新月的黄昏，山前水边一片白雪。竹篱围着的茅屋，淡淡炊烟中，枯草覆盖的孤村。

## 赏析

这首曲是白朴《天净沙》四季组曲中的第四首，描绘了冬日黄昏的萧瑟景象。

"一声画角谯门"，以凄厉的画角声开篇，营造出冬日的肃杀氛围。"半庭新月黄昏"，写黄昏时分，新月升起，庭院半明半暗。"雪里山前水滨"，写白雪覆盖的山前水边，一片苍茫。

"竹篱茅舍，淡烟衰草孤村"，以简练的笔触勾勒出冬日乡村的景象。竹篱、茅舍、淡烟、衰草、孤村，这些意象叠加在一起，构成一幅凄清而宁静的冬景图。

全曲语言凝练，意境萧瑟，与马致远《天净沙·秋思》有异曲同工之妙，但更加含蓄内敛，体现了白朴散曲清丽冷峻的风格。

# 塞鸿秋·浔阳即景

**[元] [周德清](/authors/zhoudqing)**

## 原文

长江万里白如练，淮山数点青如淀。
江帆几片疾如箭，山泉千尺飞如电。
晚云都变露，新月初学扇。
塞鸿一字来如线。

## 注释

- 塞鸿秋：曲牌名
- 浔阳：今江西九江
- 练：白色的丝绸
- 淮山：指江淮一带的山
- 淀：同「靛」，深蓝色的染料
- 江帆：江上的船帆
- 疾如箭：形容船行迅速
- 飞如电：形容瀑布飞流直下
- 变露：凝结成露水
- 学扇：像扇子一样，指新月如扇
- 塞鸿：塞外飞来的大雁
- 一字：雁群飞行时排成一字形

## 译文

万里长江白如素练，淮山数点青如靛蓝。江上船帆几片疾如飞箭，山泉千尺飞流如电。晚云都凝结成露水，新月弯弯如扇。塞外大雁排成一字飞来，细如丝线。

## 赏析

这首曲是周德清的代表作，描绘了浔阳一带的壮丽景色，是一幅色彩鲜明、动静结合的山水画卷。

全曲七句，每句都用了比喻，形成了独特的艺术效果。"长江万里白如练"，写长江的绵长和洁白；"淮山数点青如淀"，写远山的青翠。一白一青，色彩对比鲜明。"江帆几片疾如箭"，写动态的船帆；"山泉千尺飞如电"，写动态的瀑布。一上一下，动静结合。

"晚云都变露"，写傍晚云气凝结成露，是细微的变化。"新月初学扇"，写新月如扇，形状优美。"塞鸿一字来如线"，写大雁南飞，排成一字，细如丝线，在广阔的天空中显得格外醒目。

全曲语言凝练，比喻精妙，色彩鲜明，层次分明，是元代散曲中写景的佳作。

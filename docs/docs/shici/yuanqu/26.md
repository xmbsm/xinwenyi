# 沉醉东风·秋景

**[元] [卢挚](/authors/luzhi)**

## 原文

挂绝壁松枯倒倚，落残霞孤鹜齐飞。四围不尽山，一望无穷水。散西风满天秋意。夜静云帆月影低，载我在潇湘画里。

## 注释

- 沉醉东风：曲牌名
- 绝壁：陡峭的山崖
- 倒倚：倒挂着
- 残霞：夕阳的余晖
- 孤鹜：孤单的野鸭
- 四围：四周
- 不尽：绵延不绝
- 云帆：船帆
- 潇湘：潇水和湘水，借指江南美景

## 译文

枯松倒挂在陡峭的山崖上，落霞与孤鹜一起飞翔。四周是绵延不绝的山峦，一眼望去是无穷无尽的水面。西风吹散，满天都是秋意。夜深人静，云帆低垂，月影映在水中，载着我仿佛行在潇湘画卷之中。

## 赏析

这首曲是卢挚的代表作，描绘了秋日江行的壮丽景色。

"挂绝壁松枯倒倚"，以奇特的视角写山崖上的枯松，给人以险峻之感。"落残霞孤鹜齐飞"，化用王勃"落霞与孤鹜齐飞"的名句，写秋日黄昏的美景。

"四围不尽山，一望无穷水"，以宏大的视野写山水之壮阔。"散西风满天秋意"，以秋风为媒介，将秋意洒满天空。

"夜静云帆月影低，载我在潇湘画里"，以宁静的夜晚作结。云帆低垂，月影映水，诗人仿佛行在一幅潇湘画卷之中。这一结尾将实景与想象融为一体，意境优美。

全曲语言清丽，意境开阔，是元代散曲中写景的佳作。

# 水仙子·咏江南

**[元] [张养浩](/authors/zhangyanghao)**

## 原文

一江烟水照晴岚，两岸人家接画檐，芰荷丛一段秋光淡。看沙鸥舞再三，卷香风十里珠帘。画船儿天边至，酒旗儿风外飐。爱杀江南！

## 注释

- 水仙子：曲牌名
- 晴岚：晴日山间的雾气
- 画檐：装饰华丽的屋檐
- 芰荷：菱叶和荷叶
- 秋光淡：秋天的光线柔和淡雅
- 沙鸥：水鸟
- 卷香风：带着香气的风
- 珠帘：珍珠装饰的帘子
- 画船：装饰华丽的船
- 酒旗：酒店的旗帜
- 风外飐：在风中飘动
- 爱杀：爱极了

## 译文

一江烟水映照着晴日的山岚，两岸的人家连接着华丽的屋檐，菱叶荷叶丛中透出一段淡雅的秋光。看沙鸥翩翩起舞，带着香气的风卷起十里的珠帘。装饰华丽的船从天边驶来，酒店的旗帜在风中飘动。爱极了这江南！

## 赏析

这首小令是张养浩的代表作，描绘了江南水乡的美丽景色，表达了作者对江南的赞美之情。

"一江烟水照晴岚，两岸人家接画檐"，开篇就勾勒出一幅江南水乡的全景图。烟水、晴岚、人家、画檐，将江南的秀美描绘得淋漓尽致。

"芰荷丛一段秋光淡"，写秋天的江南。菱叶荷叶丛中，透出淡雅的秋光，将江南的秋景描绘得清新脱俗。

"看沙鸥舞再三，卷香风十里珠帘"，写江南的动态美。沙鸥起舞，香风卷帘，将江南的生机和灵动表现得生动传神。

"画船儿天边至，酒旗儿风外飐"，写江南的人文景观。画船从远处驶来，酒旗在风中飘动，将江南的繁华和诗意融为一体。

"爱杀江南！"，以感叹作结，直抒胸臆，表达了作者对江南的无限热爱。

全曲语言清丽，意境优美，将江南水乡的自然美和人文美完美融合，是咏江南的千古名篇。

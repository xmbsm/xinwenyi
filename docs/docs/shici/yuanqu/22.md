# 普天乐·西山夕照

**[元] [徐再思](/authors/xuzaisi)**

## 原文

晚云收，夕阳挂，一川枫叶，两岸芦花。
鸥鹭栖，牛羊下，万顷波光天图画。
水晶宫冷浸红霞，凝烟暮景，转晖老树，背影昏鸦。

## 注释

- 普天乐：曲牌名
- 西山：北京西郊的山
- 晚云收：傍晚的云彩散去
- 夕阳挂：夕阳悬挂西天
- 一川：一片
- 芦花：芦苇花
- 牛羊下：牛羊归圈，语出《诗经》
- 万顷：形容水面广阔
- 天图画：天然的图画
- 水晶宫：指水中的宫殿，比喻湖水清澈
- 冷浸：清凉地映照
- 凝烟：凝聚的烟雾
- 转晖：夕阳的余晖
- 背影：背对着夕阳的影子
- 昏鸦：黄昏时的乌鸦

## 译文

傍晚的云彩散去，夕阳悬挂西天。一片枫叶红遍，两岸芦花如雪。鸥鹭栖息，牛羊归圈，万顷波光如天然的图画。湖水清澈如水晶宫，清凉地映照着红霞。暮霭凝烟，夕阳余晖转向老树，昏鸦背着夕阳的影子。

## 赏析

这首曲是徐再思写景之作，描绘了西山夕照的壮丽景色，是一幅色彩绚丽的秋日黄昏图。

"晚云收，夕阳挂"，开篇即点明时间和景象，云散日出，夕阳高挂。"一川枫叶，两岸芦花"，写秋天的特色景物，枫叶红、芦花白，色彩对比鲜明。"鸥鹭栖，牛羊下"，写动物归巢，增添了生机。"万顷波光天图画"，以比喻总写湖光山色之美。

"水晶宫冷浸红霞"，写湖水清澈，倒映着红霞，如水晶宫般美丽。"凝烟暮景，转晖老树，背影昏鸦"，以细腻的笔触描绘暮景：烟雾凝聚，夕阳余晖转向老树，昏鸦背着夕阳的影子。这一画面既有色彩，又有动感，将黄昏的景色描绘得如诗如画。

全曲语言清丽，色彩鲜明，层次分明，是元代散曲中写景的佳作。

# 寿阳曲·潇湘夜雨

**[元] [马致远](/authors/mazhiyuan)**

## 原文

渔灯暗，客梦回。一声声滴人心碎。孤舟五更家万里，是离人几行情泪。

## 注释

- 寿阳曲：曲牌名
- 潇湘：潇水和湘水，在今湖南
- 渔灯：渔船上的灯火
- 客梦：游子的梦
- 五更：凌晨时分
- 离人：离别的人

## 译文

渔船上的灯火昏暗，游子从梦中醒来。夜雨一声声滴落，让人心碎。孤舟漂泊，五更时分，离家万里，这雨正是离人几行伤心的眼泪。

## 赏析

这首曲是马致远《寿阳曲》组曲中的一首，描绘了潇湘夜雨中的羁旅之愁。

"渔灯暗，客梦回"，开篇即营造出孤寂的氛围。昏暗的渔灯，游子的梦醒，暗示了漂泊的孤独。"一声声滴人心碎"，写夜雨声声，每一声都滴在离人的心上，让人心碎。

"孤舟五更家万里"，写五更时分，孤舟漂泊，离家万里。"是离人几行情泪"，以比喻作结，将夜雨比作离人的眼泪，既形象又感人。

全曲语言简练，意境凄清，将夜雨、孤舟、离愁完美地融为一体，是马致远散曲中写羁旅之愁的代表作。

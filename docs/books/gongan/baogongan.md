# 包公案

## 作品简介

《包公案》，明代的公案小说，讲述包拯破案的故事。包拯（999年－1062年），字希仁，庐州合肥（今安徽合肥）人，北宋名臣。因曾任天章阁待制、龙图阁直学士，故世称"包待制"、"包龙图"。

包拯廉洁公正、立朝刚毅，不附权贵，铁面无私，且英明决断，敢于替百姓申不平，故有"包青天"及"包公"之名，京师有"关节不到，有阎罗包老"之语。后世将他奉为神明崇拜，认为他是文曲星转世，由于民间传其黑面形象，亦被称为"包青天"。

## 文学价值

《包公案》是中国古代公案小说的代表作之一。小说通过一系列案件的侦破，展现了包拯清正廉洁、刚正不阿、执法如山的形象，表达了人民对清官的期盼和对正义的向往。该书对後世的公案小说、戏曲、民间故事都产生了深远的影响。

## 第一回 判焚永州之野庙

话说包拯初任开封府尹，一日，出巡永州。永州地方，山多田少，民风淳朴。包拯到任後，先访民间疾苦，後审积年案卷。闻说永州城外有一野庙，香火甚盛，但常有怪异之事发生，包拯决定前往查看。

这日，包拯带了两名随从，来到野庙。只见庙宇虽不大，但收拾得整齐干净。殿上供着一尊神像，面目狰狞，令人望而生畏。包拯细看那神像，觉得有些蹊跷，便问庙祝："这供的是何方神圣？"庙祝答道："回老爷，这是本地的山神，灵验得很，四方百姓都来祈福求安。"

包拯点点头，在庙中四处查看。走到後殿，只见墙角堆着些干草，草中似乎藏着什么东西。包拯命随从拨开干草，只见草下藏着几具白骨！包拯大惊，立即命人封锁庙宇，将庙祝拿下审问。

原来，这庙祝并非真正的出家人，而是一个杀人越货的强盗。他借山神之名，诱骗过往行人到庙中住宿，夜间将其杀害，劫取财物，尸体就藏在後殿的干草之下。几年来，已有数十人遭其毒手。包拯查明真相，依法将庙祝斩首示众，为死者昭雪。

## 作品评价

《包公案》通过一系列曲折离奇的案件，展现了包拯的智慧和正义。小说情节紧凑，悬念迭起，既有公案小说的推理色彩，又有传奇小说的神异色彩。包拯这一形象，成为中国文化中清官的典范，影响深远。

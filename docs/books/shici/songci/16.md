# 鹊桥仙·纤云弄巧

**[宋] [秦观](/authors/qinguan)**

## 原文

纤云弄巧，飞星传恨，银汉迢迢暗度。金风玉露一相逢，便胜却人间无数。

柔情似水，佳期如梦，忍顾鹊桥归路。两情若是久长时，又岂在朝朝暮暮。

## 注释

- 鹊桥仙：词牌名，取材于牛郎织女七夕相会的传说
- 纤云弄巧：纤细的云彩变幻出巧妙的图案
- 飞星：流星
- 银汉：银河
- 迢迢：遥远的样子
- 暗度：悄悄渡过
- 金风玉露：秋风白露，指七夕时节
- 忍顾：不忍心回头看
- 鹊桥：传说喜鹊为牛郎织女搭的桥
- 朝朝暮暮：日日夜夜

## 译文

纤细的云彩变幻出巧妙的图案，飞驰的流星传递着离愁别恨。牛郎织女 tonight 悄悄地渡过遥远的银河。在秋风白露的七夕之夜相逢一次，便胜过人间无数次的相聚。

柔情像水一样缠绵，美好的相会如梦一般短暂。怎么忍心回头看那鹊桥归路呢？两情若是能够长久不变，又何必在乎朝朝暮暮的相守呢？

## 赏析

这首词是秦观的代表作，以牛郎织女的传说为题材，歌颂了真挚而坚贞的爱情。

上片写牛郎织女相会的情景。"纤云弄巧，飞星传恨"，以细腻的笔触描绘出七夕夜空的美景，云彩变幻、流星飞逝，都似乎在为他们传递情意。"银汉迢迢暗度"，点明相会的艰难。"金风玉露一相逢，便胜却人间无数"，是千古名句，以高远的立意赞美了这种超越世俗的爱情。

下片写离别时的不舍和对爱情的深刻思考。"柔情似水，佳期如梦"，以比喻手法写出相聚的甜蜜与短暂。"忍顾鹊桥归路"，写离别时的依依不舍。结尾"两情若是久长时，又岂在朝朝暮暮"，是全词的点睛之笔，以议论入词，升华了主题：真正的爱情不在于朝夕相守，而在于心灵的永恒相守。这一观点突破了传统爱情词的缠绵悱恻，展现出一种旷达的爱情观。

全词意境优美，立意高远，是七夕词中的千古绝唱。

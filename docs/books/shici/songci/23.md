# 念奴娇·过洞庭

**[宋] [张孝祥](/authors/zhangxiaoxiang)**

## 原文

洞庭青草，近中秋，更无一点风色。玉鉴琼田三万顷，着我扁舟一叶。素月分辉，明河共影，表里俱澄澈。悠然心会，妙处难与君说。

应念岭海经年，孤光自照，肝胆皆冰雪。短发萧骚襟袖冷，稳泛沧浪空阔。尽挹西江，细斟北斗，万象为宾客。扣舷独啸，不知今夕何夕！

## 注释

- 念奴娇：词牌名
- 洞庭青草：洞庭湖和青草湖，在湖南岳阳
- 玉鉴：玉镜，比喻湖水
- 琼田：玉田，比喻湖面
- 素月：明月
- 明河：银河
- 表里：内外
- 岭海：指岭南地区，今广东广西一带
- 孤光自照：以孤光比喻自己的高洁品格
- 肝胆皆冰雪：比喻心地纯洁、襟怀坦白
- 萧骚：稀疏的样子
- 尽挹：舀尽
- 西江：长江
- 细斟北斗：用北斗七星作酒器斟酒
- 万象：天地万物
- 扣舷：敲击船边
- 今夕何夕：语出《诗经》，表示这是一个多么美好的夜晚

## 译文

洞庭湖和青草湖，时近中秋，湖面上没有一丝风，平静无波。如玉镜琼田般的湖面有三万顷，承载着我这一叶扁舟。明月洒下光辉，银河倒映湖中，内外一片澄澈。我悠然心领神会这美妙之处，却难以用言语向你诉说。

回想在岭南度过的岁月，孤光自照，肝胆都如冰雪般纯洁。短发稀疏，衣襟袖间感到微冷，稳稳地泛舟于这空阔的沧浪之中。我要舀尽西江之水，用北斗七星作勺细斟，邀请天地万物作宾客。敲击船舷独自长啸，不知今夜是何年何夕！

## 赏析

这首词是张孝祥被贬岭南北归途中，经过洞庭湖时所作。全词以澄澈的湖光月色为背景，表达了词人高洁的人格和旷达的胸怀。

上片写景，"洞庭青草，近中秋，更无一点风色"，点明时间地点，湖面平静如镜。"玉鉴琼田三万顷，着我扁舟一叶"，以宏大的湖面衬托扁舟之小，但词人却感到自在从容。"素月分辉，明河共影，表里俱澄澈"，写月光、银河与湖水交相辉映，内外澄澈。这一景象既是写实，也是词人内心世界的写照。

下片抒情，"应念岭海经年，孤光自照，肝胆皆冰雪"，回顾被贬岭南的经历，以"肝胆皆冰雪"比喻自己的高洁品格。"短发萧骚襟袖冷"，写外貌的憔悴，但"稳泛沧浪空阔"，却表现出内心的从容。

"尽挹西江，细斟北斗，万象为宾客"，是千古名句。词人想象舀尽西江之水，用北斗作勺，邀请天地万物共饮，气魄宏大，想象奇特。"扣舷独啸，不知今夕何夕"，以豪放的动作和感叹作结，将词人的旷达情怀推向高潮。

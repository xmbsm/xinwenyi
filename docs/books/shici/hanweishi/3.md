# 龟虽寿

**[汉] [曹操](/authors/caocao)**

## 原文

神龟虽寿，犹有竟时。
腾蛇乘雾，终为土灰。
老骥伏枥，志在千里。
烈士暮年，壮心不已。
盈缩之期，不但在天；
养怡之福，可得永年。
幸甚至哉，歌以咏志。

## 注释

- 神龟：传说中长寿的龟
- 寿：长寿
- 竟：终结，这里指死亡
- 腾蛇：传说中能腾云驾雾的神蛇
- 骥：良马
- 枥：马槽
- 烈士：有雄心壮志的人
- 暮年：晚年
- 不已：不停止
- 盈缩：指人的寿命长短
- 养怡：调养身心，保持心情愉快
- 永年：长寿

## 译文

神龟虽然长寿，也有生命终结的时候。
腾蛇即使能乘雾飞行，最终也会化为土灰。
年老的千里马虽然伏在马槽旁，它的志向仍是驰骋千里。
有雄心壮志的人即使到了晚年，奋发进取的心也不会停止。
人的寿命长短，不只由上天决定；
调养身心保持愉悦，就可以延年益寿。
庆幸得很啊，用歌声来表达我的心志。

## 赏析

《龟虽寿》是曹操《步出夏门行》组诗的第四章，作于建安十二年（207年）北征乌桓胜利之后。此时曹操已五十三岁，面对人生暮年，他写下这首充满积极进取精神的诗篇。

诗的前四句以神龟、腾蛇为喻，说明世间万物皆有生死，即使是传说中的长寿之物也难免一死。这是诗人对生命规律的清醒认识。但诗人并未因此消沉，反而以"老骥伏枥，志在千里；烈士暮年，壮心不已"四句，表达了不服老、不放弃的昂扬斗志。这四句成为千古传诵的名句，激励着无数后人在逆境中奋发向上。

"盈缩之期，不但在天；养怡之福，可得永年"，诗人进一步表达了人定胜天的思想，认为人的寿命不仅由天命决定，更在于自身的调养和心态。这种积极乐观的人生态度，在当时的时代背景下尤为可贵。

全诗充满辩证思维，既承认生命的有限，又强调精神追求的无限；既尊重自然规律，又主张发挥人的主观能动性。这种积极进取、自强不息的精神，正是建安风骨的核心内涵。

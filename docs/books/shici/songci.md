# 宋词三百首

## 简介

《宋词三百首》是清代朱孝臧编选的宋词选集。朱孝臧（1857年—1931年），原名祖谋，字藿生，一字古微，号沤尹，又号彊村，浙江归安（今湖州）人。光绪九年（1883年）进士，官至礼部右侍郎。工诗词，为清末四大词家之一。

宋词是继唐诗之后的又一文学高峰，分为豪放派和婉约派，展现了宋代文人的情感世界和艺术追求。宋词在形式上突破了唐诗的格律限制，采用长短句的形式，更加灵活自由，能够更好地表达复杂的情感。

## 编选特点

《宋词三百首》的编选特点：

1. **选目精当**：所选词作都是宋词中的精华，代表了宋词的最高成就
2. **风格多样**：既有豪放派的苏轼、辛弃疾，又有婉约派的李清照、柳永
3. **题材广泛**：涵盖咏史怀古、山水田园、爱情闺怨、送别赠答等各种题材
4. **便于学习**：篇幅适中，注释简明，非常适合初学者入门

### 念奴娇·赤壁怀古

**苏轼**

大江东去，浪淘尽，千古风流人物。
故垒西边，人道是，三国周郎赤壁。
乱石穿空，惊涛拍岸，卷起千堆雪。
江山如画，一时多少豪杰。

遥想公瑾当年，小乔初嫁了，雄姿英发。
羽扇纶巾，谈笑间，樯橹灰飞烟灭。
故国神游，多情应笑我，早生华发。
人生如梦，一尊还酹江月。

寻寻觅觅，冷冷清清，凄凄惨惨戚戚。

**柳永**

寒蝉凄切，对长亭晚，骤雨初歇。
都门帐饮无绪，留恋处，兰舟催发。
执手相看泪眼，竟无语凝噎。
念去去，千里烟波，暮霭沉沉楚天阔。

多情自古伤离别，更那堪，冷落清秋节！
今宵酒醒何处？杨柳岸，晓风残月。
此去经年，应是良辰好景虚设。

## 影响与评价

宋词是中国文学史上的一座高峰，与唐诗并称"唐诗宋词"，代表了中国古典诗歌的最高成就。宋词在形式上突破了唐诗的格律限制，采用长短句的形式，更加灵活自由，能够更好地表达复杂的情感。在内容上，宋词题材广泛，风格多样，既有豪放派的慷慨激昂，又有婉约派的缠绵悱恻，展现了宋代文人的情感世界和艺术追求。

《宋词三百首》作为宋词选本的代表，自问世以来一直受到读者的喜爱，成为学习宋词的必读之书。该书不仅为读者提供了一个了解宋词的窗口，也成为中国古典文学教育的重要教材。

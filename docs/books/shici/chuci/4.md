# 天问

**[战国] [屈原](/authors/quyuan)**

## 原文

曰：遂古之初，谁传道之？
上下未形，何由考之？
冥昭瞢暗，谁能极之？
冯翼惟象，何以识之？
明明暗暗，惟时何为？
阴阳三合，何本何化？

圜则九重，孰营度之？
惟兹何功，孰初作之？
斡维焉系，天极焉加？
八柱何当，东南何亏？
九天之际，安放安属？
隅隈多有，谁知其数？

## 注释

- **天问**：对天发问，即向苍天提出疑问。这是屈原创作的一首奇特的长诗，全诗共提出一百七十多个问题。
- **曰**：发语词，一说指屈原自称，或指提问的开始。
- **遂古**：远古。遂，通"邃"，深远。
- **初**：开端。
- **传道**：传说，流传。
- **上下**：指天地。
- **未形**：尚未形成形体。
- **何由**：根据什么。
- **考**：考察，推究。
- **冥昭瞢暗**：昼夜未分，混沌不明的样子。冥，幽暗。昭，明亮。瞢暗，混沌不清。
- **极**：穷究，探求到底。
- **冯翼**：大气充盛弥漫的样子。冯，通"凭"，满。翼，盛。
- **惟象**：只有景象，无形无象。
- **识**：辨识，认识。
- **明明暗暗**：昼夜交替，明暗变化。
- **惟时何为**：这是为了什么。时，通"是"，此。
- **阴阳**：中国古代哲学概念，指宇宙间两种对立统一的基本力量。
- **三合**：三，指天、地、人；合，配合。一说指阴阳与气三者结合。
- **何本何化**：什么是本源，什么是变化。本，根本。化，化生。
- **圜**：同"圆"，指天。古人认为天圆地方。
- **九重**：九层。古人传说天有九层。
- **孰**：谁。
- **营度**：经营度量，规划测量。
- **惟兹何功**：这是何等功业。兹，此，指九重天。
- **初作**：最初建造。
- **斡**：旋转的枢纽，指天体旋转的轴心。
- **维**：维系，指系天的大绳。古人认为天由大绳维系。
- **焉系**：系在哪里。
- **天极**：天的顶端，北极星所在。
- **焉加**：架在哪里。加，放置，架设。
- **八柱**：支撑天的八根柱子。古代神话传说有八座山作为擎天柱。
- **何当**：在何处承当。当，承当，支撑。
- **东南何亏**：东南方为什么缺损。古代传说共工怒触不周山，天倾西北，地不满东南。
- **九天**：古人将天分为九层，中央钧天，东方苍天，东北变天，北方玄天，西北幽天，西方颢天，西南朱天，南方炎天，东南阳天。
- **际**：边界。
- **安放**：安置在何处。
- **安属**：连接在何处。属，连接。
- **隅隈**：角落和弯曲的地方。隅，角落。隈，弯曲处。
- **谁知其数**：谁能知道它们的数目。

## 译文

请问：远古的开端，是谁将它传述下来？
天地尚未形成，根据什么来考察推究？
昼夜混沌不分，谁能穷究它的道理？
大气弥漫只有景象，凭什么来辨识认识？
明暗交替变化，这一切是为了什么？
阴阳与天地人三者配合，什么是本源什么是化生？

天是圆的且有九重，是谁经营度量它？
这是何等伟大的功业，是谁最初建造的？
旋转的轴心和维系的大绳系在何处？
天的顶端架设在何处？
八根天柱支撑在何处？
东南方为什么缺损？
九天的边界，安置在哪里？连接在何处？
角落和弯曲之处如此众多，谁能知道它们的数目？

## 赏析

《天问》是屈原创作的一首极其独特的长诗，全诗三百七十余句，提出了一百七十多个问题，从天地开辟、宇宙生成，到神话传说、历史兴衰，无所不问，气势磅礴，构思奇特，是中国文学史上一部空前绝后的作品。

诗以"曰"字开篇，连续发问，开篇即追问宇宙的起源："遂古之初，谁传道之？上下未形，何由考之？"诗人对远古混沌初开、天地未形的状态提出质疑，对阴阳变化、三才配合的本源进行追问，表现出强烈的探索精神和理性思辨色彩。

第二段转向对天体结构的追问："圜则九重，孰营度之？""斡维焉系，天极焉加？"诗人对天有九重、八柱擎天、天倾东南等神话传说提出一连串疑问，表现出不盲从传统、勇于质疑的科学精神。这些问题涉及天文学、宇宙论，在先秦时期具有极高的思想价值。

《天问》的独特之处在于：它通篇只有问句，没有答语；它不问人事而先问天地，体现了屈原宏大的宇宙意识；它质疑神话传说，表现出理性批判精神。全诗气势磅礴，句式整齐，四言为主，节奏鲜明，具有独特的艺术魅力。

此诗不仅是中国文学史上的奇篇，也是思想史上的杰作。它反映了屈原对自然、历史、人生的深刻思考，体现了他追求真理、探索未知的精神品格。后世李白、柳宗元等诗人皆受其影响，柳宗元更作《天对》以答屈原之问，成为中国思想史上的一段佳话。

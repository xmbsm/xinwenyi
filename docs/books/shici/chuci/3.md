# 九歌·山鬼

**[战国] [屈原](/authors/quyuan)**

## 原文

若有人兮山之阿，被薜荔兮带女萝。
既含睇兮又宜笑，子慕予兮善窈窕。
乘赤豹兮从文狸，辛夷车兮结桂旗。
被石兰兮带杜衡，折芳馨兮遗所思。

余处幽篁兮终不见天，路险难兮独后来。
表独立兮山之上，云容容兮而在下。
杳冥冥兮羌昼晦，东风飘兮神灵雨。
留灵修兮憺忘归，岁既晏兮孰华予？

采三秀兮于山间，石磊磊兮葛蔓蔓。
怨公子兮怅忘归，君思我兮不得闲。
山中人兮芳杜若，饮石泉兮荫松柏，
君思我兮然疑作。

雷填填兮雨冥冥，猨啾啾兮狖夜鸣。
风飒飒兮木萧萧，思公子兮徒离忧。

## 注释

- **山鬼**：山中的女神，一说为山神。楚地多山，民间信仰山神，此为祭祀山神的乐歌。
- **若有人**：仿佛有人，形容山鬼若隐若现的姿态。
- **山之阿**：山的弯曲处，山隅。
- **被**：同"披"，披在身上。
- **薜荔**：一种蔓生香草，又称木莲。
- **带**：以……为带。
- **女萝**：一种攀援植物，即松萝。
- **含睇**：含情微视。睇，微微斜视，形容美目流盼。
- **宜笑**：笑起来很好看。
- **子**：你，指山鬼所爱慕的人。
- **慕**：爱慕。
- **予**：我，山鬼自称。
- **善**：善于，显得。
- **窈窕**：美好的样子，形容体态优美。
- **赤豹**：红色的豹子。传说山鬼乘赤豹。
- **从**：使……跟从。
- **文狸**：有花纹的野猫。狸，野猫。
- **辛夷车**：用辛夷木做的车。辛夷，香木名，即木兰。
- **结**：编结。
- **桂旗**：用桂树枝做的旗帜。
- **石兰**：香草名，即山兰。
- **杜衡**：香草名。
- **芳馨**：芳香的花朵。馨，散布很远的香气。
- **遗**：赠送。
- **所思**：所思念的人。
- **余**：我，山鬼自称。
- **幽篁**：幽深的竹林。篁，竹林。
- **险难**：艰险难行。
- **独后来**：独自来迟。
- **表**：突出地，高高地。
- **独立**：独自站立。
- **容容**：云气浮动的样子。
- **杳冥冥**：幽暗深远的样子。
- **羌**：楚地方言，句首语气词。
- **昼晦**：白天昏暗。
- **飘**：吹动。
- **神灵雨**：神灵降下的雨。
- **留**：挽留，等待。
- **灵修**：指山鬼所思念的人。灵修本为神明之称，此处指所思之人。
- **憺**：安然，安乐。
- **岁既晏**：年岁已晚。晏，晚，迟。
- **孰华予**：谁能使我青春常驻。华，同"花"，使……如花般美丽。
- **三秀**：灵芝草的别名。灵芝一年开花三次，故称三秀。
- **磊磊**：石头堆积的样子。
- **葛**：葛藤。
- **蔓蔓**：蔓延的样子。
- **公子**：指山鬼所思念的人。
- **怅**：惆怅。
- **君**：你，指所思之人。
- **山中人**：山鬼自称。
- **芳杜若**：像杜若一样芬芳。
- **石泉**：山石间的泉水。
- **荫**：遮蔽。
- **然疑作**：信疑交加。然，相信。疑，怀疑。
- **填填**：雷声轰鸣的样子。
- **冥冥**：昏暗的样子。
- **猨**：同"猿"，猿猴。
- **啾啾**：猿猴的哀鸣声。
- **狖**：一种长尾猿。
- **飒飒**：风声。
- **萧萧**：草木摇落的声音。
- **徒**：白白地。
- **离忧**：遭受忧愁。离，同"罹"，遭受。

## 译文

仿佛有人啊在山弯深处，身披薜荔啊腰系女萝。
含情微视啊笑靥动人，你爱慕我啊我姿态窈窕。
乘坐赤豹啊花纹野猫跟随，辛夷木车啊桂树枝旗。
身披石兰啊腰系杜衡，折取芳香啊送给所思之人。

我身处幽深竹林啊终日不见天日，道路艰险啊我独来迟。
高高独立啊在山巅之上，云气浮动啊在我脚下。
幽暗深远啊白昼如晦，东风飘拂啊神灵降雨。
等待灵修啊安然忘归，年岁已晚啊谁使我青春常驻？

采摘灵芝啊在山间，石头堆积啊葛藤蔓延。
怨恨公子啊惆怅忘归，你想念我啊却不得空闲。
山中之人啊芬芳如杜若，饮用石泉啊松柏遮荫，
你想念我啊我又信又疑。

雷声轰鸣啊大雨冥冥，猿猴啾啾啊狖猴夜鸣。
风声飒飒啊木叶萧萧，思念公子啊白白忧愁。

## 赏析

《九歌·山鬼》是屈原《九歌》组诗中的名篇，是祭祀山神的乐歌。关于"山鬼"的身份，历来有不同说法，或以为是山神，或以为是巫山神女。从诗的内容来看，诗人塑造了一位美丽多情、纯洁忠贞的山中女神形象，她深情地等待所思之人的到来，却终究失望而归。

全诗以山鬼的口吻展开，首段描绘山鬼的装束与风姿：身披薜荔、腰系女萝，乘坐赤豹、文狸相随，辛夷为车、桂旗招展，石兰为衣、杜衡为带，一派山野仙姿。"既含睇兮又宜笑"一句，将山鬼的妩媚多情刻画得栩栩如生。

第二段写山鬼赴约的艰辛与等待的执着。她身处幽篁，路险来迟，独立山巅，云气在脚下浮动，白昼如晦，风雨交加，却依然"留灵修兮憺忘归"，甘愿等待。"岁既晏兮孰华予"一句，流露出对青春流逝的焦虑与对爱情的渴望。

第三段写山鬼的疑虑与哀怨。她采摘灵芝，却见"石磊磊兮葛蔓蔓"，道路阻隔；她怨恨公子不来，却又自我安慰"君思我兮不得闲"，最后陷入"然疑作"的矛盾心理，真实而动人。

末段以景结情，"雷填填兮雨冥冥，猨啾啾兮狖夜鸣。风飒飒兮木萧萧"，以凄风苦雨、猿啼枭鸣的悲凉景象，烘托出山鬼"思公子兮徒离忧"的无限惆怅。全诗情景交融，人神相恋的题材在屈原笔下写得缠绵悱恻、凄婉动人，是中国古代浪漫主义诗歌的杰作。

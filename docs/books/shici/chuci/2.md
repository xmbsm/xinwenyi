# 九歌·湘夫人

**[战国] [屈原](/authors/quyuan)**

## 原文

帝子降兮北渚，目眇眇兮愁予。
袅袅兮秋风，洞庭波兮木叶下。
登白薠兮骋望，与佳期兮夕张。
鸟何萃兮蘋中，罾何为兮木上？

沅有芷兮澧有兰，思公子兮未敢言。
荒忽兮远望，观流水兮潺湲。
麋何食兮庭中？蛟何为兮水裔？
朝驰余马兮江皋，夕济兮西澨。
闻佳人兮召予，将腾驾兮偕逝。

筑室兮水中，葺之兮荷盖。
荪壁兮紫坛，播芳椒兮成堂。
桂栋兮兰橑，辛夷楣兮药房。
罔薜荔兮为帷，擗蕙櫋兮既张。
白玉兮为镇，疏石兰兮为芳。
芷葺兮荷屋，缭之兮杜衡。

合百草兮实庭，建芳馨兮庑门。
九嶷缤兮并迎，灵之来兮如云。
捐余袂兮江中，遗余褋兮澧浦。
搴汀洲兮杜若，将以遗兮远者。
时不可兮骤得，聊逍遥兮容与。

## 注释

- **帝子**：指湘夫人。传说她是尧帝的女儿，故称帝子。
- **降**：降临。
- **北渚**：北岸的小洲。
- **眇眇**：远望的样子，目光悠远。
- **愁予**：使我忧愁。
- **袅袅**：微风吹拂的样子。
- **洞庭**：洞庭湖。
- **波**：起波浪。
- **木叶**：树叶。
- **白薠**：一种秋生的草，类似莎草。
- **骋望**：纵目远望。
- **佳期**：约会的好时光。
- **夕张**：在傍晚张设帷帐，准备迎接。
- **萃**：聚集。
- **蘋**：一种水草，也叫田字草。
- **罾**：一种用木棍或竹竿做支架的方形渔网。
- **沅**：沅水，在湖南西部。
- **澧**：澧水，在湖南西北部，流入洞庭湖。
- **公子**：指湘夫人。古代诸侯之女也可称公子。
- **荒忽**：恍惚，心神不定的样子。
- **潺湲**：水流缓慢的样子。
- **麋**：麋鹿。
- **蛟**：传说中的一种龙。
- **水裔**：水边。
- **江皋**：江边高地。
- **济**：渡水。
- **西澨**：西岸。澨，水边。
- **腾驾**：驾车飞奔。
- **偕逝**：一同前往。
- **葺**：覆盖屋顶。
- **荷盖**：用荷叶做屋顶。
- **荪壁**：用荪草装饰墙壁。荪，香草名。
- **紫坛**：用紫贝铺成的庭院地面。坛，庭院中的台地。
- **播**：散布。
- **芳椒**：芳香的花椒。
- **桂栋**：用桂木做屋梁。栋，正梁。
- **兰橑**：用木兰做屋椽。橑，屋椽。
- **辛夷**：香木名，即木兰。
- **楣**：门框上的横木。
- **药房**：用白芷装饰的房室。药，即白芷。
- **罔**：同"网"，编结。
- **薜荔**：一种蔓生香草。
- **帷**：帐幕。
- **擗**：剖开，分开。
- **蕙櫋**：用蕙草编织的帐顶。櫋，帐顶。
- **张**：张设。
- **镇**：压席的用具。
- **疏**：分布，陈列。
- **石兰**：香草名。
- **芷葺**：用白芷覆盖。
- **缭**：缠绕，这里指环绕。
- **杜衡**：香草名。
- **实**：充实，布满。
- **芳馨**：芳香。
- **庑门**：走廊和门。庑，堂周围的走廊。
- **九嶷**：九嶷山，传说中舜帝安葬的地方，在湖南省南部。
- **缤**：众多的样子。
- **灵**：神灵，指湘夫人的随从神灵。
- **捐**：抛弃，丢弃。
- **袂**：衣袖。
- **褋**：单衣。
- **澧浦**：澧水之滨。
- **搴**：拔取。
- **汀洲**：水中平地。
- **杜若**：香草名。
- **遗**：赠送。
- **远者**：远方的人，指湘夫人。
- **骤得**：屡次得到，轻易得到。
- **逍遥**：悠闲自在的样子。
- **容与**：从容自在的样子。

## 译文

帝子湘夫人降临在北岸的小洲啊，我极目远望啊，心中充满忧愁。
秋风轻轻吹拂啊，洞庭湖泛起波浪啊，树叶纷纷飘落。
登上长满白薠的高地纵目远望啊，与佳人约好在傍晚张设帷帐迎接。
鸟儿为什么聚集在水草之中？渔网为什么挂在树木之上？

沅水有白芷啊澧水有兰草，思念湘夫人啊却不敢明言。
心神恍惚啊向远方眺望，只见流水啊缓缓流淌。
麋鹿为什么在庭院中觅食？蛟龙为什么在水边游动？
清晨我驱马奔驰到江边高地，傍晚渡水到西岸。
听说佳人在召唤我啊，我将驾车飞奔与她同往。

在水中建造房屋啊，用荷叶覆盖屋顶。
用荪草装饰墙壁啊，紫贝铺成庭院，撒播芳香的花椒啊布满厅堂。
桂木做屋梁啊木兰做屋椽，辛夷木做门楣啊白芷装饰房室。
编结薜荔啊做成帐幕，剖开蕙草啊张设帐顶。
用白玉啊做成压席的镇石，分布石兰啊使其芳香。
用白芷覆盖啊荷叶做的屋顶，环绕着杜衡啊芬芳馥郁。

汇合百草啊布满庭院，建构芳香啊直到廊门。
九嶷山的神灵啊纷纷来迎，众神降临啊如同云聚。
把我衣袖啊抛入江中，把我单衣啊留在澧水之滨。
拔取汀洲上的杜若啊，准备送给啊远方的人。
美好的时光啊不可轻易得到，姑且逍遥自在啊从容徘徊。

## 赏析

《九歌·湘夫人》是屈原《九歌》组诗中的名篇，是祭祀湘水女神的乐歌。湘夫人是湘水女神，传说为尧帝之女、舜帝之妻娥皇、女英之一。全诗以湘君（湘水男神）的口吻，抒写对湘夫人的思念与追求，以及约会不遇的惆怅与失落。

诗开篇以"袅袅兮秋风，洞庭波兮木叶下"起兴，寥寥数笔便勾勒出一幅洞庭秋景图，秋风萧瑟、波涛涌动、落叶纷飞，渲染出凄清哀婉的氛围，成为千古传诵的写景名句。清人王夫之赞其为"千古言秋之祖"。

诗中通过"鸟何萃兮蘋中，罾何为兮木上""麋何食兮庭中？蛟何为兮水裔"等反常景象的描写，以比兴手法暗示约会失期的失望与困惑。随后转入想象，诗人精心构筑了一座水中芳室，以荷、荪、桂、兰、辛夷、薜荔、蕙、石兰、杜若等香草美木装饰，象征着对美好爱情的向往与追求。

末段"捐余袂兮江中，遗余褋兮澧浦"，以抛衣江水的仪式表达思念与期盼，"搴汀洲兮杜若，将以遗兮远者"则表现了对爱情的执着与忠贞。全诗融写景、抒情、想象于一体，意境优美，情致缠绵，是《九歌》中最动人的篇章之一。

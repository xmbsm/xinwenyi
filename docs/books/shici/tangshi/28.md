# 行路难

**[唐] [李白](/authors/libai)**

## 原文

金樽清酒斗十千，玉盘珍羞直万钱。
停杯投箸不能食，拔剑四顾心茫然。
欲渡黄河冰塞川，将登太行雪满山。
闲来垂钓碧溪上，忽复乘舟梦日边。
行路难，行路难，多歧路，今安在？
长风破浪会有时，直挂云帆济沧海。

## 注释

- 行路难：乐府旧题
- 金樽：金杯
- 清酒：美酒
- 斗十千：一斗酒值十千钱，形容酒价昂贵
- 珍羞：珍贵的菜肴
- 直：同"值"
- 投箸：放下筷子
- 茫然：迷茫不知所措
- 冰塞川：黄河被冰雪堵塞
- 太行：太行山
- 垂钓碧溪：指姜太公在渭水垂钓遇周文王
- 乘舟梦日：指伊尹梦见乘船经过日月之旁，后被商汤重用
- 歧路：岔路
- 今安在：如今在哪里
- 长风破浪：比喻志向远大，不怕困难
- 济：渡

## 译文

金杯中的美酒一斗价值十千，玉盘里的珍贵菜肴价值万钱。放下酒杯，扔掉筷子，不能进食；拔出宝剑，环顾四周，心中一片茫然。想渡过黄河，却被冰雪堵塞了河道；想登上太行山，却被大雪覆盖了山路。闲暇时像姜太公一样在碧溪上垂钓，忽然又梦见像伊尹一样乘船经过日月旁边。行路难啊，行路难！岔路这么多，如今身在何方？相信总有一天能乘长风破万里浪，高挂云帆，渡过沧海。

## 赏析

这首诗是李白遭受谗毁被排挤出长安时所作，抒发了诗人在政治道路上遭遇艰难时的愤激情绪，同时也表现了诗人乐观自信的人生态度和对理想的执着追求。

前四句写宴饮场景，"金樽清酒斗十千，玉盘珍羞直万钱"，描绘了丰盛的宴席。但"停杯投箸不能食，拔剑四顾心茫然"，以强烈的反差写出诗人内心的苦闷和迷茫。美酒佳肴在前，却无心享用，拔剑四顾，不知何去何从。

"欲渡黄河冰塞川，将登太行雪满山"，以自然界的艰难比喻人生道路的坎坷。黄河冰封、太行雪满，象征着诗人前进道路上的重重障碍。

"闲来垂钓碧溪上，忽复乘舟梦日边"，引用姜太公和伊尹的典故，表达了诗人对重新得到重用的期盼。虽然现实艰难，但诗人并未放弃希望。

"行路难，行路难，多歧路，今安在？"，以短促的句式和反复的修辞，表达了诗人对人生道路的迷茫和慨叹。但结尾"长风破浪会有时，直挂云帆济沧海"，笔锋一转，以豪迈的语气表达了对未来的信心：总有一天，我会乘风破浪，实现自己的理想。

全诗情感跌宕起伏，从苦闷到希望，从迷茫到自信，充分展现了李白豪放不羁的性格和积极乐观的人生态度。

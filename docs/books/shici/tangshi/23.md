# 望岳

**[唐] [杜甫](/authors/dufu)**

## 原文

岱宗夫如何？齐鲁青未了。
造化钟神秀，阴阳割昏晓。
荡胸生曾云，决眦入归鸟。
会当凌绝顶，一览众山小。

## 注释

- 岳：指东岳泰山
- 岱宗：泰山的尊称
- 夫如何：怎么样
- 齐鲁：春秋时的齐国和鲁国，在今山东一带
- 青未了：青翠的山色连绵不断，望不到尽头
- 造化：天地自然
- 钟：聚集
- 神秀：神奇秀丽
- 阴阳：山的北面和南面
- 割：分割
- 昏晓：黄昏和拂晓
- 荡胸：心胸激荡
- 曾云：层云
- 决眦：极力张大眼睛
- 归鸟：归巢的鸟
- 会当：一定要
- 凌：登上
- 绝顶：最高峰
- 一览：放眼望去

## 译文

泰山到底怎么样呢？在齐鲁大地上，它那青翠的山色连绵不断，望不到尽头。大自然将神奇和秀丽都聚集在这里，山南山北仿佛被分割成黄昏和拂晓。层层云气升腾，使人心胸激荡；极力张大眼睛远望归巢的鸟儿。一定要登上泰山的最高峰，放眼望去，所有的山都显得渺小。

## 赏析

这首诗是杜甫青年时期的作品，是他现存最早的一首诗，也是咏泰山的千古名篇。全诗洋溢着青年诗人蓬勃的朝气和远大的抱负。

首联以问句起笔，"岱宗夫如何？齐鲁青未了"，以广阔的视角写出泰山的雄伟气势。在齐鲁大地上，泰山的青翠之色绵延不绝，一望无际。

颔联"造化钟神秀，阴阳割昏晓"，写泰山的神奇秀丽和高峻挺拔。大自然将所有的神奇和秀丽都赋予了泰山，山南山北阳光分明，仿佛被分割成两个世界。

颈联"荡胸生曾云，决眦入归鸟"，写诗人仰望泰山时的感受。云气升腾，使人心胸开阔；极目远眺，可以看到归巢的鸟儿。这一联将写景与抒情融为一体。

尾联"会当凌绝顶，一览众山小"，是千古名句，表达了诗人一定要登上泰山之巅、俯视群山的雄心壮志。这不仅是写登山，更是诗人远大抱负的象征，体现了盛唐时期青年人积极进取的精神风貌。

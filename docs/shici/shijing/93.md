# 芄兰

**《诗经·卫风》**

## 原文

芄兰之支，童子佩觿。虽则佩觿，能不我知。容兮遂兮，垂带悸兮。

芄兰之叶，童子佩韘。虽则佩韘，能不我甲。容兮遂兮，垂带悸兮。

## 注释

- **芄兰**：一种蔓生植物，又名萝藦。
- **支**：通"枝"，枝条。
- **童子**：少年，未成年男子。
- **佩觿**：佩戴解结的锥子。觿，古代解绳结的用具，成年男子所佩。
- **能不我知**：却不能与我相知。能，乃，却。
- **容兮遂兮**：装作庄重成熟的样子。容，从容。遂，成熟。
- **垂带悸兮**：垂下的衣带摇动的样子。悸，摇动的样子。
- **韘**：古代射箭时戴在拇指上的骨制扳指，成年男子所佩。
- **甲**：通"狎"，亲近。一说通"洽"，融洽。

## 译文

芄兰的枝条，少年却佩戴着解结的锥子。虽然佩戴着锥子，却不能与我相知。装作庄重成熟的样子，垂下的衣带摇摇晃晃。

芄兰的叶子，少年却佩戴着射箭的扳指。虽然佩戴着扳指，却不能与我亲近。装作庄重成熟的样子，垂下的衣带摇摇晃晃。

## 赏析

《芄兰》是《诗经·卫风》中的一篇讽刺诗，以芄兰起兴，讽刺一位少年装模作样地佩戴成年男子的饰物，却毫无成年人的修养和品格，表达了诗人的鄙夷和不满。

全诗共两章，结构相同。每章首句"芄兰之支""芄兰之叶"以芄兰起兴。芄兰是蔓生植物，枝条柔软，叶子心形——以芄兰的柔弱反衬少年的不成熟。

每章第二句"童子佩觿""童子佩韘"点出讽刺的对象——一个少年却佩戴着成年男子的饰物。觿是解绳结的锥子，韘是射箭的扳指，都是成年男子的佩饰。少年尚未成年，却早早佩戴成年人的饰物，本身就是一种装模作样。

每章第三句"虽则佩觿，能不我知""虽则佩韘，能不我甲"是讽刺的核心——虽然佩戴着成年人的饰物，却不能与人相知、不能与人亲近。这里揭示了形式与内容的矛盾——外在的装束虽然成年化，内在的修养却仍是孩童。

每章末句"容兮遂兮，垂带悸兮"描绘少年的姿态——装作庄重成熟的样子，垂下的衣带却摇摇晃晃。"垂带悸兮"四字尤为传神——衣带的摇动暴露了少年的不稳重，与"容兮遂兮"的装模作样形成反差，将少年的虚伪和可笑写得入木三分。

此诗最大的艺术特色是反衬和细节描写。以芄兰的柔弱反衬少年的不成熟，以"佩觿""佩韘"的成年饰物反衬少年的孩童心态，以"容兮遂兮"的装模作样反衬"垂带悸兮"的不稳重。多重反衬，使讽刺之意层层加深。细节描写尤为传神——"垂带悸兮"四字，将少年的滑稽之态写得栩栩如生，体现了《诗经》讽刺艺术的精湛。

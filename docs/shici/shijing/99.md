# 大车

**《诗经·王风》**

## 原文

大车槛槛，毳衣如菼。岂不尔思？畏子不敢。

大车啍啍，毳衣如璊。岂不尔思？畏子不奔。

穀则异室，死则同穴。谓予不信，有如皦日。

## 注释

- **大车**：大夫所乘之车。
- **槛槛**：车行声。
- **毳衣**：用兽毛织的衣服，大夫所服。
- **菼**：初生的荻，青白色。
- **尔思**：思念你。
- **畏子不敢**：怕你不敢（私奔）。
- **啍啍**：车行迟重的样子。
- **璊**：赤色的玉。
- **不奔**：不私奔。
- **穀**：活着。穀，生。
- **异室**：不同室（不能同居）。
- **同穴**：同葬一穴。
- **谓予不信**：说我不诚信。
- **有如皦日**：有如白日之明。皦，白，明亮。

## 译文

大车槛槛地行驶，毳衣如初生荻般青白。我怎能不思念你？只怕你不敢。

大车啍啍地行驶，毳衣如赤玉般红。我怎能不思念你？只怕你不私奔。

活着虽不能同室，死后要同葬一穴。说我不诚信，有如白日般光明！

## 赏析

《大车》是《诗经·王风》中的一首爱情诗，描绘了一位女子对情人的深情誓约——生不能同居，死则同葬一穴，以皦日为誓，情感激烈而坚贞。

全诗共三章。前两章结构相似。"大车槛槛""大车啍啍"写大车的行驶声——大车是大夫所乘之车，由此可知诗中的"子"是一位大夫。"毳衣如菼""毳衣如璊"写大夫的服饰——毳衣如初生荻般青白，又如赤玉般红艳。这两句以车声和服饰描绘大夫的形象，既是写实，也渲染出一种庄重的气氛。

"岂不尔思？畏子不敢""畏子不奔"两句是女子的内心独白——我怎能不思念你？只怕你不敢私奔。这两句写出了女子的矛盾：一方面深爱着对方，另一方面又担心对方不敢迈出那一步。这种矛盾，将女子的深情和无奈表达得淋漓尽致。

第三章是全诗的高潮，也是中国古典诗歌中最早的爱情誓言之一。"穀则异室，死则同穴"——活着虽不能同室，死后要同葬一穴。这一誓言，将爱情超越了生死——生前不能结合，死后也要同穴而葬，体现了女子对爱情的坚贞和决绝。"谓予不信，有如皦日"——如果怀疑我的诚信，有如白日般光明！这一誓，将皦日作为见证，将爱情誓言推向了最高潮。

此诗最大的艺术特色是直白的热烈和誓言的庄重。"岂不尔思"的直白、"畏子不敢"的矛盾、"死则同穴"的决绝、"有如皦日"的誓言，将女子的爱情写得热烈而坚贞。这种"之死矢靡它"式的爱情誓言，与《鄘风·柏舟》异曲同工，体现了《诗经》时代爱情诗的真率之美。"死则同穴"成为后世表达生死相随的经典意象，对后世爱情文学产生了深远影响。

# 芣苢

**[先秦] 佚名**

## 原文

采采芣苢，薄言采之。采采芣苢，薄言有之。

采采芣苢，薄言掇之。采采芣苢，薄言捋之。

采采芣苢，薄言袺之。采采芣苢，薄言襭之。

## 注释

- 芣苢：车前草，古人认为其子可治不孕
- 采采：茂盛的样子，一说采摘
- 薄言：发语词，无实义
- 有：取得
- 掇：拾取
- 捋：用手顺着抹下来
- 袺：提起衣襟兜住
- 襭：把衣襟掖在腰带上兜住

## 译文

茂盛的车前草，快来采摘它。茂盛的车前草，快来取得它。

茂盛的车前草，快来拾取它。茂盛的车前草，快来捋取它。

茂盛的车前草，提起衣襟兜住它。茂盛的车前草，掖起衣襟兜住它。

## 赏析

《芣苢》是《诗经·周南》中的一首，是一首描写妇女采集车前草的劳动歌谣。

全诗三章，采用重章叠句的形式，仅换了六个动词：采、有、掇、捋、袺、襭。这六个动词生动地描绘了采集车前草的整个过程：从采摘到取得，从拾取到捋取，再到用衣襟兜住。动作的递进，展现了劳动的进程和收获的喜悦。

诗中没有直接抒情，但通过反复咏唱和动作的描写，传达出劳动者欢快的心情。妇女们一边采集，一边歌唱，歌声中充满了对劳动的热爱和对收获的期盼。

这种以动作代替抒情的写法，是《诗经》民歌的典型特征。全诗节奏明快，语言质朴，充满了生活气息和劳动的美感。

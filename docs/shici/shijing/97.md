# 兔爰

**《诗经·王风》**

## 原文

有兔爰爰，雉离于罗。我生之初，尚无为；我生之后，逢此百罹。尚寐无吪！

有兔爰爰，雉离于罦。我生之初，尚无造；我生之后，逢此百忧。尚寐无觉！

有兔爰爰，雉离于罿。我生之初，尚无庸；我生之后，逢此百凶。尚寐无聪！

## 注释

- **爰爰**：自由自在、缓慢行走的样子。
- **雉**：野鸡。
- **离**：同"罹"，遭遇，陷入。
- **罗**：网。
- **无为**：无事，指没有劳役。
- **百罹**：多种灾难。罹，忧患。
- **尚寐**：还是睡着吧。尚，且，还是。寐，睡。
- **无吪**：不要动。吪，动。
- **罦**：一种装有机关的捕鸟兽的网。
- **造**：指劳役之事。
- **百忧**：多种忧患。
- **无觉**：不要醒。觉，醒。
- **罿**：捕鸟网。
- **庸**：劳役。
- **百凶**：多种凶祸。
- **无聪**：不要听。聪，听。

## 译文

有兔子自由自在地走，野鸡却陷入了网中。我出生之初，还没有劳役；我出生之后，逢此百般灾难。还是睡了吧，不要动！

有兔子自由自在地走，野鸡却陷入了捕网。我出生之初，还没有劳役；我出生之后，逢此百般忧患。还是睡了吧，不要醒！

有兔子自由自在地走，野鸡却陷入了捕网。我出生之初，还没有劳役；我出生之后，逢此百般凶祸。还是睡了吧，不要听！

## 赏析

《兔爰》是《诗经·王风》中的一篇感时伤乱诗，以兔和雉的对比起兴，抒发了诗人对时代变乱的悲愤和对现实的逃避，是《诗经》中"生不逢时"主题的代表作。

全诗共三章。每章首两句"有兔爰爰，雉离于罗""雉离于罦""雉离于罿"以兔和雉起兴。兔子自由自在地行走，野鸡却陷入了网中——兔与雉的对比，比喻乱世中小人得势（兔子）、君子遭难（野鸡）。这一比兴，深刻揭示了乱世的不公。

每章中三句"我生之初，尚无为""尚无造""尚无庸"回忆往昔——我出生之初，还没有劳役。这里的"无为""无造""无庸"都是指没有劳役之苦，是诗人对往昔太平之世的怀念。"我生之后，逢此百罹""逢此百忧""逢此百凶"回到现实——我出生之后，逢此百般灾难、忧患、凶祸。昔今对比，将时代的变化和诗人的悲愤写得淋漓尽致。

每章末句"尚寐无吪""尚寐无觉""尚寐无聪"是诗人的逃避之辞——还是睡了吧，不要动、不要醒、不要听。这三个"无"字，写出了诗人对现实的彻底绝望——既然无法改变现实，不如"装睡"——不动、不醒、不听，以一种消极的逃避表达对乱世的抗议。

此诗最大的艺术特色是对比的运用和"逃避"主题的开创。兔与雉的对比，象征小人与君子；往昔与现实的对比，写时代之变；动与不动的对比，写心境之变。"尚寐无吪"的逃避，开创了中国诗歌中"以睡遁世"的主题，对后世阮籍、陶渊明等人的隐逸思想产生了深远影响。

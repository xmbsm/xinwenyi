# 凯风

**《诗经·邶风》**

## 原文

凯风自南，吹彼棘心。棘心夭夭，母氏劬劳。

凯风自南，吹彼棘薪。母氏圣善，我无令人。

爰有寒泉？在浚之下。有子七人，母氏劳苦。

睍睆黄鸟，载好其音。有子七人，莫慰母心。

## 注释

- **凯风**：和风，南风，夏天的风。
- **南**：南方。
- **棘**：酸枣树。
- **棘心**：酸枣树初生的嫩芽。
- **夭夭**：茂盛的样子。
- **母氏**：母亲。
- **劬劳**：劳苦。
- **棘薪**：酸枣树长成了柴。
- **圣善**：明事理而有德行。
- **令人**：善良的人。
- **爰**：发语词。
- **寒泉**：清凉的泉水。
- **浚**：卫国地名，在今河南。
- **睍睆**：鸟鸣声清丽的样子。
- **载**：则，就。
- **好其音**：使它的声音好听。
- **莫慰**：不能安慰。

## 译文

和风从南方吹来，吹拂那酸枣树的嫩芽。嫩芽茂盛生长，母亲的劳苦深重。

和风从南方吹来，吹拂那长成柴的酸枣树。母亲明理而善良，我们却没有成材之人。

哪里有清凉的泉水？在浚地的下面。有七个儿子，母亲却依旧劳苦。

清丽鸣叫的黄鸟，它的声音多么好听。有七个儿子，却不能安慰母亲的心。

## 赏析

《凯风》是《诗经·邶风》中的名篇，是一首儿子自责、颂母之德的孝子之诗，以深情的笔调赞美了母亲的辛劳和美德，表达了儿子们不能安慰母心的自责。

全诗共四章。前两章以"凯风自南"起兴，以和风吹拂酸枣树比喻母亲养育儿女。"吹彼棘心"——吹拂嫩芽，比喻母亲抚育幼子；"吹彼棘薪"——吹拂长成的酸枣柴，比喻儿女已长大成人。"棘心夭夭，母氏劬劳"——嫩芽虽茂盛，全靠母亲劳苦培育；"母氏圣善，我无令人"——母亲明理善良，我们却没有成材之人。这两章以棘树的生长比喻儿女的成长，以凯风比喻母爱，既赞美了母亲的辛劳，也表达了自责。

第三章"爰有寒泉？在浚之下"以寒泉起兴。寒泉水清凉，滋润万物，比喻母亲的养育之恩。"有子七人，母氏劳苦"——七个儿子，母亲却依旧劳苦，这一对比，更显儿子们的不孝。

第四章"睍睆黄鸟，载好其音"以黄鸟起兴。黄鸟鸣声清丽，能悦人心，反衬儿子们不能安慰母亲。"有子七人，莫慰母心"——七个儿子，却无一能安慰母亲的心，这一对比，将自责之情推向高潮。

此诗最大的艺术特色是"兴"的手法的运用和对比的反衬。凯风吹棘、寒泉润物、黄鸟悦耳，三种自然景象，反衬出儿子们的不孝。每章末句"母氏劬劳""我无令人""母氏劳苦""莫慰母心"，层层递进，将颂母与自责之情表达得淋漓尽致。此诗被誉为中国古代孝子诗的代表作，对后世产生了深远影响。

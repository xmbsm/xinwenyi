# 考槃

**《诗经·卫风》**

## 原文

考槃在涧，硕人之宽。独寐寤言，永矢弗谖。

考槃在阿，硕人之薖。独寐寤歌，永矢弗过。

考槃在陆，硕人之轴。独寐寤宿，永矢弗告。

## 注释

- **考**：敲击。
- **槃**：木盘，乐器。考槃即敲盘而歌。
- **涧**：山间流水。
- **硕人**：高大贤德之人。
- **宽**：宽宏，此处指心胸开阔。
- **独寐寤言**：独自睡、醒、说话。
- **永矢**：永远发誓。矢，通"誓"。
- **弗谖**：不忘记。
- **阿**：山丘弯曲处。
- **薖**：安乐，或解为"窝"。
- **寤歌**：醒来唱歌。
- **弗过**：不过，指不与世俗交往。
- **陆**：高平之地。
- **轴**：盘桓不进，或解为"美"。
- **寤宿**：醒来住宿。
- **弗告**：不告人，不向外人道。

## 译文

敲着木盘在山涧之间，贤德之人的心胸宽宏。独自睡，醒来，说话，永远发誓不忘此乐。

敲着木盘在山丘弯曲处，贤德之人的安乐。独自睡，醒来，唱歌，永远发誓不与世俗交往。

敲着木盘在高平之地，贤德之人的盘桓。独自睡，醒来，住宿，永远发誓不向外人道。

## 赏析

《考槃》是《诗经·卫风》中的一篇隐逸诗，描绘了一位贤德之人在山间隐居的快乐生活，是中国文学史上最早的隐逸诗之一，被誉为"隐逸诗之祖"。

全诗共三章。每章首句"考槃在涧""考槃在阿""考槃在陆"以敲盘而歌的场景起笔。"考槃"即敲击木盘而歌，描绘出隐士的生活情态——以乐自娱，不假外求。"涧""阿""陆"三个地点，从山涧到山丘再到高平之地，写出了隐士活动的范围，也象征着隐士的精神境界越来越开阔。

每章第二句"硕人之宽""硕人之薖""硕人之轴"赞美隐士的品德。"硕人"指高大贤德之人，"宽"指心胸宽宏，"薖"指安乐，"轴"指盘桓（或美）。这三个词从心胸到心境再到气度，层层描绘出隐士的精神风貌——他不是无奈而隐，而是真正享受隐居的乐趣。

每章后两句"独寐寤言""独寐寤歌""独寐寤宿"写隐士独居的生活——独自睡，醒来，说话、唱歌、住宿。这一系列动作，写出隐士独居的自在——不必与人言，自言自语；不必与人歌，自歌自咏；不必与人宿，自得其乐。"永矢弗谖""永矢弗过""永矢弗告"三个誓言，写出了隐士的决心——永远不忘此乐、永远不与世俗交往、永远不向外人道。这三个"永矢"，将隐士的坚贞和超脱表达得淋漓尽致。

此诗最大的艺术特色是简淡的笔调和深远的意境。诗人以最简练的语言描绘隐士的生活——敲盘而歌、独寐寤言，却将隐士的精神境界写得高远超脱。每章末句"永矢"的誓言，既是隐士对自己的承诺，也是对世俗的宣言。此诗开创了中国文学中的隐逸传统，对后世陶渊明等隐逸诗人产生了深远影响，被誉为"千古隐逸诗之祖"。

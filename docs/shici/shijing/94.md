# 河广

**《诗经·卫风》**

## 原文

谁谓河广？一苇杭之。谁谓宋远？跂予望之。

谁谓河广？曾不容刀。谁谓宋远？曾不崇朝。

## 注释

- **河**：黄河。
- **广**：宽。
- **一苇杭之**：一片芦苇就可以渡过。杭，通"航"，渡过。
- **宋**：宋国。
- **跂**：踮起脚跟。
- **予**：我。
- **望之**：望见它。
- **曾**：简直，竟然。
- **容刀**：容下一条小船。刀，通"舠"，小船。
- **崇朝**：终朝，从天亮到早饭之间，形容时间短。崇，终。

## 译文

谁说黄河宽广？一片芦苇就可以渡过。谁说宋国遥远？踮起脚就能望见。

谁说黄河宽广？竟容不下一条小船。谁说宋国遥远？用不了一个早晨就能到。

## 赏析

《河广》是《诗经·卫风》中的一篇思乡诗，描写一位流寓卫国的宋国人思归宋国的心情，以夸张的手法表达了归乡之切的强烈情感。

全诗共两章，结构相同。每章前两句"谁谓河广？一苇杭之""谁谓河广？曾不容刀"以反问和夸张写黄河之"窄"。黄河本是天险，宽广难渡，但在思乡之人的眼中，却"一苇杭之"——一片芦苇就可以渡过，"曾不容刀"——简直容不下一条小船。这种夸张，并非写实，而是写心——因为思乡心切，所以觉得黄河不宽。

每章后两句"谁谓宋远？跂予望之""谁谓宋远？曾不崇朝"以反问和夸张写宋国之"近"。宋国本在黄河对岸，有一定距离，但在思乡之人眼中，却"跂予望之"——踮起脚就能望见，"曾不崇朝"——用不了一个早晨就能到。这种夸张，同样是写心——因为归乡心切，所以觉得宋国不远。

此诗最大的艺术特色是夸张和反问的结合。诗人以"谁谓"领起每句，连续反问，增强了情感的力度；以"一苇杭之""曾不容刀""跂予望之""曾不崇朝"四个夸张，将黄河之"窄"和宋国之"近"写到极致。然而，这种"窄"和"近"并非事实，而是思乡之人的心理——越是思念，越是觉得距离不远；越是归心似箭，越是觉得阻碍不大。这种"以夸写情"的手法，将思乡之情表达得淋漓尽致，体现了《诗经》抒情艺术的高超。

全诗仅十六字，却蕴含了深沉的思乡之情，是中国古典诗歌中"以少胜多"的典范，对后世思乡诗的夸张手法产生了深远影响。

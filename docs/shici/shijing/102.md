# 将仲子

**《诗经·郑风》**

## 原文

将仲子兮，无逾我里，无折我树杞。岂敢爱之？畏我父母。仲可怀也，父母之言，亦可畏也。

将仲子兮，无逾我墙，无折我树桑。岂敢爱之？畏我诸兄。仲可怀也，诸兄之言，亦可畏也。

将仲子兮，无逾我园，无折我树檀。岂敢爱之？畏人之多言。仲可怀也，人之多言，亦可畏也。

## 注释

- **将**：请，愿。
- **仲子**：二哥，指女子的情人。仲，排行第二。
- **逾**：翻越。
- **里**：里巷，邻里。
- **折**：折断。
- **树杞**：种的杞柳。
- **爱**：吝惜。
- **畏**：害怕。
- **怀**：思念。
- **墙**：院墙。
- **树桑**：种的桑树。
- **诸兄**：各位兄长。
- **园**：园子。
- **树檀**：种的檀树。
- **多言**：多嘴多舌。

## 译文

请仲子啊，不要翻越我里巷的墙，不要折断我种的杞柳。我怎敢吝惜这些？只怕我的父母。仲子值得怀念，但父母的话，也令人害怕。

请仲子啊，不要翻越我院墙，不要折断我种的桑树。我怎敢吝惜这些？只怕我的各位兄长。仲子值得怀念，但兄长的话，也令人害怕。

请仲子啊，不要翻越我园子的墙，不要折断我种的檀树。我怎敢吝惜这些？只怕人们多嘴多舌。仲子值得怀念，但人们的闲话，也令人害怕。

## 赏析

《将仲子》是《诗经·郑风》中的名篇，是一首爱情诗，描写一位女子劝阻情人翻墙幽会，既表达了对情人的思念，又表达了对父母、兄长、邻里的畏惧，情感矛盾而真实。

全诗共三章。每章首句"将仲子兮"以呼告起笔，请仲子不要做某事——这一呼告，既含深情，又含劝阻，奠定了全诗矛盾的基调。

每章中三句"无逾我里，无折我树杞""无逾我墙，无折我树桑""无逾我园，无折我树檀"写女子的劝阻。"逾里""逾墙""逾园"，从里巷到院墙到园子，层层深入，写出仲子求爱的急切；"折杞""折桑""折檀"，从杞柳到桑树到檀树，写出仲子翻墙时造成的损坏。这些劝阻，既是写实——仲子确实在翻墙幽会，也是隐喻——女子的防御在层层后退。

每章后四句"岂敢爱之？畏我父母""畏我诸兄""畏人之多言"写女子的矛盾心理。"岂敢爱之"——我怎敢吝惜这些树木？言外之意是：我不是舍不得树木，而是害怕人言。"仲可怀也"——仲子值得怀念，这是女子的深情；"父母之言，亦可畏也""诸兄之言""人之多言"——但父母、兄长、邻里的闲话也令人害怕，这是女子的畏惧。深情与畏惧并存，将女子内心的矛盾写得淋漓尽致。

此诗最大的艺术特色是心理描写的细腻和矛盾的展现。女子既爱仲子，又畏惧礼教——这种"爱"与"畏"的矛盾，正是古代女子在爱情与礼教之间的真实处境。从"父母"到"诸兄"到"人之多言"，畏惧的范围越来越大，写出了女子处境的越来越艰难。此诗被誉为《诗经》中描写女子心理的杰作，对后世爱情诗的心理描写产生了深远影响。

# 淇奥

**《诗经·卫风》**

## 原文

瞻彼淇奥，绿竹猗猗。有匪君子，如切如磋，如琢如磨。瑟兮僩兮，赫兮咺兮。有匪君子，终不可谖兮！

瞻彼淇奥，绿竹青青。有匪君子，充耳琇莹，会弁如星。瑟兮僩兮，赫兮咺兮。有匪君子，终不可谖兮！

瞻彼淇奥，绿竹如箦。有匪君子，如金如锡，如圭如璧。宽兮绰兮，猗重较兮。善戏谑兮，不为虐兮！

## 注释

- **瞻**：看。
- **淇**：淇水。
- **奥**：水边弯曲处。
- **绿竹**：绿，王刍。竹，萹蓄。皆为水边植物。
- **猗猗**：美盛的样子。
- **匪**：通"斐"，文采。
- **君子**：指卫武公。
- **如切如磋**：像治骨角那样切割磋磨。切，治骨。磋，治角。
- **如琢如磨**：像治玉石那样雕琢打磨。琢，治玉。磨，治石。
- **瑟**：庄重的样子。
- **僩**：威严的样子。
- **赫**：光明的样子。
- **咺**：显著的样子。
- **谖**：忘记。
- **青青**：葱翠茂盛的样子。
- **充耳**：古代冠冕上垂在两侧的玉饰。
- **琇**：美石。
- **莹**：晶莹。
- **会弁**：鹿皮冠的接缝处。会，缝合处。弁，鹿皮冠。
- **如星**：镶着的玉饰如星星。
- **箦**：积，密集的样子。
- **金锡**：金与锡，比喻君子修炼精进。
- **圭璧**：玉器，比喻君子品德高洁。
- **宽**：宽宏。
- **绰**：温和。
- **猗**：通"倚"，依靠。
- **重较**：古代卿所乘之车。
- **戏谑**：开玩笑。
- **虐**：刻薄伤人。

## 译文

看那淇水弯曲处，绿竹美盛。有位文采君子，如切如磋，如琢如磨。庄重啊威严啊，光明啊显著啊。有位文采君子，终不能忘记啊！

看那淇水弯曲处，绿竹葱翠。有位文采君子，充耳是晶莹的美玉，鹿皮冠上玉饰如星。庄重啊威严啊，光明啊显著啊。有位文采君子，终不能忘记啊！

看那淇水弯曲处，绿竹密集。有位文采君子，如金如锡，如圭如璧。宽宏啊温和啊，靠着车子。善于开玩笑啊，却不刻薄伤人啊！

## 赏析

《淇奥》是《诗经·卫风》中的名篇，是一首赞美卫武公的诗，以淇水之畔的绿竹起兴，描绘了一位文采斐然、品德高尚的君子形象，是《诗经》赞美诗的代表作。

全诗共三章。每章前两句"瞻彼淇奥，绿竹猗猗""绿竹青青""绿竹如箦"以淇水和绿竹起兴。淇水弯曲处，绿竹美盛、葱翠、密集——竹子的挺拔青翠，象征君子的高洁品格。"瞻彼"二字领起，将读者带入清雅的意境。

第一章"有匪君子，如切如磋，如琢如磨"是全诗的名句。"如切如磋，如琢如磨"用治骨角玉石的工艺，比喻君子的修身进德——精益求精，不断进取。这一比喻成为中国文化的经典意象，"切磋琢磨"成为后世修身养性的常用语。"瑟兮僩兮，赫兮咺兮"描绘君子的仪态——庄重威严、光明显著。"有匪君子，终不可谖兮"——这样的君子，怎能忘记？

第二章"充耳琇莹，会弁如星"描绘君子的服饰。充耳是晶莹的美玉，鹿皮冠上玉饰如星——以服饰之美衬托君子之美。"瑟兮僩兮，赫兮咺兮"重复第一章，强调君子仪态的庄重威严。

第三章"如金如锡，如圭如璧"以金、锡、圭、璧四种贵重之物，比喻君子品德的精纯高洁。"宽兮绰兮"写君子性格的宽宏温和；"猗重较兮"写君子乘车的气派；"善戏谑兮，不为虐兮"写君子善于开玩笑却不过分——这一笔尤为传神，将君子的亲切幽默与分寸感写得栩栩如生。

此诗最大的艺术特色是博喻的运用。"如切如磋，如琢如磨""如金如锡，如圭如璧"，连用比喻，将君子的修身、品德、性格、仪态描绘得淋漓尽致。绿竹的意象贯穿全诗，与君子的品格相映衬，构成了情景交融的意境。此诗被誉为《诗经》赞美诗的典范，对后世赞美君子的诗歌产生了深远影响。

# 匏有苦叶

**《诗经·邶风》**

## 原文

匏有苦叶，济有深涉。深则厉，浅则揭。

有弥济盈，有鷕雉鸣。济盈不濡轨，雉鸣求其牡。

雝雝鸣雁，旭日始旦。士如归妻，迨冰未泮。

招招舟子，人涉卬否。人涉卬否，卬须我友。

## 注释

- **匏**：葫芦。
- **苦叶**：枯叶。古人渡水时将葫芦系在腰间以助浮。
- **济**：济水。
- **深涉**：深渡口。
- **厉**：连衣涉水。
- **揭**：提起下衣涉水。
- **弥**：水满的样子。
- **盈**：满。
- **鷕**：雉鸣声。
- **雉**：野鸡。
- **濡**：沾湿。
- **轨**：车轴头。
- **牡**：雄性禽兽。
- **雝雝**：雁鸣声。
- **旭日**：初升的太阳。
- **旦**：明，天亮。
- **归妻**：娶妻。
- **迨**：及，趁。
- **泮**：融解。
- **招招**：招手的样子。
- **舟子**：船夫。
- **卬**：我。
- **否**：不。
- **须**：等待。

## 译文

葫芦有枯叶可系腰渡水，济水有深渡口可过。水深就连衣涉水，水浅就提起下衣涉水。

济水满满地涨起来，野鸡咯咯地叫着。济水虽满不沾湿车轴，野鸡鸣叫是求其配偶。

雝雝鸣叫的大雁，旭日初升天刚亮。男子若要娶妻，趁河水未结冰时来。

船夫招手示意渡河，别人渡河我不过。别人渡河我不过，我要等我的朋友。

## 赏析

《匏有苦叶》是《诗经·邶风》中的一篇，是一首描写女子等待未婚夫前来迎娶的爱情诗，以巧妙的比兴和细腻的心理描写展现了待嫁女子的情思。

全诗共四章。第一章"匏有苦叶，济有深涉"以葫芦和渡口起兴。葫芦叶枯可以系腰渡水，渡口虽深也有涉渡之法。"深则厉，浅则揭"两句，写出渡水的经验——水深就连衣涉水，水浅就提起下衣涉水。这一章既写渡水，也暗喻处事之道——不论情况如何，都有应对之法。

第二章"有弥济盈，有鷕雉鸣"以水满和雉鸣起兴。济水满涨，野鸡鸣叫求偶。"济盈不濡轨"——水虽满却不沾湿车轴，比喻适度；"雉鸣求其牡"——野鸡鸣叫求其配偶，暗喻女子盼望夫婿。

第三章"雝雝鸣雁，旭日始旦"以雁鸣和旭日起兴。古人以雁为贽礼娶妻，"雝雝鸣雁"暗喻婚娶之事。"旭日始旦"写迎亲的好时光。"士如归妻，迨冰未泮"——男子若要娶妻，趁河水未结冰时来。这是女子含蓄的期盼：希望未婚夫趁早来迎娶。

第四章"招招舟子，人涉卬否"是全曲的关键。船夫招手示意渡河，别人都渡河了，唯独女子不过河。"人涉卬否，卬须我友"——别人渡河我不过，我要等我的朋友。这一章将女子的痴情等待写得生动传神——她不是不能过河，而是要等心爱的人一起来。

此诗最大的艺术特色是比兴的巧妙运用。葫芦、济水、野鸡、大雁、旭日、船夫，一系列意象交织，构成了一个完整的待嫁女子的心理世界。语言清丽，意境生动，体现了《诗经》爱情诗的纯真之美。

# 兰陵王·丙子送春

**[宋] [刘辰翁](/authors/liuchenweng)**

## 原文

送春去，春去人间无路。秋千外，芳草连天，谁遣风沙暗南浦？依依甚意绪？谩忆海门飞絮。乱鸦过，斗转城荒，不见来时试灯处。

春去最谁苦？但箭雁沉边，梁燕无主。杜鹃声里长门暮。想玉树凋土，泪盘如露。咸阳送客屡回顾，斜日未能度。

春去尚来否？正江令恨别，庾信愁赋。苏堤尽日风和雨。叹神游故国，花记前度。人生流落，顾孺子，共夜语。

## 注释

- **兰陵王**：词牌名，首见于周邦彦词。全词三阕一百三十字。
- **丙子**：指宋恭帝德祐二年（1276年），元军攻陷临安，南宋灭亡。
- **春去人间无路**：春去人间已无路可走，喻南宋灭亡。
- **秋千外**：秋千之外。
- **芳草连天**：芳草与天际相连。
- **风沙暗南浦**：风沙使南浦暗淡。南浦，南面的水边，常指送别之地，此处暗指南宋故土。
- **依依甚意绪**：依依不舍是什么心绪。依依，思慕怀念。意绪，心意情绪。
- **谩忆**：空自思忆。谩，通"漫"。
- **海门飞絮**：海门的飞絮，暗指南渡的宋室君臣。海门，今江苏南通东。
- **乱鸦**：暗指占据临安的元军。
- **斗转城荒**：转眼间都城临安变成荒城。斗转，星斗转移，喻时局巨变。
- **试灯**：元宵前的张灯预赏。
- **箭雁沉边**：中箭的大雁坠落于边塞，喻被掳北去的君臣。
- **梁燕无主**：梁上燕子失去主人，喻亡国后的臣民。
- **长门**：汉宫名，借指宋帝宫阙。
- **玉树凋土**：玉树凋零入土，喻宋朝栋梁之臣凋谢。
- **泪盘如露**：铜仙泪盘上沾满露水。汉武帝建金铜仙人承露盘，魏明帝拆迁时铜仙泣泪，此处喻宋朝覆亡之痛。
- **咸阳送客屡回顾**：化用李贺"衰兰送客咸阳道"诗意，写被掳北行者的回望。
- **斜日未能度**：斜日西沉，难以前行。
- **江令**：指江淹，著有《恨赋》《别赋》。
- **庾信愁赋**：庾信仕梁出使西魏被留，著有《愁赋》。
- **苏堤**：西湖苏堤。
- **神游故国**：精神上游历故国。
- **花记前度**：化用刘禹锡"桃花依旧笑春风"诗意，写重来不见故人。
- **顾孺子**：看着儿子。孺子，指词人之子。
- **共夜语**：夜间共语。

## 译文

送春归去，春去后人间已无路可走。秋千外芳草连天，是谁让风沙暗淡了南浦？依依不舍是什么心绪？空自回忆海门飞絮。乱鸦飞过，星斗转移都城荒废，不见来时试灯的地方。

春去后谁最苦？中箭的大雁坠于边塞，梁上燕子失去主人。杜鹃啼声中长门日暮。想玉树凋零入土，铜仙泪盘如露。咸阳道上送客频频回顾，斜日西沉难以前行。

春去后还能再来否？正如江淹恨别，庾信愁赋。苏堤上终日风风雨雨。叹神游故国，花记前度。人生流落，看着儿子，夜间共语。

## 赏析

这首词是刘辰翁的代表作，作于南宋灭亡的丙子年（1276年），以"送春"喻"送宋"，借送春写出了亡国之痛，是宋末遗民词中沉痛感人的杰作。

第一叠写春去之景。"送春去，春去人间无路"——送春归去，春去后人间无路——以"春"喻"宋"，"春去"即"宋亡"，开篇即点明亡国之痛。"秋千外，芳草连天，谁遣风沙暗南浦？"——秋千外芳草连天，谁让风沙暗淡南浦——以芳草连天写春景之美，以风沙暗南浦写亡国之惨。"依依甚意绪？谩忆海门飞絮"——依依不舍，空忆海门飞絮——写对南渡君臣的追忆。"乱鸦过，斗转城荒，不见来时试灯处"——乱鸦飞过，城荒斗转，不见试灯处——以乱鸦喻元军，以城荒写临安陷落后的凄凉。

第二叠写春去之苦。"春去最谁苦？"——春去后谁最苦——以问句领起。"但箭雁沉边，梁燕无主"——箭雁坠边，梁燕无主——以箭雁喻被掳北去的君臣，以梁燕喻亡国后的臣民。"杜鹃声里长门暮"——杜鹃啼声中长门日暮——以杜鹃啼血写亡国之悲。"想玉树凋土，泪盘如露"——玉树凋土，泪盘如露——以玉树凋零和铜仙泣泪写宋朝覆亡。"咸阳送客屡回顾，斜日未能度"——送客频顾，斜日难度——写被掳北行者频频回望的悲恋。

第三叠写春去之思。"春去尚来否？"——春去还能再来否——以问句写对故国恢复的期待与绝望。"正江令恨别，庾信愁赋"——如江淹恨别，庾信愁赋——以江淹、庾信自比，写亡国之愁。"苏堤尽日风和雨"——苏堤终日风雨——以风雨写亡国后的凄凉。"叹神游故国，花记前度"——叹神游故国，花记前度——写对故国的思念和重来的怅惘。"人生流落，顾孺子，共夜语"——人生流落，看儿子，夜共语——以父子夜语作结，写出了流落余生中亲情的慰藉和亡国的沉痛。

全词以"送春"喻"送宋"，三叠层层递进——第一叠写春去之景，第二叠写春去之苦，第三叠写春去之思——将亡国之痛写得沉痛深婉，是宋末遗民词的代表作。词中大量用典——箭雁、梁燕、长门、玉树、泪盘、咸阳送客、江令、庾信——将历史与现实交织，写出了深沉的故国之思和亡国之痛。

# 风入松·听风听雨过清明

**[宋] [吴文英](/authors/wuwenying)**

## 原文

听风听雨过清明。愁草瘗花铭。楼前绿暗分携路，一丝柳、一寸柔情。料峭春寒中酒，交加晓梦啼莺。

西园日日扫林亭。依旧赏新晴。黄蜂频扑秋千索，有当时、纤手香凝。惆怅双鸳不到，幽阶一夜苔生。

## 注释

- **风入松**：词牌名，又名《风入松慢》。双调七十六字。
- **清明**：清明节。
- **愁草瘗花铭**：愁于起草葬花的铭文。瘗，埋葬。铭，铭文。
- **绿暗**：绿叶浓密。
- **分携路**：分手分别的路。
- **一寸柔情**：一寸寸柔情。
- **料峭**：形容微寒。
- **中酒**：醉酒。
- **交加晓梦啼莺**：莺啼交加，惊破晓梦。
- **西园**：园名，此处指词人寓居之所。
- **林亭**：林间亭子。
- **新晴**：雨后初晴。
- **秋千索**：秋千的绳索。
- **纤手香凝**：纤手的香气凝留在秋千索上。
- **双鸳**：鸳鸯履，指女子的足迹。
- **幽阶**：幽静的台阶。
- **苔生**：长出青苔。

## 译文

听着风听着雨度过了清明。愁于起草葬花的铭文。楼前绿叶浓密的那条分手路上，一丝柳叶牵动一寸柔情。春寒料峭中醉了酒，莺啼交加惊破了晓梦。

西园林亭日日清扫。依旧欣赏雨后新晴。黄蜂频频扑向秋千绳索，上面还凝有当时纤手的香气。惆怅女子的足迹不再来，幽静的台阶上一夜长出了青苔。

## 赏析

这首词是吴文英的代表作之一，以清明为背景，写出了对逝去爱情的追思和孤寂之情，体现了吴文英词"绵密幽邃"的艺术风格。

上片写清明愁思。"听风听雨过清明"——听风听雨度过清明——以风雨写清明，奠定了凄清的基调。"愁草瘗花铭"——愁于起草葬花铭文——化用庾信《瘗花铭》，以葬花写伤春和伤逝。"楼前绿暗分携路，一丝柳、一寸柔情"——楼前绿叶浓密的分手路上，一丝柳一寸柔情——写昔日分别之路，以柳丝喻柔情。"料峭春寒中酒，交加晓梦啼莺"——春寒醉酒，莺啼惊破晓梦——写愁苦难眠和晓梦被莺啼惊破的惆怅。

下片写西园怀人。"西园日日扫林亭。依旧赏新晴"——日日扫西园林亭，依旧赏新晴——写等待中不忘整理园亭，期待故人重来。"黄蜂频扑秋千索，有当时、纤手香凝"——黄蜂频扑秋千索，因上面凝有纤手余香——以蜂扑秋千索写女子曾在此荡秋千，香气犹存，极为细腻。"惆怅双鸳不到，幽阶一夜苔生"——惆怅女子足迹不来，幽阶一夜生苔——以"一夜苔生"写等待之苦和孤独之深，化无情为有情。

"黄蜂频扑秋千索，有当时、纤手香凝"是全词的精妙之笔，以黄蜂扑索这一细微景象，写出纤手香凝的幻觉，将思念之情写得极为细腻入微。"幽阶一夜苔生"以夸张手法写等待之久，化为深情的想象。全词意象绵密，时空交错，体现了吴文英词"如七宝楼台，眩人眼目"的特色。

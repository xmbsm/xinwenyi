# 满庭芳·山抹微云

**[宋] [秦观](/authors/qinguan)**

## 原文

山抹微云，天连衰草，画角声断谯门。暂停征棹，聊共引离尊。多少蓬莱旧事，空回首、烟霭纷纷。斜阳外，寒鸦万点，流水绕孤村。

销魂。当此际，香囊暗解，罗带轻分。谩赢得、青楼薄幸名存。此去何时见也，襟袖上、空惹啼痕。伤情处，高城望断，灯火已黄昏。

## 注释

- **满庭芳**：词牌名。
- **抹**：涂抹。
- **画角**：古代乐器，外加彩绘，故称画角。
- **谯门**：城门上的瞭望楼。
- **征棹**：远行的船。棹，船桨。
- **引离尊**：举杯饯别。引，举。尊，酒杯。
- **蓬莱旧事**：指在会稽（今绍兴）蓬莱阁的往事。
- **烟霭**：云雾。
- **销魂**：形容极度悲伤。
- **香囊暗解**：暗暗解下香囊赠别。
- **罗带轻分**：轻轻解下罗带分赠。
- **谩**：空，徒然。
- **薄幸**：薄情，负心。

## 译文

山间抹着微云，天边连着衰草，城门楼上画角声已断。暂停远行的船桨，姑且共举离别的酒杯。多少蓬莱阁的旧事，空回首只见烟霭纷纷。夕阳外，万点寒鸦，流水环绕着孤村。

令人销魂。此时此刻，暗暗解下香囊，轻轻分赠罗带。徒然赢得了青楼薄幸的名声。此去何时才能再见？衣袖上白白沾满泪痕。伤情之处，望断高城，灯火已是黄昏时分。

## 赏析

这首词是秦观离开会稽时为歌妓所作的离别词，以凄婉的笔调写出了离别的愁苦，是秦观婉约词的代表作。

上片写离别之景。"山抹微云，天连衰草"——山间抹着微云，天边连着衰草——"抹"字极妙，将微云如画般涂在山间，写出了暮秋的萧瑟。"画角声断谯门"——城楼画角声断——以角声的凄凉渲染离别的气氛。"暂停征棹，聊共引离尊"——暂停车船，共举离杯——写饯别的场景。"多少蓬莱旧事，空回首、烟霭纷纷"——蓬莱阁的旧事，回首只见烟霭——写往事如烟，不可追寻。"斜阳外，寒鸦万点，流水绕孤村"——夕阳外万点寒鸦，流水环绕孤村——以景结情，写出了离别的凄凉。这三句化用隋炀帝"寒鸦飞数点，流水绕孤村"之句，更为精妙。

下片写离别之情。"销魂"二字领起，写离别之痛。"香囊暗解，罗带轻分"——解香囊、分罗带——写赠别之物，含蓄地写出了两人的亲密。"谩赢得、青楼薄幸名存"——徒然得了薄幸之名——自嘲中含着无奈和苦涩。"此去何时见也，襟袖上、空惹啼痕"——此去何时再见，衣袖空沾泪痕——写别后的相思。"伤情处，高城望断，灯火已黄昏"——望断高城，已是黄昏灯火——以景作结，写出了行舟渐远、回望高城的深情。

全词以"抹"字和"连"字写出暮秋远景，以"斜阳外，寒鸦万点，流水绕孤村"写出离别凄景，以"天不老，情难绝"般的深情写别离之痛，是秦观婉约词的代表作，苏轼曾戏称秦观为"山抹微云秦学士"。

# 鹧鸪天·元夕有所梦

**[宋] [姜夔](/authors/jiangkui)**

## 原文

肥水东流无尽期，当初不合种相思。梦中未比丹青见，暗里忽惊山鸟啼。

春未绿，鬓先丝。人间别久不成悲。谁教岁岁红莲夜，两处沉吟各自知。

## 注释

- **鹧鸪天**：词牌名。
- **元夕**：元宵节。
- **肥水**：源出安徽合肥，此处指词人在合肥的一段情事。
- **不合**：不该。
- **种相思**：种下相思之情。
- **丹青**：画像。
- **见**：同"现"，显现。
- **春未绿**：春天尚未使草木变绿。
- **鬓先丝**：鬓发已经白如丝。
- **不成悲**：不觉得悲伤，指悲痛已极反而麻木。
- **红莲夜**：元宵夜。红莲指红莲花灯。
- **沉吟**：默默思念。

## 译文

肥水东流没有尽头，当初不该种下这相思之情。梦中相见还不如画像清晰，暗中被山鸟的啼叫惊醒。

春草还未变绿，鬓发已经白如丝。人间离别太久反而不觉悲伤。是谁让年年元宵之夜，两处默默思念各自心知。

## 赏析

这首词是姜夔为悼念合肥情人所作，以元宵梦醒为契机，写出了深沉的相思和离别之苦，是姜夔词中感情最为真切的代表作之一。

上片写梦醒后的感慨。"肥水东流无尽期，当初不合种相思"——肥水东流没有尽头，当初不该种下相思——以肥水起兴，写相思之无尽；"不合"二字是悔恨之语，实则是深情之极——不是真的后悔，而是痛悔相思之苦。"梦中未比丹青见，暗里忽惊山鸟啼"——梦中相见还不如画像清晰，暗中被山鸟惊醒——梦中相见已经模糊，还不如画像清楚，却被鸟啼惊醒，连模糊的梦也做不成了。这两句写出了梦醒后的失望和怅惘。

下片写别后的深情。"春未绿，鬓先丝"——春草未绿而鬓发已白——以春未绿反衬鬓先丝，写出了岁月的流逝和人的衰老。"人间别久不成悲"——离别太久反而不再觉得悲伤——这是全词最深刻的句子，不是不悲，而是悲到极处反而不觉悲了，这种"不成悲"比"悲"更加深沉。"谁教岁岁红莲夜，两处沉吟各自知"——是谁让年年元宵夜，两处默默思念各自心知——以问句作结，写出了两人天各一方、各自思念的深沉痛苦。"各自知"三字，写出了相思的孤独——只有自己知道这份思念，对方也在思念，但彼此无法交流。

全词感情深沉真切，"人间别久不成悲"一句尤为深刻，写出了久别之痛的极致——不是不悲，而是悲极反不觉悲。这种深沉的感情，在姜夔以"清空"著称的词风中，别具一格。

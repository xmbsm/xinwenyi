# 浪淘沙·把酒祝东风

**[宋] [欧阳修](/authors/ouyangxiu)**

## 原文

把酒祝东风，且共从容。垂杨紫陌洛城东。总是当时携手处，游遍芳丛。

聚散苦匆匆，此恨无穷。今年花胜去年红。可惜明年花更好，知与谁同？

## 注释

- **浪淘沙**：词牌名。
- **把酒**：端起酒杯。
- **祝**：祝祷。
- **从容**：悠闲舒缓，留连不迫。
- **紫陌**：京城的道路。洛城，洛阳。
- **携手处**：当年携手同游之处。
- **芳丛**：花丛。
- **匆匆**：急促的样子。

## 译文

端起酒杯祝告东风，请它从容地吹拂。在洛阳城东垂杨飘拂的紫陌上。那里正是当年携手同游之处，游遍了芬芳的花丛。

聚散苦于太匆忙，这种遗憾无穷无尽。今年的花比去年更红艳。可惜明年的花会更好，不知与谁同赏？

## 赏析

这首词是欧阳修在洛阳与友人游春时所作，以祝东风起兴，抒发了聚散匆匆的感慨和对友情的珍重，感情真挚，语言流畅。

上片写游春之景。"把酒祝东风，且共从容"——端酒祝告东风，请它从容不迫地吹拂——以祝东风起笔，写出了惜春之情，希望春光留得久些。"垂杨紫陌洛城东"——洛阳城东紫陌上垂杨飘拂——点明了游春的地点。"总是当时携手处，游遍芳丛"——这里正是当年携手同游之处，游遍了花丛——由今日之游回忆当年之游，"携手"二字写出了友情的深厚。

下片写聚散之慨。"聚散苦匆匆，此恨无穷"——聚散苦于太匆忙，这种遗憾无穷无尽——由游春之乐转入离别之愁，"匆匆"二字写出了相聚之短，"此恨无穷"写出了离别之苦。"今年花胜去年红"——今年的花比去年更红——花虽更好，但花好与人聚并非同步。"可惜明年花更好，知与谁同"——明年的花会更好，但不知与谁同赏——以问句作结，写出了对未来的不确定感和对友情的眷恋。

全词以花为线索，将过去、现在、未来三个时间维度串联起来：去年携手游花丛，今年花胜去年红，明年花更好却不知与谁同。这种层层递进的结构，将聚散匆匆的感慨写得层层深入。结句"知与谁同"以问句作结，余味无穷，是欧阳修词中脍炙人口的名篇。

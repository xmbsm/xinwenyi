# 点绛唇·丁未冬过吴松作

**[宋] [姜夔](/authors/jiangkui)**

## 原文

燕雁无心，太湖西畔随云去。数峰清苦，商略黄昏雨。

第四桥边，拟共天随住。今何许。凭栏怀古，残柳参差舞。

## 注释

- **点绛唇**：词牌名。
- **丁未**：宋孝宗淳熙十四年（1187年）。
- **吴松**：即吴淞江，太湖的支流。
- **燕雁**：北方飞来的大雁。
- **无心**：没有机心，任运自然。
- **太湖**：在今江苏南部。
- **清苦**：形容山峰的清寒凄苦。
- **商略**：商量，酝酿。
- **第四桥**：即甘泉桥，在吴淞江上。
- **天随**：晚唐诗人陆龟蒙，号天随子，隐居松江。
- **何许**：何处，什么样。
- **参差**：高低不齐。

## 译文

北方飞来的大雁没有机心，在太湖西畔随着云彩飞去。几座山峰显得清寒凄苦，正在商量着黄昏时下一场雨。

第四桥边，我打算与天随子为邻而居。如今是什么光景？凭栏怀想古人，只见残柳在风中参差起舞。

## 赏析

这首词是姜夔途经吴淞江时所作，以清冷的笔调写出了 winter日的萧瑟和对隐逸生活的向往，体现了姜夔词清空骚雅的特色。

上片写吴淞冬景。"燕雁无心，太湖西畔随云去"——北方飞来的大雁没有机心，在太湖西畔随云而去——"无心"二字是全词的关键，写出了雁的任运自然，也暗含词人对无心之境的向往。"数峰清苦，商略黄昏雨"——几座山峰显得清寒凄苦，正在酝酿黄昏的雨——"清苦"二字将山峰拟人化，写出了冬山的萧瑟；"商略"二字更是奇妙，山峰在"商量"下雨，将无情的山峰写得有情。这两句是姜夔的千古名句，以奇特的拟人写出了冬日的清寒。

下片写怀古之情。"第四桥边，拟共天随住"——第四桥边，打算与陆龟蒙为邻——以陆龟蒙自比，写出了对隐逸生活的向往。"今何许"——如今是什么光景——一声感叹，含着对时代的感慨。"凭栏怀古，残柳参差舞"——凭栏怀想古人，只见残柳在风中参差起舞——以景作结，"残柳参差舞"写出了冬柳的萧瑟，也写出了词人心中的苍凉。

全词以"清空"为特色，"数峰清苦，商略黄昏雨"一句尤为后人称道，将山峰拟人化，写得既清冷又生动，是姜夔"清空骚雅"词风的典型体现。

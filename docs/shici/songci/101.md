# 洞仙歌·冰肌玉骨

**[宋] [苏轼](/authors/sushi)**

## 原文

冰肌玉骨，自清凉无汗。水殿风来暗香满。绣帘开，一点明月窥人，人未寝，欹枕钗横鬓乱。

起来携素手，庭户无声，时见疏星渡河汉。试问夜如何？夜已三更，金波淡，玉绳低转。但屈指西风几时来，又不道流年暗中偷换。

## 注释

- **洞仙歌**：词牌名。此词为苏轼据蜀主孟昶与花蕊夫人纳凉之词续补而成。
- **冰肌玉骨**：形容女子肌肤莹润如冰如玉。
- **水殿**：建于水边的宫殿。
- **暗香**：幽香。
- **欹枕**：斜靠枕头。欹，倾斜。
- **素手**：洁白的手。
- **河汉**：银河。
- **金波**：月光。
- **玉绳**：星名，在北斗星附近。
- **不道**：不觉。
- **流年**：如水般流逝的时光。

## 译文

她肌肤如冰如玉，自然清凉没有汗意。水殿中微风吹来，暗香弥漫。绣帘拉开，一线明月照进来偷看，人还没有入睡，斜靠着枕头，金钗横斜，鬓发散乱。

起来牵着她的素手，庭院中一片寂静，不时看见疏星划过银河。试问今夜如何？已是三更时分，月光淡淡，玉绳星已低转。只需屈指算算秋风何时到来，却不觉流年已在暗中偷换。

## 赏析

这首词是苏轼据五代后蜀孟昶与花蕊夫人夏夜纳凉之残词续补而成，描绘了一个清幽高雅的夏夜宫廷生活场景，抒发了流年暗换的感慨。

上片写夏夜纳凉的情景。"冰肌玉骨，自清凉无汗"，先写花蕊夫人的美丽和清凉——肌肤如冰如玉，自然清凉无汗，既写出了美人的天生丽质，又写出了夏夜水殿的凉爽。"水殿风来暗香满"，水殿中微风带来幽香——"暗香"二字，写出了香气的若有若无。接着以"绣帘开，一点明月窥人"写月光的偷窥——"窥"字将明月拟人化，生动有致；"人未寝，欹枕钗横鬓乱"，写美人未眠的慵懒姿态。

下片写夜深出游和流年之慨。"起来携素手，庭户无声"，牵着素手起来，庭院一片寂静——写出了夜的宁静。"时见疏星渡河汉"，偶尔看见疏星划过银河——写出了夜深的时间感。"试问夜如何？夜已三更，金波淡，玉绳低转"，以问答写时间的推移——月光渐淡，玉绳星低转，已是深夜。结句"但屈指西风几时来，又不道流年暗中偷换"，是全词的警策——只顾算着秋风何时到来，却不觉流年已在暗中偷换。这结句由夏夜纳凉引出人生感慨，意境深远，是全词的点睛之笔。

# 折桂令·九日

**元 · [张可久](/authors/zhangkejiu)**

## 原文

对青山强整乌纱。归雁横秋，倦客思家。翠袖殷勤，金杯错落，玉手琵琶。人老去西风白发，蝶愁来明日黄花。回首天涯，一抹斜阳，数点寒鸦。

## 注释

- **折桂令**：曲牌名，又名"蟾宫曲"。
- **九日**：农历九月初九重阳节。
- **强整乌纱**：勉强整理乌纱帽。乌纱，官员所戴的乌纱帽。用孟嘉重阳落帽典故，反其意而用之。
- **归雁横秋**：归雁横列于秋空。
- **倦客**：疲倦的客子。
- **翠袖殷勤**：指歌妓殷勤劝酒。翠袖，绿色衣袖，代指歌妓。
- **金杯错落**：金杯交错。错落，交错的样子。
- **玉手琵琶**：玉手弹奏琵琶。
- **人老去西风白发**：人在西风中老去，白发渐生。
- **蝶愁来明日黄花**：蝴蝶也为明日的黄花而愁。黄花，菊花，重阳节赏菊。明日黄花，比喻过时之物。
- **天涯**：天边，指遥远的地方。
- **一抹斜阳**：一片夕阳余晖。
- **寒鸦**：寒天的乌鸦。

## 译文

面对青山勉强整理乌纱帽。归雁横列秋空，疲倦的客子思念家乡。翠袖的歌妓殷勤劝酒，金杯交错，玉手弹奏琵琶。人在西风中老去，白发渐生；蝴蝶也为明日的黄花而愁。回首天涯，一片斜阳余晖，几只寒鸦。

## 赏析

张可久的《折桂令·九日》是一首重阳佳节思乡之作，以清丽的笔调和深沉的情感，抒发了客居他乡的倦游之感和人生易老的慨叹。

起句"对青山强整乌纱"以"强整"二字领起，写出勉强过节的心态。重阳佳节，本应登高赏菊，但客居他乡的诗人却只能"强整乌纱"——勉强整理官帽，应付节日。一个"强"字，道出了内心的勉强和无奈。"归雁横秋，倦客思家"两句，由景入情——归雁横列秋空，引发倦客的思乡之情。雁能归而人不能归，对比之中见出客愁。

"翠袖殷勤，金杯错落，玉手琵琶"三句写节日宴饮的盛况。歌妓殷勤劝酒，金杯交错，琵琶声声——表面热闹，实则反衬客愁。这三句对仗工整，色彩鲜明，写出了宴席的繁华，但"倦客"的心境并未因此改变。

"人老去西风白发，蝶愁来明日黄花"两句是全曲的警句。"人老去"对"蝶愁来"，"西风白发"对"明日黄花"，对仗极为工整。"西风白发"写人之衰老——西风中白发渐生；"明日黄花"用典精妙——重阳过后菊花将萎，连蝴蝶也要发愁。这两句将人生易老与节物变迁融为一体，意境深远。

结句"回首天涯，一抹斜阳，数点寒鸦"以景作结。回首天涯，只见一抹斜阳、数点寒鸦——萧瑟的秋景，正是客子心境的写照。"一抹""数点"两个数量词，写出了景物的疏落和心境的孤寂。

全曲最大的艺术特色是对仗的工整和意境的萧瑟。"翠袖殷勤，金杯错落，玉手琵琶"三句鼎足对，"人老去西风白发，蝶愁来明日黄花"两句工对，都是元散曲中对仗的典范。语言清丽典雅，意境萧瑟深远，体现了张可久散曲清丽派的典型风格。

# 落梅风·烟寺晚钟

**[元] [马致远](/authors/mazhiyuan)**

## 原文

寒烟细，古寺清，近黄昏礼佛人静。顺西风晚钟三四声，怎生教老僧禅定？

## 注释

- **落梅风**：曲牌名，又名"寿阳曲"，属双调。
- **烟寺晚钟**：潇湘八景之一。烟寺，烟雾笼罩的寺庙。
- **寒烟**：寒凉的烟雾。
- **古寺**：古老的寺庙。
- **礼佛**：拜佛。
- **禅定**：佛教修行方法，指心专注一境，不为外物所动。

## 译文

寒烟细细飘荡，古寺清幽寂静，将近黄昏时分，礼佛之人已经安静下来。顺着西风传来三四声晚钟，怎能让老僧安然禅定呢？

## 赏析

马致远的《落梅风·烟寺晚钟》是"潇湘八景"组曲之一，描绘了一幅古寺晚景图。首句"寒烟细"，以寒凉细腻的烟雾渲染出秋日傍晚的清冷氛围。次句"古寺清"，写古寺的清幽寂静。第三句"近黄昏礼佛人静"，写黄昏时分礼佛之人散去后的寂静。

末两句"顺西风晚钟三四声，怎生教老僧禅定"，是全曲的点睛之笔。晚钟三四声，本应助人入定，然而钟声随西风传来，反而搅动了老僧的心绪，使其难以禅定。一个"怎生教"，写出钟声对心境的扰动，含蓄地表达了内心的不平静。全曲以景衬情，以动衬静，营造出一种清幽而略带惆怅的意境。

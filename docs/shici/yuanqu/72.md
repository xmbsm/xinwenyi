# 山坡羊·北邙山怀古

**[元] [张养浩](/authors/zhangyanghao)**

## 原文

悲风成阵，荒烟埋恨，碑铭残缺应难认。知他是汉朝君，晋朝臣？把风云庆会消磨尽，都做北邙山下尘。便是君，也唤不应；便是臣，也唤不应！

## 注释

- **山坡羊**：曲牌名，属中吕。
- **北邙山**：即邙山，在河南洛阳北，是历代王公贵族的墓地。
- **悲风成阵**：悲凉的风成阵吹来。
- **荒烟**：荒野的烟雾。
- **碑铭**：墓碑上的铭文。
- **风云庆会**：风云际会，指君臣遇合的盛事。
- **唤不应**：叫不答应，指人已死去。

## 译文

悲风阵阵吹来，荒烟埋葬了遗恨，墓碑铭文残缺难以辨认。谁知道他是汉朝的君主，还是晋朝的臣子？把那些风云际会的盛事都消磨尽了，都成了北邙山下的尘土。便是君主，也叫不答应；便是臣子，也叫不答应！

## 赏析

张养浩的《山坡羊·北邙山怀古》是一首以洛阳北邙山为题材的怀古之作。北邙山是历代王公贵族的墓地，作者以此地起兴，感叹历史的虚无。

首三句"悲风成阵，荒烟埋恨，碑铭残缺应难认"，以悲风、荒烟、残碑三个意象，渲染出北邙山的荒凉景象。墓碑铭文残缺难认，昔日显赫之人已无人知晓。四、五句"知他是汉朝君，晋朝臣？把风云庆会消磨尽，都做北邙山下尘"，以诘问的口吻写历史的湮没，无论汉朝君主还是晋朝臣子，无论曾有何等风云际会，最终都化为北邙山下尘土。

末两句"便是君，也唤不应；便是臣，也唤不应"，以重复的句式强调死亡的平等，无论君臣，死后都叫不答应。全曲语言苍凉，意境悲壮，于怀古中寄寓了对人生无常的深刻感悟，与作者的《山坡羊·潼关怀古》有异曲同工之妙。

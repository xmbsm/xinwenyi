# 朱履曲·警世

**[元] [张养浩](/authors/zhangyanghao)**

## 原文

弄世界机关识破，叩天门意气消磨，人潦倒青山慢嵯峨。前面有千古远，后头有万年多，量半炊时成得甚么。

## 注释

- **朱履曲**：曲牌名，属中吕。即"红绣鞋"。
- **警世**：警醒世人。
- **弄世界**：在世间周旋。
- **机关**：计谋，心机。
- **叩天门**：指求取功名。天门，喻朝廷。
- **潦倒**：失意，颓丧。
- **慢**：同"漫"，随意，任凭。
- **嵯峨**：山高峻貌。此处指任凭青山高峻，自己却无心欣赏。
- **半炊**：半顿饭的功夫，喻时间短暂。典出"黄粱一梦"。

## 译文

在世间周旋，机关算尽终被识破；叩天门求取功名，意气消磨殆尽。人潦倒之时，任凭青山嵯峨也无心欣赏。前面有千古之远，后面有万年之多，衡量这半炊之功能成就什么呢？

## 赏析

张养浩的《朱履曲·警世》是一首警世之作，感叹人生短暂，功名虚幻。

首句"弄世界机关识破"，写在世间周旋的心机终被识破，仕途的算计终归徒劳。次句"叩天门意气消磨"，写求取功名的意气在现实中消磨殆尽。第三句"人潦倒青山慢嵯峨"，写失意之时，任凭青山嵯峨也无心欣赏，以景衬情。

末三句"前面有千古远，后头有万年多，量半炊时成得甚么"，以时间的长远反衬人生的短暂。前有千古，后有万年，而人生不过半炊之工，又能成就什么呢？一个"量"字，写尽对人生功业的怀疑。全曲语言通俗，意境苍凉，于警世中寄寓了对人生虚无的深刻感悟。

# 哨遍·高祖还乡

**元 · [睢景臣](/authors/suijingchen)**

## 原文

[哨遍]社长排门告示，但有的差使无推故，这差使不寻俗。一壁厢纳草也根，一边又要差夫，索应付。又言是车驾，都说是銮舆，今日还乡故。王乡老执定瓦台盘，赵忙郎抱着酒葫芦。新刷来的头巾，恰糨来的绸衫，畅好是妆幺大户。

[耍孩儿]瞎王留引定火乔男女，胡踢蹬吹笛擂鼓。见一颩人马到庄门，匹头里几面旗舒：一面旗白胡阑套住个迎霜兔，一面旗红曲连打着个毕月乌，一面旗鸡学舞，一面旗狗生双翅，一面旗蛇缠葫芦。

[五煞]红漆了叉，银铮了斧，甜瓜苦瓜黄金镀。明晃晃马镫枪尖上挑，白雪雪鹅毛扇上铺。这几个乔人物，拿着些不曾见的器仗，穿着些大作怪衣服。

[四煞]辕条上拴着马，老辕条上拴着牛，草梢上蘸着黄土。打一面破皮鼓，一个寄槽刷了一把杆子不剌叉，一个上头戴一顶镔铁盔。

[三煞]那大汉下的车，众人施礼数。那大汉觑得人如无物。众乡老展脚舒腰拜，那大汉挪身着手扶。猛可里抬头觑，觑多时认得，险气破我胸脯。

[二煞]你须身姓刘，你妻须姓吕，把你两家儿根脚从头数：楼上做煎胶柱树，淘气力做了亭长，耽了几盏酒。你丈人教村学，读几卷书；也在俺庄东住，也曾与我喂牛切草，拽坝扶锄。

[一煞]春采了桑，冬借了俺粟，零支了米麦无重数。换田契强秤了麻三秤，还酒债偷量了豆几斛。有甚胡突处？明标着册历，见放着文书。

[尾]少我的钱，差发内旋拨还；欠我的粟，税粮中私准除。只道刘三，谁肯把你揪捽住？白甚么改了姓、更了名、唤做汉高祖！

## 注释

- **哨遍**：曲牌名，此为套数。
- **高祖还乡**：汉高祖刘邦称帝后荣归故里事。
- **社长**：村社之长。排门告示：挨门挨户通知。
- **不寻俗**：不寻常。
- **一壁厢**：一边。
- **车驾、銮舆**：都指皇帝的车马。
- **瓦台盘**：陶制的托盘。
- **妆幺大户**：装作大户人家的派头。
- **瞎王留**：乡民诨名。火：伙。乔男女：怪模怪样的人。
- **一颩**：一队。匹头里：迎面。
- **白胡阑套住个迎霜兔**：月旗的形象，白环中画兔。
- **红曲连打着个毕月乌**：日旗的形象，红圈中画乌鸦。
- **鸡学舞**：舞凤旗。狗生双翅：飞虎旗。蛇缠葫芦：蟠龙旗。
- **甜瓜苦瓜黄金镀**：指金瓜锤。
- **马镫枪尖上挑**：画戟。
- **鹅毛扇**：雉尾扇。
- **乔人物**：怪人物。
- **寄槽刷**：不明其意，应为乡民对仪仗的俗称。
- **猛可里**：猛然间。
- **煎胶柱树**：喻指做木工活。
- **亭长**：刘邦曾任泗水亭长。
- **拽坝扶锄**：拉耙扶锄，干农活。
- **胡突**：糊涂。
- **册历**：账本。
- **差发内旋拨还**：从派发的款项中马上扣除归还。
- **私准除**：私下里抵扣。
- **刘三**：刘邦排行第三，故称。
- **白甚么**：凭什么无故地。

## 译文

社长挨门挨户通知，凡有的差使不得推辞，这次差使不同寻常。一边要交纳草料，一边又要征派差夫，必须应付。又说是车驾，都说是銮舆，今日还乡。王乡老捧着瓦台盘，赵忙郎抱着酒葫芦。新刷洗的头巾，刚浆洗的绸衫，正好像装腔作势的大户人家。

瞎王留领着一伙怪模怪样的人，胡乱吹笛擂鼓。见一队人马到了庄门，迎面几面旗展开：一面白环套着迎霜兔，一面红圈打着毕月乌，一面鸡学舞，一面狗生双翅，一面蛇缠葫芦。

红漆的叉，银饰的斧，甜瓜苦瓜都镀了金。明晃晃的马镫在枪尖上挑着，白雪雪的鹅毛铺在扇上。这几个怪人物，拿着些没见过的器仗，穿着些奇装异服。

辕条上拴着马，辕条上拴着牛，草梢上蘸着黄土。打着一面破皮鼓，一个拿着不剌叉，一个头上戴着镔铁盔。

那大汉下了车，众人行礼。那大汉把人看得如同无物。众乡老展脚舒腰地拜，那大汉挪动身子用手扶。猛然间抬头一看，看了多时认了出来，险些气破我的胸脯。

你不是姓刘吗，你妻子不是姓吕吗，把你们两家的根底从头数来：你曾做木工活，又出力做了亭长，喝了几盏酒。你丈人教村学，读了几卷书，也在我们庄东住，也曾和我一起喂牛切草，拉耙扶锄。

春天采了我的桑叶，冬天借了我的粟米，零碎借支了米麦无数。换田契时强行多秤了三秤麻，还酒债时偷着少量了几斛豆。有什么糊涂处？账本上明写着，文书都摆在那里。

欠我的钱，从差发中立即扣除归还；欠我的粟，从税粮中私下抵扣。只叫你刘三，谁肯把你揪住？凭什么无故改了姓、更了名，叫做汉高祖！

## 赏析

睢景臣的《哨遍·高祖还乡》是元散曲套数中的名篇杰作，以独特的视角和辛辣的讽刺，解构了汉高祖刘邦"威加海内兮归故乡"的庄严神话，展现了元代散曲讽刺艺术的最高成就。

全套由哨遍、耍孩儿、五煞、四煞、三煞、二煞、一煞、尾八支曲子组成，以一个熟悉刘邦底细的乡民口吻，讲述汉高祖还乡的盛况。开篇"社长排门告示"写乡里的忙碌准备，"王乡老执定瓦台盘，赵忙郎抱着酒葫芦"等句，以诙谐笔调写乡民们装模作样的可笑姿态，为后文的讽刺埋下伏笔。

第二、三支曲子写皇家仪仗，但作者别出心裁地用乡民的视角来描述：月旗成了"白胡阑套住个迎霜兔"，日旗成了"红曲连打着个毕月乌"，凤旗是"鸡学舞"，飞虎旗是"狗生双翅"，蟠龙旗是"蛇缠葫芦"——这些庄严的皇家旗帜被解构成了滑稽的乡间事物，金瓜锤成了"甜瓜苦瓜黄金镀"，画戟成了"马镫枪尖上挑"。这种视角的转换，使庄严的皇家排场变得荒诞可笑，体现了作者高超的讽刺艺术。

三煞是全曲的转折点。"那大汉觑得人如无物"写刘邦的傲慢，"猛可里抬头觑，觑多时认得，险气破我胸脯"写乡民的震惊和愤怒——原来这个威风凛凛的皇帝竟是昔日的无赖刘三！这一转折既出人意料，又在情理之中。

二煞、一煞、尾三支曲子，乡民当众揭刘邦的老底："也曾与我喂牛切草，拽坝扶锄"，"春采了桑，冬借了俺粟"，"换田契强秤了麻三秤，还酒债偷量了豆几斛"——一系列陈年旧账，将刘邦昔日的无赖行径和盘托出。结尾"只道刘三，谁肯把你揪捽住？白甚么改了姓、更了名、唤做汉高祖"一句，以乡民的口吻直接质疑皇权的神圣性，将讽刺推向高潮。

全套曲最大的艺术特色是视角的独特和语言的诙谐。作者以乡民视角解构帝王神话，使庄严与滑稽、神圣与世俗形成强烈反差。语言既有散曲特有的俗语方言，又有生动的描摹和辛辣的讽刺，体现了元代散曲"豪放诙谐"的典型风格，是中国古典文学中讽刺艺术的杰作。

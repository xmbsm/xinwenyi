# 落梅风·远浦秋帆

**[元] [马致远](/authors/mazhiyuan)**

## 原文

夕阳下，酒旆闲，两三航未曾着岸。落花水香茅舍晚，断桥头卖鱼人散。

## 注释

- **落梅风**：曲牌名，又名"寿阳曲"，属双调。
- **远浦秋帆**：潇湘八景之一。浦，水边。远浦，遥远的水边。
- **酒旆**：酒旗，酒家悬挂的幌子。旆，旗帜。
- **闲**：悠闲，指酒旗在风中悠闲飘动。
- **航**：船只。
- **着岸**：靠岸。
- **落花水香**：落花飘在水面，使水带花香。
- **断桥**：残断的桥。

## 译文

夕阳西下，酒旗悠闲地飘动，两三只船还未曾靠岸。落花飘在水面，水带花香，茅舍沐浴在傍晚的余晖中。断桥头边，卖鱼的人已经散去。

## 赏析

马致远的《落梅风·远浦秋帆》是"潇湘八景"组曲之一，描绘了一幅秋日傍晚的水乡图景。首句"夕阳下，酒旆闲"，以夕阳、酒旗两个意象，营造出悠闲恬静的氛围。次句"两三航未曾着岸"，写远处两三只船尚未靠岸，动静相宜，给人以悠远之感。

末两句"落花水香茅舍晚，断桥头卖鱼人散"，将镜头拉近，落花、水香、茅舍、断桥、卖鱼人散，种种意象叠加，构成一幅宁静的水乡晚景图。一个"散"字，写尽渔村傍晚的恬静与闲适。全曲语言凝练，意境悠远，以白描手法勾勒出水乡秋暮的宁静之美，是马致远写景小令的代表作之一。

# 折桂令·赠胡存善

**元 · [王举之](/authors/wangjuzhi)**

## 原文

上都来主是风流，诗句留传，东海西州。天下文章，胡存善四海交游。虫鱼老去，兔管秃休。有斗酒双鱼，受用一襟秋。问甚么鳞角，但闻处是珠楼。

## 注释

- **折桂令**：曲牌名，又名"蟾宫曲"。
- **胡存善**：元末散曲家胡正臣之子，能传父业。
- **上都**：元代上都，在今内蒙古正蓝旗。此处"上都来"疑为"上都客"或"西都来"之误，指自京城而来。
- **主**：一作"客"。
- **东海西州**：泛指各地。
- **天下文章**：指胡存善精通天下文章。
- **四海交游**：四海之内都有交游。
- **虫鱼**：指考据注释之学，源于《尔雅》有《释虫》《释鱼》篇。
- **老去**：老去，指年事已高。
- **兔管**：兔毛笔，指毛笔。
- **秃休**：用秃了，停下不再写。
- **斗酒双鱼**：一杯酒，一对鱼，指简单的款待。
- **一襟秋**：满怀秋意，指心情清逸。
- **鳞角**：鱼鳞和兽角，喻指琐碎之物。
- **珠楼**：珠玉之楼，喻指佳作荟萃之地。

## 译文

从京城来的客人风流倜傥，诗句流传于东海西州。天下文章，胡存善与四海之交游。考据之学已老去，毛笔用秃了方休。有斗酒双鱼款待，受用满怀秋意。问什么鳞角琐事，但凡闻到之处皆是珠玉之楼。

## 赏析

王举之的《折桂令·赠胡存善》是一首赠友之作，以赞美的笔调描绘了胡存善的才情与品格，体现了元代文人之间以曲相赠的风尚。

起句"上都来主是风流"以"风流"二字总评胡存善。"风流"在元人语境中，既指才华出众，也指品格脱俗。"诗句留传，东海西州"一句写其诗名远播——诗句流传于东海西州，可见其影响之广。"天下文章，胡存善四海交游"两句进一步写其学问与交游：精通天下文章，与四海之士交游。这既是对胡存善才华的赞美，也写出他作为元代文坛名士的地位。

"虫鱼老去，兔管秃休"两句写胡存善的勤学。"虫鱼"代指考据之学，"老去"二字见其年事已高；"兔管"即毛笔，"秃休"二字见其写作之勤——毛笔用秃了才肯停休。这两句既写出胡存善的学识渊博，也写出他的勤奋不怠，是一位真正的学者型文人。

"有斗酒双鱼，受用一襟秋"两句写其生活情趣。斗酒双鱼，是简单的款待；"受用一襟秋"五字尤妙——满怀秋意，既是写时令，也是写心境。秋代表着清逸、高远，"一襟秋"三字将胡存善清雅脱俗的精神境界写得淋漓尽致。

结句"问甚么鳞角，但闻处是珠楼"以反问作结，余味无穷。"鳞角"喻琐碎之物，"珠楼"喻佳作荟萃之地。两句意谓：不必问那些琐碎之事，但凡胡存善所在之处，便是珠玉荟萃之地。这是对胡存善才华的最高赞美——其人所在，即是文采风流之地。

全曲最大的艺术特色是赞美之中见真情。作者以简练的笔触勾勒出胡存善的形象——风流、博学、勤勉、清雅，既有对其才华的赞美，也有对其品格的敬重。语言典雅而不失流畅，体现了赠答之作的应有格调。

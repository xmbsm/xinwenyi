# 寿阳曲·山市晴岚

**元 · [马致远](/authors/mazhiyuan)**

## 原文

花村外，草店西，晚霞明雨收天霁。四围山一竿残照里，锦屏风又添铺翠。

## 注释

- **寿阳曲**：曲牌名，又名"落梅风"，属双调。
- **山市晴岚**：潇湘八景之一，指雨后山间市镇在晴光中浮现的岚气。
- **花村**：开满野花的山村。
- **草店**：茅草盖顶的客店。
- **晚霞明**：晚霞明亮。
- **雨收天霁**：雨停了，天空放晴。霁，雨后天晴。
- **四围山**：四面环山。
- **一竿残照**：形容夕阳距山仅一竿之高，即将落山。残照，夕阳余晖。
- **锦屏风**：喻指群山如锦绣屏风。
- **铺翠**：铺上一层翠色，形容雨后山色更加青翠欲滴。

## 译文

花村之外，草店之西，晚霞明亮，雨收云散，天空放晴。四围的群山笼罩在一竿高的夕阳余晖之中，如锦绣屏风又添了一层翠色。

## 赏析

马致远的《寿阳曲·山市晴岚》是其著名的"潇湘八景"组曲之一，描绘了一幅雨后山间市镇的优美画卷，体现了作者对自然山水的热爱和细腻的观察力。

起句"花村外，草店西"以简淡的笔法点明地点，花开满村，草店坐落，营造出一种宁静恬淡的田园氛围。"晚霞明雨收天霁"一句，写雨后初晴的景象：晚霞明亮，天空如洗，雨后的清新气息扑面而来。这一句既是写景，也是定下全曲清朗明快的基调。

后两句"四围山一竿残照里，锦屏风又添铺翠"是全曲的精华。"四围山"写出山市被群山环绕的环境，"一竿残照"形象地描绘出夕阳即将落山的瞬间，时间感极强。"锦屏风"的比喻新颖而贴切，将群山比作华丽的屏风，"又添铺翠"则写出了雨后山色格外青翠的特点——那层翠色仿佛是夕阳为新洗的群山又铺上了一层。

全曲仅二十七字，却囊括了山市、晴岚、晚霞、群山、夕阳等多种景物，构成一幅完整的画面。语言清新自然，意境优美空灵，体现了马致远散曲清丽淡雅的一面，与其豪放旷达的《天净沙·秋思》形成鲜明对照，展现了作者多样的艺术风格。

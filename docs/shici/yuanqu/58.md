# 庆东原·叹世

**[元] [白朴](/authors/baipu)**

## 原文

忘忧草，含笑花，劝君闻早冠宜挂。那里也能言陆贾？那里也良谋子牙？那里也豪气张华？千古是非心，一夕渔樵话。

## 注释

- **庆东原**：曲牌名，属双调。
- **忘忧草**：即萱草，传说食之可以忘忧。
- **含笑花**：一种花名，花开如含笑状。
- **闻早**：趁早。闻，同"趁"。
- **冠宜挂**：宜辞官归隐。典出王弘挂冠的神仙典故。
- **那里也**：哪里还有，意为都不见了。
- **能言陆贾**：陆贾，汉初谋士，以善辩著称，曾出使南越。
- **良谋子牙**：姜子牙，即吕尚，周初开国功臣，足智多谋。
- **豪气张华**：张华，西晋文学家、政治家，气度豪迈。
- **渔樵话**：渔夫樵夫的闲话，指乡野间的谈资。

## 译文

忘忧草、含笑花，劝你趁早挂冠归隐。哪里还有能言善辩的陆贾？哪里还有足智多谋的姜子牙？哪里还有气度豪迈的张华？千古的是非功过，不过是渔夫樵夫一夜的闲话罢了。

## 赏析

白朴的《庆东原·叹世》是一首叹世归隐之作。开头以"忘忧草，含笑花"起兴，既是写景，又以忘忧、含笑二名暗寓归隐之乐。第三句"劝君闻早冠宜挂"，直抒劝人归隐之意，点明主旨。

中间三句"那里也能言陆贾？那里也良谋子牙？那里也豪气张华"，以三个历史人物为例，发出"哪里还有"的诘问。陆贾善辩、子牙多谋、张华豪迈，这些显赫一时的人物如今都已烟消云散，以此说明功名利禄终归于空。末两句"千古是非心，一夕渔樵话"，以千古是非与一夕闲话对比，感慨万千，是非功过终成渔樵闲谈。全曲语言通俗，感慨深沉，体现了白朴对功名利禄的彻悟。

# 沉醉东风·渔夫

**[元] [白朴](/authors/baipu)**

## 原文

黄芦岸白蘋渡口，绿柳堤红蓼滩头。
虽无刎颈交，却有忘机友，
点秋江白鹭沙鸥。
傲杀人间万户侯，不识字烟波钓叟。

## 注释

- 沉醉东风：曲牌名
- 黄芦：枯黄的芦苇
- 白蘋：一种水生植物，俗称浮萍
- 红蓼：一种水边植物，开红花
- 刎颈交：可以同生死、共患难的朋友
- 忘机友：没有机心、淡泊名利的朋友，此处指白鹭沙鸥
- 点：点缀
- 傲杀：傲视至极
- 万户侯：古代爵位，食邑万户，泛指高官厚禄
- 烟波钓叟：在烟波浩渺中垂钓的老翁

## 译文

枯黄的芦苇岸边，白蘋丛生的渡口；绿柳低垂的堤岸，红蓼盛开的滩头。
虽然没有可以同生共死的刎颈之交，却有那些没有机心的忘机之友——点缀在秋江上的白鹭和沙鸥。
（这种生活）傲视人间那些万户侯，（我就是那个）不识字的烟波钓叟。

## 赏析

这首散曲描绘了一幅秋江垂钓图，表现了渔夫淡泊名利、超然物外的生活情趣，是元曲中隐逸题材的代表作。

"黄芦岸白蘋渡口，绿柳堤红蓼滩头"，开篇以两组对偶句描绘秋江景色。黄、白、绿、红四种色彩交相辉映，构成了一幅明丽而富有诗意的秋江图，点明了渔夫的居住环境。

"虽无刎颈交，却有忘机友，点秋江白鹭沙鸥"，写渔夫的精神世界。他没有世俗的知己，却有白鹭沙鸥这些"忘机友"相伴。"忘机"二字是关键，指没有机心、不图名利，这正是渔夫精神境界的写照。

"傲杀人间万户侯，不识字烟波钓叟"，以傲视王侯作结，将渔夫的形象升华。一个"傲"字，写出了隐士不慕荣利、蔑视权贵的高洁品格。"不识字"并非真的目不识丁，而是表明不涉世事、不通世故的质朴与纯真。全曲语言清丽，意境悠远，表达了作者对归隐生活的向往。

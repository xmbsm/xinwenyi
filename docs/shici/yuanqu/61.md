# 落梅风·潇湘夜雨

**[元] [马致远](/authors/mazhiyuan)**

## 原文

渔灯暗，客梦回，一声声滴人心碎。孤舟五更家万里，是离人几行清泪。

## 注释

- **落梅风**：曲牌名，又名"寿阳曲"，属双调。
- **潇湘夜雨**：潇湘八景之一。潇湘，湖南湘江的别称，因江水清深而得名。
- **渔灯**：渔船上的灯火。
- **客梦回**：旅客从梦中醒来。
- **心碎**：形容极度伤心。
- **五更**：天将明时，约凌晨三四点。
- **离人**：离别家乡之人。

## 译文

渔灯昏暗，旅客从梦中惊醒，一声声雨滴令人心碎。孤舟停泊在五更时分，家乡远在万里之外，这雨声仿佛是离人流淌的几行清泪。

## 赏析

马致远的《落梅风·潇湘夜雨》是"潇湘八景"组曲之一，写旅人夜泊潇湘的离愁别绪。首句"渔灯暗"，以昏暗的渔灯渲染出夜色的朦胧凄迷。次句"客梦回"，写旅客从梦中惊醒，梦醒后的孤寂更加难堪。第三句"一声声滴人心碎"，写雨声滴落，声声击在旅人心上，令人心碎。

末两句"孤舟五更家万里，是离人几行清泪"，将雨声与泪水融为一体。孤舟、五更、家万里，三个意象层层递进，将旅人的孤独与思乡之情推向极致。末句以"清泪"喻雨，又以雨喻泪，雨泪难分，情景交融。全曲语言凝练，意境凄美，是写客愁的佳作。

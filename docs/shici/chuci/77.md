# 天问·节选三

**[战国] [屈原](/authors/quyuan)**

## 原文

不任汩鴻，何以尚之？
僉曰何憂，何不課而行之？
鴟龜曳銜，鯀何聽焉？
順欲成功，帝何刑焉？
永遏在羽山，夫何三年不施？
伯禹腹鯀，天何以變之？

纂就前緒，遂成考功。
何續初繼業，而厥謀不同？
洪泉極深，何以窴之？
地方九則，何以墳之？
應龍何畫？河海何歷？

鯀何所營？禹何所成？
咸播秬黍，莆雚是營。
咸逃丘土，禹何取焉？
昆弟並淫，危害厥兄。
何變化以作詐，而後嗣逢長？

## 注释

- **汩鴻**：治理洪水。汩，治。鴻，通"洪"。
- **尚**：推举。
- **僉**：众人。
- **課**：试验。
- **鴟龜曳銜**：鸱龟拖衔，指治水的神异传说。
- **聽**：听信。
- **順欲成功**：顺其意愿即可成功。
- **遏**：囚禁。
- **羽山**：地名，鯀被处死之处。
- **施**：施刑。
- **伯禹腹鯀**：禹从鯀腹中出生。
- **纂就前緒**：继承前人事业。
- **考功**：父亲的事业。
- **洪泉**：洪水源泉。
- **窴**：填塞。
- **九則**：九州。
- **墳**：划分。
- **應龍**：有翼的龙，传说以尾画地成江。
- **秬黍**：黑黍。
- **莆雚**：芦苇杂草。
- **丘土**：高地。

## 译文

鯀不能胜任治水，为何还被推举？
众人说不必忧，为何不先试而行？
鸱龟拖衔，鯀为何听信？
顺其意愿即可成功，天帝为何施刑？
永远囚禁在羽山，为何三年不施刑？
伯禹从鯀腹中生出，天为何使之变化？

继承前人事业，完成父亲功业。
为何继续初业，而谋略不同？
洪水极深，如何填塞？
地方九州，如何划分？
应龙如何画地？河海如何流经？

鯀经营了什么？禹成就了什么？
都播种黑黍，经营芦苇杂草。
都逃往高地，禹取了什么？
兄弟并淫，危害其兄。
为何变化作诈，而后嗣却能逢吉而长？

## 赏析

《天问·节选三》集中追问鲧禹治水的神话传说，是《天问》中最具神话色彩的段落之一。诗人对鯀被推举治水却遭刑罚的命运表示质疑——"順欲成功，帝何刑焉"——即如果鯀能顺其意愿而成功，天帝为何还要施刑？这反映了诗人对天命公正性的思考。

"伯禹腹鯀"涉及禹从父亲鯀腹中出生的神话，诗人问"天何以變之"，对这种神异的诞生方式表示好奇。随后"纂就前緒，遂成考功"赞颂禹继承父业、完成治水之功，但又问"厥謀不同"，指出禹的治水方法与父亲不同。

"應龍何畫？河海何歷"追问应龙以尾画地成江的传说，展现了诗人丰富的神话知识。全段以连珠炮式的发问，对鲧禹治水的神话传说进行了系统的追问，既体现了诗人的探索精神，也保存了大量珍贵的神话资料。

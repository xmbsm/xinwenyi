# 九怀·思忠

**[汉] [王褒](/authors/wangbao)**

## 原文

登九灵兮游神，静淑清兮太微。
苍龙兮青虬，御飞廉兮骖螭。
登阆风兮抚云，超流沙兮越河。

览九州兮有余，横四海兮焉穷。
玄渊兮幽深，孰能测兮其中。
桂水兮潺湲，扬波兮并流。
蛟龙兮并跃，水兽兮相从。

思忠信兮愈笃，历远路兮长勤。
登太乙兮玉堂，览古今兮得失。
逢佳人兮同心，愿一觌兮无因。
时不可兮再得，恐迟暮兮何为。

## 注释

- **思忠**：思念忠信。
- **九灵**：九天之神。
- **游神**：神游。
- **淑清**：清澈。
- **太微**：太微垣，星宿名。
- **苍龙**：青龙。
- **青虬**：青色的虬龙。
- **飞廉**：风神。
- **骖螭**：以螭龙为骖。
- **阆风**：昆仑山上的仙境。
- **流沙**：沙漠。
- **九州**：天下九州。
- **四海**：天下。
- **玄渊**：深渊。
- **桂水**：桂林之水。
- **潺湲**：水流平缓。
- **蛟龙**：传说中能发水的龙。
- **笃**：深厚。
- **太乙**：太一，天神。
- **玉堂**：神仙居所。
- **觌**：相见。
- **无因**：无由。

## 译文

登上九灵神游啊，寂静清澈于太微。
驾苍龙御青虬啊，以飞廉为御以螭为骖。
登上阆风抚云啊，超越流沙跨过河流。

览观九州尚有余啊，横跨四海哪有穷尽。
玄渊幽深啊，谁能测知其中。
桂水潺湲流淌啊，扬起波涛并流。
蛟龙并跃啊，水兽相随。

思念忠信愈发笃厚啊，经历远路长久勤苦。
登上太乙玉堂啊，览观古今得失。
遇到佳人同心啊，愿一相见却无由。
时机不可再得啊，恐迟暮将至又能如何。

## 赏析

《九怀·思忠》以神游天界为线索，抒发了诗人对忠信品格的坚守和对理想境界的追求。"登九灵兮游神，静淑清兮太微"以神游太微的壮丽想象开篇，"苍龙兮青虬，御飞廉兮骖螭"描写驾龙乘风的神奇旅程，体现了楚辞特有的浪漫色彩。

"览九州兮有余，横四海兮焉穷"展现了诗人广阔的视野和胸襟。"玄渊兮幽深，孰能测兮其中"以深渊难测比喻世事难料。"思忠信兮愈笃，历远路兮长勤"点明主题，表达了虽经历艰辛而忠信之心愈坚的品格。

末段"时不可兮再得，恐迟暮兮何为"流露出对时光流逝的焦虑，与屈原"恐美人之迟暮"一脉相承。全篇想象瑰奇，意境开阔，是西汉楚辞体诗歌的代表作之一。

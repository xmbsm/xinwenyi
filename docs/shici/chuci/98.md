# 九辩·节选二

**[战国] [宋玉](/authors/songyu)**

## 原文

皇天平分四时兮，窃独悲此廪秋。
白露既下百草兮，奄离披此梧楸。
去白日之昭昭兮，袭长夜之悠悠。
离芳蔼之方壮兮，余萎约而悲愁。

秋既先戒以白露兮，冬又申之以严霜。
收恢台之孟夏兮，然坎傺而沈臧。
叶菸邑而无色兮，枝烦挐而交横。
颜淫溢而将罢兮，柯仿佛而萎黄。
萷櫹椮之可哀兮，形销铄而瘀伤。

惟其纷糅而将落兮，恨其失时而无当。
揽騑辔而下节兮，聊逍遥以相伴。
岁忽忽而遒尽兮，恐余寿之弗将。
悼余生之不时兮，逢此世之俇攘。

## 注释

- **皇天**：天。
- **四时**：四季。
- **廪秋**：凛秋，寒冷的秋天。
- **奄**：忽然。
- **离披**：分散凋零。
- **梧楸**：梧桐和楸树。
- **昭昭**：明亮。
- **悠悠**：漫长。
- **芳蔼**：芳美茂盛。
- **萎约**：枯萎困顿。
- **恢台**：广大繁盛。
- **孟夏**：初夏。
- **坎傺**：困顿失意。
- **沈臧**：沉藏。
- **菸邑**：枯萎。
- **烦挐**：纷乱。
- **淫溢**：过度。
- **罢**：同"疲"。
- **萷**：树梢。
- **櫹椮**：树叶凋落。
- **销铄**：消损。
- **瘀伤**：郁结受伤。
- **纷糅**：众多杂乱。
- **騑辔**：马缰绳。
- **下节**：停车。
- **相伴**：相伴而行。
- **遒尽**：将尽。
- **弗将**：不长。
- **俇攘**：纷扰。

## 译文

皇天平分四季啊，我独自悲叹这凛秋。
白露已经降在百草之上啊，梧楸忽然凋零。
远离白日的明亮啊，袭来长夜的漫长。
离别芳美正壮之时啊，我枯萎困顿而悲愁。

秋天既已用白露先行告诫啊，冬天又用严霜加重。
收去初夏的繁盛啊，然后困顿而沉藏。
树叶枯萎失去颜色啊，枝条纷乱交错。
容颜过度而将疲惫啊，枝茎仿佛枯黄。
树梢凋落可哀啊，形体消损而郁伤。

想到纷杂将落啊，恨其失时而不当。
揽住马缰停车啊，姑且逍遥相伴而行。
岁月匆匆将尽啊，恐我的寿命不长。
悼念我生不逢时啊，遭逢此世的纷扰。

## 赏析

《九辩·节选二》承接前段"悲哉秋之为气也"的悲秋主题，进一步以细腻的笔触描绘秋天的萧瑟景象。"皇天平分四时兮，窃独悲此廪秋"以天地四时为背景，突出了诗人独悲秋天的孤寂情怀。

"白露既下百草兮，奄离披此梧楸"以白露降、梧楸凋的景象，渲染出秋天肃杀的氛围。"秋既先戒以白露兮，冬又申之以严霜"以白露和严霜的递进，写出节气的推移。"叶菸邑而无色兮，枝烦挐而交横"细致描写树木凋零的景象，以景寓情。

末段"岁忽忽而遒尽兮，恐余寿之弗将。悼余生之不时兮，逢此世之俇攘"由悲秋转为悲己，感叹岁月流逝、寿命将尽、生不逢时。全段以秋景起兴，以悲己作结，情景交融，是宋玉"悲秋"文学的精华所在，对后世悲秋文学产生了深远影响。

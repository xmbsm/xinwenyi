# 九歌·礼魂

**[战国] [屈原](/authors/quyuan)**

## 原文

成礼兮会鼓，传芭兮代舞。
姱女倡兮容时。
春兰兮秋菊，长无绝兮终古。

## 注释

- **礼魂**：祭祀结束时的送神曲。"魂"即神灵。
- **成礼**：完成祭礼。
- **会鼓**：齐击鼓。
- **传芭**：传递香花。芭，通"葩"，花。
- **代舞**：交替起舞。
- **姱女**：美丽的巫女。
- **倡**：同"唱"。
- **容时**：舞姿从容合拍。
- **春兰秋菊**：春日兰花，秋季菊花，代表四时祭祀不绝。
- **终古**：永远。

## 译文

完成祭礼啊齐击鼓，传递香花啊交替起舞。
美丽巫女歌唱啊舞姿从容。
春日献兰啊秋季献菊，永远不断啊直至终古。

## 赏析

《礼魂》是《九歌》的送神曲，为祭祀结束时的总结篇章。全诗仅五句，短小精悍。"成礼兮会鼓，传芭兮代舞"写祭祀结束时鼓乐齐鸣、歌舞不歇的热闹场面。"春兰兮秋菊，长无绝兮终古"以春兰秋菊象征四时祭祀的绵延不绝，表达了对神灵永久的崇敬与纪念。虽篇幅短小，却含蓄深沉，为《九歌》画上了一个隽永的句号，余韵悠长。

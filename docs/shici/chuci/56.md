# 九歌·东皇太一

**[战国] [屈原](/authors/quyuan)**

## 原文

吉日兮辰良，穆将愉兮上皇。
抚长剑兮玉珥，璆锵鸣兮琳琅。
瑶席兮玉瑱，盍将把兮琼芳。
蕙肴蒸兮兰藉，奠桂酒兮椒浆。
扬枹兮拊鼓，疏缓节兮安歌，陈竽瑟兮浩倡。
灵偃蹇兮姣服，芳菲菲兮满堂。
五音纷兮繁会，君欣欣兮乐康。

## 注释

- **东皇太一**：天神之尊称，楚地信仰中的最高神祇。
- **辰良**：即良辰，美好的时辰。
- **穆**：恭敬。
- **愉**：娱乐，取悦。
- **上皇**：即东皇太一。
- **抚**：持，握。
- **珥**：剑柄的装饰。
- **璆**：美玉。
- **锵鸣**：玉佩相击的声音。
- **琳琅**：美玉。
- **瑶席**：用瑶草编的席子。
- **玉瑱**：玉制的压席器。
- **盍**：同"合"，聚集。
- **把**：持，捧。
- **琼芳**：如玉的花朵。
- **蕙肴蒸**：用蕙草包裹的蒸肉。
- **兰藉**：用兰草垫底。
- **奠**：祭献。
- **桂酒**：桂花酿的酒。
- **椒浆**：花椒泡的酒。
- **扬**：举起。
- **枹**：鼓槌。
- **拊鼓**：击鼓。
- **疏缓节**：舒缓的节拍。
- **安歌**：安详地歌唱。
- **陈**：排列。
- **竽瑟**：管乐器和弦乐器。
- **浩倡**：大声歌唱。
- **灵**：神灵，指扮神的巫。
- **偃蹇**：舞姿优美的样子。
- **姣服**：美丽的服饰。
- **菲菲**：香气浓郁。
- **五音**：宫、商、角、徵、羽。
- **繁会**：交会，齐奏。
- **君**：指东皇太一。
- **康**：安康。

## 译文

吉日良辰啊，恭敬地来娱乐上皇。
手抚长剑啊玉饰剑柄，身上玉佩锵鸣啊琳琅作响。
瑶草为席啊玉为镇，捧起如玉的鲜花啊。
蕙草包蒸肉啊兰草为垫，祭献桂酒啊和椒浆。
举起鼓槌啊击鼓，舒缓节拍啊安详歌唱，排列竽瑟啊高声唱和。
神灵舞姿优美啊服饰华美，芳香四溢啊充满殿堂。
五音纷繁啊齐奏，神君欢欣啊安康快乐。

## 赏析

《东皇太一》是《九歌》的首篇，为祭祀天神最高神的乐歌。全诗描绘了隆重的祭祀场面：良辰吉日、玉器琼芳、蕙肴桂酒、鼓乐歌舞，展现了楚地巫风祭祀的盛况。诗中以"穆将愉兮上皇"开篇，定下虔诚恭敬的基调；以"芳菲菲兮满堂"渲染香气氤氲的氛围；末以"君欣欣兮乐康"作结，表现神人共乐的和谐境界。全篇辞藻华美，音调铿锵，气势庄严而恢宏，体现了楚人对天神的崇敬。

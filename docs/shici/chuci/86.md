# 九怀·尊嘉

**[汉] [王褒](/authors/wangbao)**

## 原文

抱昭华兮宝璋，欲献之兮无由。
沐兰泽兮含若芳，仪素发兮被明光。
驾玄螭兮乘飞龙，结荣光兮扬旌旗。

临深水兮登高陵，览桂椒兮列中庭。
芳若兹兮愈微，欲献之兮无媒。
望旧邦兮路远，情郁郁兮谁告。

哀时命兮不合，生不辰兮独悲。
思古人兮莫及，叹今人兮何为。
鹍鸡鸣兮悲鸣，秋风起兮木叶飞。
登高望远兮心愁，思君兮不忘。

## 注释

- **尊嘉**：尊崇美德。
- **昭华**：美玉名。
- **宝璋**：宝贵的玉璋。
- **沐兰泽**：以兰草洗发。
- **若芳**：杜若的芳香。
- **仪素发**：以素发为仪。
- **明光**：明亮的光辉。
- **玄螭**：黑色的螭龙。
- **荣光**：彩色的光芒。
- **旌旗**：旗帜。
- **高陵**：高山。
- **桂椒**：桂树和花椒。
- **愈微**：越来越微弱。
- **旧邦**：故国。
- **郁郁**：忧愁的样子。
- **不合**：不合时宜。
- **不辰**：不得其时。
- **鹍鸡**：一种形似鹤的鸟。

## 译文

怀抱昭华美玉宝璋啊，想献上却无门路。
沐浴兰泽含杜若之芳啊，素发为仪披明光。
驾玄螭乘飞龙啊，结荣光扬旌旗。

面临深水登上高陵啊，观看桂椒列于中庭。
芳香如此却愈发微弱啊，想献上却无媒人。
遥望故国路途遥远啊，心情郁郁向谁诉说。

哀叹时命不合啊，生不逢时独自悲伤。
思念古人无法企及啊，叹息今人所作何为。
鹍鸡鸣叫悲声啊，秋风起木叶纷飞。
登高望远心中忧愁啊，思念君王不能忘怀。

## 赏析

《九怀·尊嘉》以"抱昭华兮宝璋，欲献之兮无由"开篇，以怀抱美玉却无人可献为喻，抒发了怀才不遇、报国无门的苦闷。"沐兰泽兮含若芳"以香草洁身，体现了诗人对高洁品格的坚守。

"临深水兮登高陵，览桂椒兮列中庭"以登高望远的姿态，展现广阔的视野。"芳若兹兮愈微"感叹美德日益衰微，"望旧邦兮路远"则表达了对故国的深切思念。

末段"哀时命兮不合，生不辰兮独悲"直抒生不逢时的悲哀。"登高望远兮心愁，思君兮不忘"以登高望远的意象作结，既表达了对君王的忠贞，也写出了远离朝堂的孤寂。全篇继承屈原楚辞的抒情传统，意象优美，感情真挚。

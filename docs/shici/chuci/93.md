# 九叹·远游

**[汉] [刘向](/authors/liuxiang)**

## 原文

悲时俗之迫阨兮，愿轻举而远游。
质菲薄而无因兮，焉托乘而上浮。
遭沉浊而污秽兮，独郁结其谁语。
夜耿耿而不寐兮，魂营营而至曙。

驾飞龙兮乘云，历昆仑兮四荒。
建日月兮为旗，扬彗星兮为旌。
朝发轫兮天津，夕余至兮西极。
凤皇翼其承旗兮，遇蓐收乎西海。

涉流沙兮驰骋，遵赤水兮容与。
麾蛟龙使梁津兮，诏西皇使涉予。
路修远以难限兮，腾众车使径待。
指西海以为期兮，屯余车其千乘。

忽临睨夫旧乡兮，仆夫悲余马怀。
蜷局顾而不行兮，思故都而伤怀。
时不可兮再得，吾将远逝以自疏。

## 注释

- **远游**：远行游历。
- **迫阨**：迫促困阨。
- **轻举**：飞升。
- **质菲薄**：资质菲薄。
- **无因**：无所凭依。
- **上浮**：向上飞浮。
- **沉浊**：沉沦污浊。
- **耿耿**：心事重重。
- **营营**：往来不绝。
- **四荒**：四方荒远之地。
- **天津**：天河的渡口。
- **西极**：西方极远之地。
- **蓐收**：西方金神。
- **赤水**：神话中的水名。
- **容与**：从容不迫。
- **西皇**：西方的天帝。
- **修远**：遥远。
- **千乘**：千辆车。
- **临睨**：俯视。
- **蜷局**：蜷曲不前。

## 译文

悲叹时俗迫促困阨啊，愿轻举飞升而远游。
资质菲薄无所凭依啊，如何托乘而上浮。
遭遇沉浊污秽啊，独自郁结向谁诉说。
夜来耿耿不寐啊，魂魄营营直到天明。

驾飞龙乘云啊，经过昆仑历四荒。
建日月为旗啊，扬彗星为旌。
早晨从天津出发啊，傍晚到达西极。
凤凰展翅承旗啊，在西海遇见蓐收。

涉过流沙驰骋啊，沿着赤水从容。
指挥蛟龙为桥梁啊，诏令西皇渡我过。
路途修远难以限量啊，腾众车径直待发。
指西海为会合之期啊，聚集千辆车。

忽然俯视旧乡啊，仆夫悲泣马儿怀思。
蜷曲回顾不肯前行啊，思念故都而伤怀。
时机不可再来啊，我将远逝以自疏。

## 赏析

《九叹·远游》明显化用屈原《离骚》和《远游》的意境，以远游天界为主题，抒发了诗人对现实的不满和对理想境界的追求。"悲时俗之迫阨兮，愿轻举而远游"开篇即点明远游的原因——时俗迫促困阨。

"建日月兮为旗，扬彗星兮为旌"以日月彗星为旗帜，气象壮阔。"朝发轫兮天津，夕余至兮西极"写一日之间从天河渡口到达西方极远之地，展现了神奇的速度。

末段"忽临睨夫旧乡兮，仆夫悲余马怀。蜷局顾而不行兮，思故都而伤怀"化用《离骚》结尾的名句，写远游中忽然回望故乡，仆夫悲泣、马儿怀思，于是蜷曲不前。这一情节深刻表达了诗人虽欲远游却始终无法忘怀故国的矛盾心理。全篇想象瑰奇，情感真挚，是刘向追慕屈原精神的佳作。

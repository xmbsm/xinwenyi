# 九叹·忧苦

**[汉] [刘向](/authors/liuxiang)**

## 原文

忧苦兮无告，思心兮绵绵。
悲余心之怛怛兮，目眇眇而遗泣。
哀余生之多艰兮，愁郁郁而无极。
抚佩衽兮太息，叹往昔兮不可追。

时忽忽其将迈兮，年冉冉而遂过。
草木零落兮多风，山萧条兮无色。
登高陵兮望远，思故人兮不见。
云霏霏兮承宇，雨雪纷纷兮交集。

嗟余生之不幸兮，逢此世之溷浊。
欲变志以从俗兮，悔初之不可为。
宁穷饿而处幽兮，孰能化于积思。
怀芳兰兮行吟，思古人兮莫及。

叹曰：
时不再来兮，年不我与。
守志待时兮，终无悔过。
恐修名之不立兮，愿从彭咸之所居。

## 注释

- **忧苦**：忧愁痛苦。
- **绵绵**：连续不断。
- **怛怛**：忧伤的样子。
- **眇眇**：远望的样子。
- **遗泣**：流泪。
- **多艰**：多艰难。
- **无极**：没有穷尽。
- **佩衽**：佩饰和衣襟。
- **不可追**：不可追回。
- **忽忽**：迅速的样子。
- **迈**：逝去。
- **冉冉**：渐渐。
- **零落**：凋谢脱落。
- **萧条**：寂寞冷落。
- **无色**：没有色彩。
- **霏霏**：云气纷飞的样子。
- **承宇**：连接屋檐。
- **交集**：交相落下。
- **溷浊**：浑浊。
- **积思**：积久的思虑。
- **悔过**：悔恨过失。

## 译文

忧愁痛苦无处诉说啊，思虑绵绵不绝。
悲叹我心忧伤啊，目光远望而流泪。
哀叹我生多艰啊，愁闷郁郁没有穷尽。
抚佩饰衣襟而长叹啊，叹息往昔不可追回。

时光匆匆将逝去啊，年岁渐渐而过。
草木凋零多风啊，山川萧条无色。
登上高陵远望啊，思念故人而不见。
云气纷飞连接屋檐啊，雨雪纷纷交相落下。

嗟叹我生不幸啊，逢此世道浑浊。
想改变志向随俗啊，后悔当初不可如此。
宁可穷饿而居幽暗啊，谁能被积习所化。
怀抱芳兰边走边吟啊，思念古人而无法企及。

叹曰：
时不再来啊，年岁不等待我。
守志待时啊，终无悔恨。
恐修名不能建立啊，愿从彭咸之所居。

## 赏析

《九叹·忧苦》以"忧苦兮无告，思心兮绵绵"开篇，直抒胸中无处诉说的忧愁。"悲余心之怛怛兮，目眇眇而遗泣"以目光远望、泪流不止的形象，刻画了一个忧国忧民的贤者形象。

"时忽忽其将迈兮，年冉冉而遂过"感叹时光飞逝，"草木零落兮多风，山萧条兮无色"以萧条的秋景烘托内心的悲凉。"云霏霏兮承宇，雨雪纷纷兮交集"以雨雪纷飞的景象，渲染出凄冷压抑的氛围。

"欲变志以从俗兮，悔初之不可为"写出了内心的矛盾——是否要改变志向随俗浮沉，但随即否定这一想法。"宁穷饿而处幽兮，孰能化于积思"表明宁可穷困也不改其志的决心。全篇语言沉郁，意境凄美，是刘向抒发忧国情怀的代表作。

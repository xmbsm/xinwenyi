# 七谏·怨世

**[汉] [东方朔](/authors/dongfangshuo)**

## 原文

怨世之沈浊兮，士皆蔽而掩明。
贤者介而自绝兮，愚者比而党成。
固时俗之工巧兮，并钩绳而弃正。
椒丘之挽辂兮，毁折以为衡。
抱璞而献之兮，遇卞和之故刑。

孰止息之以中路兮，抚长剑而太息。
悲来抱之不可以久留兮，恐忽亡而失德。
叹曰：
江离弃于穷巷兮，蒺藜蔓乎东厢。
贤者蔽而不达兮，佞人进而群行。
兰芷幽而独芳兮，荃蕙化而为茅。
世既莫吾知兮，人心不可谓兮。

## 注释

- **怨世**：怨恨世俗。
- **沈浊**：沉沦污浊。
- **蔽而掩明**：蒙蔽掩盖光明。
- **介**：耿介。
- **比而党成**：结党营私。
- **钩绳**：规矩准绳。
- **椒丘**：长满花椒的山丘。
- **挽辂**：拉车。
- **衡**：车辕前的横木。
- **抱璞**：抱着未雕琢的玉。
- **卞和**：楚人，献璞玉反被刖刑。
- **中路**：半路。
- **失德**：失去德行。
- **江离**：香草名。
- **蒺藜**：带刺的杂草。
- **东厢**：东边的厢房。
- **荃蕙**：香草名。
- **茅**：茅草，喻小人。

## 译文

怨恨世俗沉沦污浊啊，士人都蒙蔽掩盖光明。
贤者耿介而自绝于世啊，愚者结党而营私。
固然时俗善于取巧啊，背弃规矩准绳而丢弃正道。
椒丘之木本可拉车啊，却被毁折为车衡。
抱着璞玉献上啊，却遭遇卞和那样的刑罚。

谁能半路止息啊，抚长剑而长叹。
悲伤来此不可久留啊，恐忽然忘失德行。
叹曰：
江离被弃于穷巷啊，蒺藜蔓延于东厢。
贤者蒙蔽而不能显达啊，佞人进用而群行。
兰芷幽处而独芳啊，荃蕙变化为茅草。
世人既不了解我啊，人心不可言说。

## 赏析

《七谏·怨世》是东方朔《七谏》组诗的第三篇，以"怨世之沈浊"开篇，直斥世俗沉沦污浊、贤愚颠倒的黑暗现实。诗中以"椒丘之挽辂兮，毁折以为衡"比喻贤才被误用，以"抱璞而献之兮，遇卞和之故刑"用卞和献玉的典故，抒发了忠贞反遭刑罚的悲愤。

末段以江离弃于穷巷、蒺藜蔓延东厢对比，以兰芷独芳、荃蕙化茅感叹世道变迁，贤者沦落而小人得势。全篇继承屈原楚辞的比兴传统，以香草美人寄托情怀，语言沉郁，感情真挚，体现了东方朔对汉武帝时代政治现实的深刻不满。

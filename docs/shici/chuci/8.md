# 招魂（节选）

**[战国] [屈原](/authors/quyuan)**

## 原文

朕幼清以廉洁兮，身服义而未沫。主此盛德兮，牵于俗而芜秽。上无所考此盛德兮，长离殃而愁苦。帝告巫阳曰："有人在下，我欲辅之。魂魄离散，汝筮予之。"

巫阳焉乃下招曰："魂兮归来！去君之恒干，何为四方些？舍君之乐处，而离彼不祥些。"

"魂兮归来！东方不可以托些。长人千仞，惟魂是索些。十日代出，流金铄石些。彼皆习之，魂往必释些。归来归来！不可以托些。"

"魂兮归来！南方不可以止些。雕题黑齿，得人肉以祀，以其骨为醢些。蝮蛇蓁蓁，封狐千里些。雄虺九首，往来倏忽，吞人以益其心些。归来归来！不可以久淫些。"

## 注释

- 招魂：召唤魂魄归来的仪式
- 朕：我
- 幼清：年少时清白
- 服义：践行道义
- 未沫：未止
- 主：保持
- 牵于俗：被世俗牵累
- 芜秽：荒芜污秽
- 考：考察
- 离殃：遭受灾祸
- 巫阳：巫师名
- 恒干：常住的身体
- 些：语气词
- 托：依托
- 长人：巨人
- 仞：古代长度单位
- 索：索取
- 十日代出：十个太阳轮流出现
- 流金铄石：使金铁熔化，石头烧焦
- 释：消散
- 止：停留
- 雕题黑齿：额头上刺花纹、牙齿染黑的人
- 醢：肉酱
- 蝮蛇：毒蛇
- 蓁蓁：众多的样子
- 封狐：大狐
- 雄虺：大蛇
- 倏忽：迅速
- 淫：滞留

## 译文

我年少时清白廉洁，亲身践行道义而不止。保持这种盛德，却被世俗牵累而荒芜。上天不考察这种盛德，使我长期遭受灾祸而愁苦。天帝告诉巫阳说："有人在下方，我想辅佐他。他的魂魄离散，你去占卜召唤回来。"

巫阳于是下界招魂说："魂魄啊归来吧！离开你的身体，为什么要去四方呢？舍弃你的乐土，而离开那不祥之地。"

"魂魄啊归来吧！东方不可以依托。那里有千丈巨人，专门索取魂魄。十个太阳轮流出现，金铁熔化石头烧焦。他们都习惯了，魂魄前去必定消散。归来吧归来吧！不可以依托。"

"魂魄啊归来吧！南方不可以停留。那里有额上刺花纹、牙齿染黑的人，拿人肉祭祀，把骨头做成肉酱。毒蛇众多，大狐遍布千里。九头大蛇，往来迅速，吞食人来补益它的心。归来吧归来吧！不可以久留。"

## 赏析

《招魂》是屈原的作品（一说为宋玉所作），是中国文学史上独特的招魂辞。这里节选的是招魂辞的开头部分，描写了召唤魂魄归来的仪式和对四方险恶环境的描述。

"朕幼清以廉洁兮"，开篇就点明了招魂的对象是一位清白廉洁的君子。"主此盛德兮，牵于俗而芜秽"，写君子虽然品德高尚，却被世俗牵累。"上无所考此盛德兮"，写上天不考察君子的盛德，使他遭受灾祸。

"帝告巫阳曰"，写天帝命令巫师巫阳去招魂。"魂魄离散，汝筮予之"，点明了招魂的原因。

"巫阳焉乃下招曰"，写巫阳下界招魂。"魂兮归来"的呼唤，反复出现，形成了强烈的节奏感。

接着描述四方的险恶。东方有"长人千仞""十日代出"，南方有"雕题黑齿""蝮蛇蓁蓁"，这些恐怖的描写，既是为了吓唬魂魄不要离去，也是为了反衬故乡的美好。

全诗想象奇特，语言瑰丽，将招魂的仪式和神话传说融为一体，是中国浪漫主义文学的独特篇章。

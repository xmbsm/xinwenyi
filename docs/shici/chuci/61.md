# 九歌·少司命

**[战国] [屈原](/authors/quyuan)**

## 原文

秋兰兮麋芜，罗生兮堂下。
绿叶兮素华，芳菲菲兮袭予。
夫人兮自有美子，荪何以兮愁苦？

秋兰兮青青，绿叶兮紫茎。
满堂兮美人，忽独与余兮目成。

入不言兮出不辞，乘回风兮载云旗。
悲莫悲兮生别离，乐莫乐兮新相知。

荷衣兮蕙带，儵而来兮忽而逝。
夕宿兮帝郊，君谁须兮云之际？

与女沐兮咸池，晞女发兮阳之阿。
望美人兮未来，临风怳兮浩歌。

孔盖兮翠旍，登九天兮抚彗星。
竦长剑兮拥幼艾，荪独宜兮为民正。

## 注释

- **少司命**：主管儿童命运的神。
- **麋芜**：即蘼芜，香草。
- **罗生**：丛生。
- **素华**：白花。
- **袭予**：扑向我。
- **荪**：香草名，此处指少司命。
- **青青**：茂盛。
- **目成**：眉目传情。
- **回风**：旋风。
- **生别离**：生离死别。
- **儵**：忽然。
- **帝郊**：天国的郊野。
- **谁须**：等待谁。
- **咸池**：神话中的太阳沐浴处。
- **晞**：晒干。
- **阳之阿**：神话中日出的山曲。
- **怳**：恍然，失意。
- **孔盖**：孔雀羽毛作的车盖。
- **翠旍**：翠鸟羽毛作的旗。
- **彗星**：扫帚星。
- **幼艾**：幼儿。
- **民正**：百姓的主宰。

## 译文

秋兰和蘼芜啊，丛生在堂下。
绿叶白花啊，芳香扑鼻。
人们自有美好的子女啊，少司命为何愁苦？

秋兰茂盛啊，绿叶紫茎。
满堂都是美人啊，你却独独与我眉目传情。

来时不说话去时不辞别啊，乘着旋风载着云旗。
悲没有比生别离更悲啊，乐没有比新相知更乐。

荷叶为衣蕙草为带啊，忽然而来忽然而去。
夜晚歇息在天国郊野啊，你在云际等待谁？

与你同浴在咸池啊，在日出处晒干你的头发。
盼望美人啊未来，迎风失意啊放声高歌。

孔雀羽盖翠鸟旗啊，登上九天抚持彗星。
手持长剑护卫幼儿啊，唯有你宜作百姓的主宰。

## 赏析

《少司命》是祭祀主管子嗣儿童之神的乐歌。"悲莫悲兮生别离，乐莫乐兮新相知"为千古名句，将人生最悲与最乐的体验凝练为对仗，道尽人情之至。诗以"秋兰"起兴，以香草象征子嗣之美好。少司命与巫者"目成"而忽来忽去，表现了神人之间若即若离的情愫。末以"竦长剑兮拥幼艾，荪独宜兮为民正"赞美少司命守护儿童的职责，寄托了诗人对保护幼弱、主持正义的期望。全诗情致缠绵而不失庄严，是《九歌》中抒情性极强的佳作。

# 观朝雨

**[南朝] [谢朓](/authors/xietiao)**

## 原文

朔风飘夜雨，清旦交密云。
耳目暂无扰，怀抱日已幽。
飞鸟晚来息，高翼暮天收。
方辞旧宇去，言就新客游。
远客且淹留，契阔从此休。

## 注释

- **观朝雨**：观看早晨的雨。
- **朔风**：北风。
- **清旦**：清晨。
- **交密云**：密云交合。
- **无扰**：没有打扰。
- **怀抱**：胸中的怀抱和心事。
- **幽**：幽深，深沉。
- **高翼**：高飞的鸟翼。
- **暮天收**：在天色将晚时收起翅膀。
- **方辞**：正要辞别。
- **旧宇**：旧居。
- **言就**：前往。言，语助词。
- **契阔**：离散聚合，此处指劳苦奔波。

## 译文

北风飘着夜雨，清晨密云交合。耳目暂时没有打扰，胸中的怀抱日益深沉。飞鸟晚间来栖息，高飞的翅膀在暮天收起。正要辞别旧居而去，前往做新的客游。远方的客人暂且淹留，劳苦奔波从此休止。

## 赏析

《观朝雨》是谢朓的一首山水抒情诗，以观朝雨之景抒发羁旅思归之情。诗歌以"朔风飘夜雨，清旦交密云"起笔，描绘北风夜雨、清晨密云的景象，营造出阴沉压抑的氛围。"耳目暂无扰，怀抱日已幽"由景及人，写雨中暂得宁静，但内心却日益深沉幽远。"飞鸟晚来息，高翼暮天收"以飞鸟暮归为比，暗喻自己渴望归息。后半部分"方辞旧宇去，言就新客游"写即将出行的不舍，"远客且淹留，契阔从此休"表达希望结束漂泊、安顿下来的心愿。全诗以雨景起兴，以飞鸟为喻，语言清丽自然，意境深远含蓄，充分体现了谢朓山水诗清新秀丽的艺术特色。诗中"耳目暂无扰，怀抱日已幽"一句以静写动，以外在的宁静反衬内心的深沉，尤为后人称道。

# 咏老马

**[南朝] [沈炯](/authors/shenjiong)**

## 原文

昔日从戎阵，流汗几东西。
一日驰千里，三丈拔深泥。
渡水频伤骨，翻霜屡损蹄。
勿言年齿暮，寻途尚不迷。

## 注释

- **从戎阵**：从军征战。戎阵，军阵。
- **流汗几东西**：汗流东西，形容征战的劳苦。几，几次。
- **一日驰千里**：一日奔驰千里。
- **三丈拔深泥**：从三丈深的泥中拔出。
- **渡水频伤骨**：渡水频繁，伤了马骨。
- **翻霜屡损蹄**：踏翻霜雪，屡次损伤马蹄。
- **勿言年齿暮**：不要说年纪已老。年齿，年纪。暮，晚。
- **寻途尚不迷**：寻找道路还不迷路。

## 译文

昔日从军征战，汗流东西不知几回。
一日奔驰千里，从三丈深的泥中拔出。
渡水频繁伤了马骨，踏翻霜雪屡次损伤马蹄。
不要说年纪已经老了，寻找道路还不曾迷路。

## 赏析

《咏老马》是沈炯的咏物之作，以老马为题材，借物言志，抒发了诗人虽年老而壮心不已的情怀。开篇"昔日从戎阵，流汗几东西"回忆老马昔日从军征战的辛劳，以"流汗几东西"概括其南征北战的劳苦。"一日驰千里，三丈拔深泥"写老马曾经的英勇——日行千里，从深泥中拔脱，表现其非凡的力量和毅力。"渡水频伤骨，翻霜屡损蹄"写老马历经艰辛留下的伤痕，渡水伤骨，踏霜损蹄，字字沉痛。末联"勿言年齿暮，寻途尚不迷"是全诗的点睛之笔：不要说老马年纪已老，它寻找道路还不曾迷路。这是以老马自况，表达了诗人虽年老体衰，但智慧和忠诚不减的胸怀。全诗借咏老马以言志，语言朴素而感情深沉，是南北朝咏物诗中的佳作。

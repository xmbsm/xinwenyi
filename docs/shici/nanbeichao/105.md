# 山斋独坐赠薛内史

**[隋] [杨素](/authors/yangsu)**

## 原文

居山四望阻，风云竟朝夕。
深溪横古树，空岩卧幽石。
日出远岫明，鸟散空林寂。
兰庭动幽气，竹室生虚白。
落花入户飞，细草当阶积。
桂酒徒盈樽，故人不在席。
日落山之幽，临风望羽客。

## 注释

- **山斋**：山中书斋。
- **薛内史**：薛道衡，时任内史侍郎。
- **四望阻**：四望皆为山势所阻。
- **竟朝夕**：从早到晚。竟，终。
- **空岩**：空寂的山岩。
- **幽石**：幽暗的石头。
- **远岫**：远处的山峰。
- **兰庭**：种有兰草的庭院。
- **幽气**：幽香之气。
- **虚白**：《庄子》"虚室生白"，指室中空明，比喻心境清虚。
- **桂酒**：桂花酒。
- **徒盈樽**：白白地斟满酒杯。
- **故人**：老友，指薛道衡。
- **山之幽**：山的幽深处。
- **羽客**：修道的仙人，此处戏称薛道衡。

## 译文

居住山中四面望去皆被山势阻隔，风云从早到晚不停。
深溪上横卧着古树，空寂的岩洞中卧着幽石。
日出时远处的山峰明亮，鸟散后空林归于寂静。
兰草庭院飘动幽香之气，竹室之中生出虚白之境。
落花飞入门户之内，细草堆积在台阶之前。
桂酒白白地斟满了酒杯，老友却不在席上同饮。
日落时分山的幽深之处，迎风远望如仙人般的故友。

## 赏析

《山斋独坐赠薛内史》是杨素的代表作，写山中独坐时对友人薛道衡的思念。开篇"居山四望阻，风云竟朝夕"写山居的环境：四望皆被山阻，风云终日不息，既写出了山的幽深，也暗示了与世隔绝的孤寂。"深溪横古树，空岩卧幽石"进一步描绘山中景物：深溪上古树横卧，空岩中幽石静卧，以"横"和"卧"两个动词赋予景物以静态之美。"日出远岫明，鸟散空林寂"写日出鸟散后的寂静，以"明"和"寂"的对比，写出山中由动而静的变化。"兰庭动幽气，竹室生虚白"转写居所：兰草飘香，竹室空明，以"兰"和"竹"的高洁衬托主人的品格，"虚白"一词更用《庄子》之典，表现心境的清虚宁静。"落花入户飞，细草当阶积"以落花入户、细草积阶的细节，写出山居的清幽和久无人来访的孤寂。"桂酒徒盈樽，故人不在席"是全诗的情感核心：桂花酒白白斟满，老友却不在席上，"徒"字写尽了独饮的无奈和对友人的思念。末句"日落山之幽，临风望羽客"以日落时临风远望作结，将思念之情推向深远，余味无穷。全诗以山水写怀抱，以清幽衬思念，风格清淡高远，开唐代山水田园诗之先声。

# 夜宿石门诗

**[南朝] [谢灵运](/authors/xielingyun)**

## 原文

朝搴苑中兰，畏彼霜下歇。
暝还云际宿，寻此石上月。
鸟鸣识夜栖，木落知风发。
异音同至听，殊响俱清越。
妙物莫为赏，芳醑谁与伐。
美人竟不来，阳阿徒晞发。

## 注释

- **石门**：山名，在今浙江嵊县。
- **搴**：采摘。
- **歇**：凋谢。
- **暝**：傍晚。
- **云际**：云间，指高山。
- **鸟鸣识夜栖**：从鸟鸣声辨认其夜间栖息之处。
- **木落**：落叶。
- **风发**：风起。
- **异音**：各种不同的声音。
- **至听**：极好的听觉享受。
- **殊响**：不同寻常的声响。
- **清越**：清脆悠扬。
- **妙物**：美好的景物。
- **芳醑**：美酒。
- **伐**：赞美，一作"献"。
- **美人**：理想中的人物。
- **阳阿**：神话中日出之处。
- **晞发**：晒干头发。

## 译文

早晨采摘苑中的兰花，担心它在霜下凋谢。
傍晚回到云际高山住宿，寻觅这石门山上的月光。
鸟鸣声中辨认它们夜栖之处，落叶声中知道风已刮起。
各种不同的声音汇成美妙的听觉，不同的声响都清脆悠扬。
美好的景物无人欣赏，美酒谁来共饮？
理想中的美人终究不来，只能在阳阿徒然晒干头发。

## 赏析

《夜宿石门诗》描写了谢灵运夜宿石门山的所见所闻。"鸟鸣识夜栖，木落知风发"以听觉写景，从鸟鸣、落叶声中辨别夜间的动静，细腻传神。"异音同至听，殊响俱清越"以音乐般的笔调描绘山中夜声的清越美妙。末以"美人竟不来，阳阿徒晞发"收束，用《楚辞》中"与女沐兮咸池，晞女发兮阳之阿"的典故，表达了知音难觅的孤独。全诗意境清幽，以声写静，体现了谢灵运山水诗的独特魅力。

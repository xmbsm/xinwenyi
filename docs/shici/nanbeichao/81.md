# 秋夜

**[南朝] [谢朓](/authors/xietiao)**

## 原文

秋夜促织鸣，南邻捣衣急。
思君隔九重，夜夜空伫立。
北窗轻幔垂，西户月光入。
何知白露下，坐视阶前湿。

## 注释

- **促织**：蟋蟀。
- **捣衣**：古人将织好的布帛放在砧上用杵捶打，使之柔软以便裁衣，多在秋天进行。
- **九重**：九重门，指深宫。
- **伫立**：久立。
- **轻幔**：轻薄的帷幔。
- **白露**：秋天的露水，也指节气。

## 译文

秋夜里蟋蟀鸣叫，南邻捣衣的声音急促。思念你却隔着九重门，夜夜空自久立。北窗轻薄的帷幔垂下，西户有月光照入。哪里知道白露已降下，坐着看着阶前已经湿了。

## 赏析

《秋夜》是谢朓的一首闺怨诗，以秋夜景色衬托思妇的孤寂情怀。诗歌以"秋夜促织鸣，南邻捣衣急"起笔，以蟋蟀鸣叫和捣衣声两种典型的秋夜声响，渲染出凄清的氛围，也暗示了时令——秋天是准备寒衣的季节，思妇之愁更显深重。"思君隔九重，夜夜空伫立"直写相思之苦，"九重"极言阻隔之深，"空伫立"写尽等待的徒劳。"北窗轻幔垂，西户月光入"以室内的静景衬托孤寂，轻幔垂、月光入，清冷中透出幽寂之美。"何知白露下，坐视阶前湿"以不知不觉间露水打湿台阶收束全篇，写出伫立之久和沉思之深。全诗语言清丽自然，意境幽美，以声衬静，以景写情，充分体现了谢朓诗歌清新含蓄的艺术特色，对唐代闺怨诗的创作颇有影响。

# 游东田

**[南朝] [谢朓](/authors/xietiao)**

## 原文

戚戚苦无悰，携手共行乐。
寻云陟累榭，随山望菌阁。
远树暧阡阡，生烟纷漠漠。
鱼戏新荷动，鸟散余花落。
不对芳春酒，还望青山郭。

## 注释

- **东田**：在今南京钟山下，谢朓的庄园。
- **戚戚**：忧愁的样子。
- **无悰**：没有欢乐。悰，欢乐。
- **陟**：登。
- **累榭**：层叠的台榭。
- **菌阁**：形如菌状的楼阁。
- **暧**：昏暗。
- **阡阡**：茂盛。
- **漠漠**：弥漫。
- **芳春酒**：春天的美酒。
- **青山郭**：青翠的山城。

## 译文

忧愁苦闷没有欢乐，携手一同出游行乐。
追寻云彩登上层叠的台榭，沿着山路远望菌形楼阁。
远处的树木茂密昏暗，升起的炊烟弥漫纷繁。
鱼儿嬉戏新荷摇动，鸟儿飞散残花飘落。
不面对芳春美酒，还回望青山环绕的城郭。

## 赏析

《游东田》是谢朓游览东田庄园所作。"鱼戏新荷动，鸟散余花落"为写景名句，以动静结合的手法，细腻地描绘了鱼戏荷动、鸟散花落的生动景象，充满了自然天趣。全诗由忧而游、由游而乐，以景写情，表现了诗人在自然中寻求心灵慰藉的情怀。语言清新自然，对仗工整，是谢朓山水诗中轻灵秀丽一面的代表。

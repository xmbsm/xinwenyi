# 诏问山中何所有赋诗以答

**[南朝] [陶弘景](/authors/taohongjing)**

## 原文

山中何所有，岭上多白云。
只可自怡悦，不堪持赠君。

## 注释

- **诏问**：皇帝下诏询问。
- **山中何所有**：齐高帝萧道成问陶弘景山中有什么。
- **赋诗以答**：作诗来回答。
- **白云**：山岭间的云雾。
- **自怡悦**：自己感到愉悦。
- **不堪**：不能。
- **持赠君**：拿来赠送给您。

## 译文

山中有什么呢？山岭上有很多白云。
只能自己欣赏感到愉悦，却不能拿来赠送给您。

## 赏析

这首诗是陶弘景隐居茅山时，回答齐高帝诏问之作。诗以问答形式展开，首句"山中何所有"即齐高帝之问，看似平淡，实则蕴含着帝王对隐者的关切与不解。次句"岭上多白云"正面作答：山中没有荣华富贵，只有岭上飘飘的白云。白云在这里既是实景，又是隐逸高洁的象征。后两句"只可自怡悦，不堪持赠君"进一步申明：白云只能自己欣赏愉悦，却不能拿来赠送给你。言外之意是：山中之乐无法用世俗之物来衡量，隐者的精神境界也不是功名利禄所能替代的。全诗仅二十字，语言朴素自然，却含蓄蕴藉，以白云为喻，巧妙地表达了诗人甘于淡泊、不慕荣华的高洁情怀，也婉谢了帝王的征召，是六朝隐逸诗的代表作。

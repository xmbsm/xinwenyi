# 望荆山

**[南朝] [江淹](/authors/jiangyan)**

## 原文

奉义至江汉，始知楚塞长。
南关绕桐柏，西岳出鲁阳。
寒郊无留影，秋日悬清光。
悲风挠重林，云霞肃川涨。
岁晏君如何，零泪沾衣裳。
玉柱空掩露，金樽坐含霜。
一闻苦寒奏，再使艳歌伤。

## 注释

- **荆山**：山名，在湖北，为楚国象征。
- **奉义**：奉命。一作"奉诏"。
- **江汉**：长江与汉水。
- **楚塞**：楚地的关塞。
- **南关**：南方的关隘。
- **桐柏**：桐柏山，在河南湖北交界处。
- **西岳**：西方的山岳。
- **鲁阳**：地名，在今河南鲁山。
- **寒郊**：寒冷的郊野。
- **无留影**：没有树木的影子，形容萧条。
- **清光**：清冷的光辉。
- **悲风**：悲凉的秋风。
- **挠**：弯曲，摇动。
- **重林**：层层的树林。
- **肃**：肃杀。
- **川涨**：河水上涨。
- **岁晏**：岁暮。
- **零泪**：落泪。
- **玉柱**：琴柱，代指琴。
- **掩露**：被露水浸润。
- **金樽**：金酒杯。
- **含霜**：凝结着霜。
- **苦寒奏**：奏苦寒之曲。
- **艳歌**：艳丽的歌曲。
- **伤**：伤感。

## 译文

奉命来到江汉之地，才知道楚地关塞的漫长。
南方的关隘绕过桐柏山，西方的山岳伸向鲁阳。
寒冷的郊野没有树木的影子，秋日的阳光悬着清冷的光辉。
悲凉的秋风摇动着重重树林，云霞肃杀河水上涨。
岁暮时节你怎样了，零落的泪水沾湿了衣裳。
琴弦空被露水浸润，金杯中凝结着寒霜。
一听到苦寒的曲调，便使艳歌也变得伤感。

## 赏析

《望荆山》是江淹途经荆山时所作的纪行诗，抒发了羁旅之愁和岁暮之感。首联"奉义至江汉，始知楚塞长"交代行踪，以"始知"二字写出亲历其境的感慨。"南关绕桐柏，西岳出鲁阳"写途经的山川：南关绕桐柏，西岳出鲁阳，视野开阔。"寒郊无留影，秋日悬清光"写秋景：寒郊萧条无影，秋日清光冷冽，营造出凄清的意境。"悲风挠重林，云霞肃川涨"以悲风摇林、云霞肃杀、河水上涨，渲染出肃杀悲凉的氛围。"岁晏君如何，零泪沾衣裳"转入抒情：岁暮之际感时伤怀，泪沾衣裳。"玉柱空掩露，金樽坐含霜"以琴弦沾露、酒杯凝霜，写夜来独坐的凄凉。末联"一闻苦寒奏，再使艳歌伤"以苦寒之曲使艳歌生悲作结，将音乐与情感融为一体。全诗写景肃杀，抒情深沉，体现了江淹诗歌沉郁苍凉的特色。

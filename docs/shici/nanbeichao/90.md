# 晚出新亭

**[南朝] [阴铿](/authors/yinkeng)**

## 原文

大江一浩荡，离悲足几重。
潮落犹如盖，云昏不作峰。
远戍唯闻鼓，寒山但见松。
九十方称半，归途讵有踪。

## 注释

- **新亭**：在今南京市南，三国时吴建，为建康城南的重要渡口。
- **浩荡**：水势盛大貌。
- **离悲**：离别的悲愁。
- **几重**：几层，形容悲愁之多。
- **潮落**：潮水退落。
- **犹如盖**：波涛仍如车盖般翻涌。
- **云昏**：云层昏暗。
- **不作峰**：不呈峰峦之状。
- **远戍**：远方的戍所。
- **鼓**：戍鼓，报时的鼓声。
- **寒山**：萧瑟的山。
- **九十方称半**：《尚书》"为山九仞，功亏一篑"，喻路程才走了一半。
- **归途**：归去的路。
- **讵有踪**：岂有踪迹，意为归期无望。

## 译文

大江浩荡东去，离别的悲愁不知有几重。
潮水虽已退落，波涛仍如车盖般翻涌，云层昏沉，不呈峰峦之状。
远方戍所只传来隐隐鼓声，寒山上只看见苍松挺立。
九十里才算走了一半，归途无期，哪里还有踪迹可寻。

## 赏析

《晚出新亭》是阴铿的代表作之一，写傍晚出新亭远行时的所见所感。首联"大江一浩荡，离悲足几重"以浩荡江水起兴，引出层层离悲，情景交融。"潮落犹如盖，云昏不作峰"写江上景象：潮虽退而波涛仍如车盖，云昏沉而不成峰峦，渲染出压抑沉闷的氛围。"远戍唯闻鼓，寒山但见松"写远方的戍鼓和寒山上的孤松，视听结合，渲染出旅途的萧条与孤寂。末联"九十方称半，归途讵有踪"以行程之远比喻人生之路的艰难，抒发了归期无望的感慨。全诗对仗工整，写景如画，语言精练而意蕴深远，体现了阴铿诗歌"善于炼字""风格清丽"的特色，对唐代律诗的发展产生了重要影响。

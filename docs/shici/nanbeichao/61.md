# 入若耶溪

**[南朝] [王籍](/authors/wangji)**

## 原文

艷艷何泛泛，空水共悠悠。
阴霞生远岫，阳景逐回流。
蝉噪林逾静，鸟鸣山更幽。
此地动归念，长年悲倦游。

## 注释

- **若耶溪**：在今浙江绍兴，若耶山下。
- **艷艷**：即"艷艷"，船行轻快的样子。一作"馀艷"。
- **泛泛**：飘荡。
- **空水**：天空和水色。
- **悠悠**：深远。
- **阴霞**：云霞。
- **远岫**：远处的山峰。
- **阳景**：日影。
- **回流**：回旋的水流。
- **蝉噪林逾静**：蝉鸣声反而衬托出树林的幽静。
- **鸟鸣山更幽**：鸟鸣声反而衬托出山的幽深。
- **动归念**：萌生归乡之念。
- **倦游**：厌倦游宦。

## 译文

轻舟飘荡泛泛而行，天空与水色共显悠悠深远。
云霞从远处的山峰升起，日影追逐着回旋的水流。
蝉鸣声使树林更加幽静，鸟叫声使山岭更加幽深。
此地令我萌生归乡之念，长年悲叹倦于游宦。

## 赏析

《入若耶溪》是王籍的代表作。"蝉噪林逾静，鸟鸣山更幽"为千古传诵的名句，以动衬静，以声写寂，将相反的事物统一于意境之中，创造了"以动写静"的典范，后人誉为"文外独绝"。全诗以清丽的笔触描绘了若耶溪的幽静景色，由景生情，"此地动归念，长年悲倦游"抒发了诗人倦于游宦、思归故里的情怀。此诗对后世山水诗影响深远，王维、孟浩然等唐代诗人都从中汲取了艺术营养。

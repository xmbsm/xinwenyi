# 登盘山绝顶

**[明] [戚继光](/authors/qijiguang)**

## 原文

霜角一声草木哀，云头对起石门开。

朔风边酒不成醉，落叶归鸦无数来。

但使雕戈销杀气，未妨白发老边才。

勒名峰上吾谁与，故李将军舞剑台。

## 注释

- **盘山**：在今天津蓟县，为京东名胜。
- **霜角**：寒霜中吹响的号角。
- **草木哀**：草木为之哀伤，形容角声悲凉。
- **云头对起**：云雾从两侧涌起。
- **石门开**：如石门大开。
- **朔风**：北风。
- **边酒**：边地的酒。
- **不成醉**：不能醉，形容心事沉重。
- **雕戈**：刻有花纹的戈，指兵器。
- **销杀气**：消除战争的杀气。
- **老边才**：在边地老去的将才。
- **勒名**：刻名记功。
- **吾谁与**：我与谁同。
- **故李将军**：已故的李广将军，汉代名将。
- **舞剑台**：李广舞剑的台。

## 译文

寒霜中一声号角草木为之哀伤，云雾对涌石门大开。北风中饮边地的酒却不能醉，落叶纷飞归鸦无数飞来。

只要能用雕戈消除战争的杀气，不妨白发苍苍在边地老去。在山峰上刻名记功我与谁同，唯有已故李广将军的舞剑台。

## 赏析

《登盘山绝顶》是戚继光戍守边关时登盘山所作的七律。首联"霜角一声草木哀，云头对起石门开"写盘山绝顶的雄奇景象，霜角悲凉、云涌石开，以边塞特有的意象渲染出苍凉壮阔的氛围。颔联"朔风边酒不成醉，落叶归鸦无数来"写登顶的感受，北风中饮酒不能醉，以"不成醉"写心事沉重，落叶归鸦写秋景萧瑟，景中含情。颈联"但使雕戈销杀气，未妨白发老边才"是全诗的主旨，表达了只要能以武力消除战争、保境安民，自己甘愿白发苍苍老死边关的壮志，写出了将军以国事为重的胸怀。尾联"勒名峰上吾谁与，故李将军舞剑台"以李广自况，表达了追慕前贤、功业无人的感慨，"吾谁与"三字写出了知音难觅的孤独。全诗格调苍凉悲壮，气势雄浑，体现了戚继光忧国忧民、甘愿戍边的英雄气概。

# 五月十九日大雨

**[明] [刘基](/authors/liuji)**

## 原文

风驱急雨洒高城，云压轻雷殷地声。

雨过不知龙去处，一池草色万蛙鸣。

## 注释

- **驱**：驱使，此处形容风势猛烈。
- **急雨**：骤雨。
- **洒**：洒落。
- **高城**：高高的城墙。
- **云压**：乌云低垂压顶。
- **殷地声**：雷声震动大地。殷，震动。
- **雨过**：雨停之后。
- **龙**：传说中能兴云布雨的神龙。
- **一池草色**：满池的青草之色。

## 译文

狂风驱使着骤雨洒落高高的城墙，乌云低垂轻雷震动大地发出声响。

大雨过后不知神龙去了何处，只见满池青草碧绿万蛙齐鸣。

## 赏析

《五月十九日大雨》是刘基写夏日暴雨的名篇。前两句"风驱急雨洒高城，云压轻雷殷地声"写大雨来时的情景，"风驱"写风势之猛，"急雨"写雨势之骤，"洒高城"写雨水洒落城墙，"云压"写乌云低垂，"殷地声"写雷声震动大地，两句以风、雨、云、雷四组意象，生动再现了暴风骤雨的磅礴气势。后两句"雨过不知龙去处，一池草色万蛙鸣"写雨后的景象，古人以为龙能兴云布雨，"不知龙去处"以神话传说写大雨的骤然停歇，充满想象。"一池草色万蛙鸣"以满池青草、万蛙齐鸣写雨后的生机盎然，与前两句的磅礴气势形成鲜明对比，由动转静，由急转缓。全诗仅二十八字，却写出了暴雨从来到去的全过程，气势磅礴而收束从容，体现了刘基诗歌雄浑奔放的艺术风格。

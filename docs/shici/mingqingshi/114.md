# 夜坐·其一

**[清] [龚自珍](/authors/gongzizhen)**

## 原文

春夜伤心坐画屏，不如放眼入青冥。

一山突起丘陵妒，万籁无言帝座灵。

塞上似腾奇女气，江东久陨少微星。

平生不蓄湘累问，唤出嫦娥诗与听。

## 注释

- **夜坐**：夜间独坐。
- **画屏**：有画饰的屏风。
- **放眼**：放眼远望。
- **青冥**：青色的天空。
- **一山突起**：一座山峰拔地而起。
- **丘陵妒**：小丘陵为之嫉妒。
- **万籁**：自然界的各种声音。
- **帝座**：天帝之座，亦指帝王之位。
- **灵**：灵异。
- **塞上**：边塞之上。
- **奇女气**：奇女之气，典故。
- **江东**：长江下游以东地区。
- **久陨**：早已陨落。
- **少微星**：星名，喻指处士、隐士。
- **平生**：一生。
- **不蓄**：不存。
- **湘累问**：指屈原《天问》。湘累，指屈原。
- **嫦娥**：月宫仙子。
- **诗与听**：诗给她听。

## 译文

春夜伤心独坐画屏旁，不如放眼望入青天。一座山峰拔地而起令丘陵嫉妒，万籁俱寂更显天帝之座的灵异。边塞似有奇女之气升腾，江东的少微星早已陨落。平生不曾存有屈原《天问》般的疑问，唤出嫦娥来听我的诗。

## 赏析

《夜坐·其一》是龚自珍的一首七律，写春夜独坐时的所思所感，抒发怀才不遇的感慨。"春夜伤心坐画屏，不如放眼入青冥"以伤心独坐起笔，转而放眼望天，"不如"二字写出了从苦闷中寻求超脱的心境。"一山突起丘陵妒，万籁无言帝座灵"以山起陵妒、万籁俱寂写夜空的景象，"一山突起"喻杰出人才，"丘陵妒"写世俗的嫉妒，"帝座灵"写天帝之座的灵异，暗喻朝廷的高高在上。"塞上似腾奇女气，江东久陨少微星"用典故写人才问题，"奇女气"喻奇才之气，"少微星"喻处士隐士，"久陨"二字写出了人才凋零的现实，暗含对朝廷不重视人才的批评。"平生不蓄湘累问，唤出嫦娥诗与听"以屈原《天问》自比，却不作天问，而是唤出嫦娥来听诗，"唤出嫦娥"的想象奇绝，写出了诗人的孤独与孤高，世间无人可语，只能唤月宫仙子来听。全诗想象奇特，用典精当，意境开阔，抒发了怀才不遇的感慨和对现实的批判，体现了龚自珍诗歌瑰丽奇肆的艺术风格。

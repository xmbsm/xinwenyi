# 秦淮海祠

**[明] [杨士奇](/authors/yangshiqi)**

## 原文

辞客风流远，高祠近郭斜。
百年心尚在，一代落谁家。
烟暝秦淮水，春残绮陌花。
向来佳丽地，惆怅过繁华。

## 注释

- **秦淮海**：秦观，字少游，号淮海居士，北宋词人。
- **辞客**：文人墨客。
- **高祠**：高大的祠堂。
- **郭**：城郭。
- **秦淮水**：南京秦淮河。
- **绮陌**：美丽的街道。
- **佳丽地**：指南京。

## 译文

辞客风流已远去，高大的祠堂在城郭边斜立。
百年的心志尚在，一代才学落于谁家？
烟霭昏暗了秦淮河水，春残花谢了绮陌花丛。
向来佳丽之地，惆怅地走过曾经的繁华。

## 赏析

《秦淮海祠》是杨士奇凭吊秦观祠堂之作。诗以"辞客风流远"开篇，表达了对秦观的追慕。"百年心尚在，一代落谁家"感叹秦观虽逝而精神长存，但后继何人？"烟暝秦淮水，春残绮陌花"以秦淮暮色和落花渲染凄清氛围。末以"向来佳丽地，惆怅过繁华"收束，由吊古而伤今，感慨繁华已逝。全诗意境凄迷，寄寓了诗人对文人命运的深沉感慨。

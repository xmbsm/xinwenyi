# 题画兰

**[清] [郑燮](/authors/zhengxie)**

## 原文

身在千山顶上头，突岩深缝妙香稠。

非无脚下浮云闹，来不相知去不留。

## 注释

- **题画兰**：在画兰上题的诗。
- **身在千山顶上头**：兰花生长在千山的最高处。
- **突岩**：突出的岩石。
- **深缝**：深深的石缝。
- **妙香稠**：幽香浓郁。稠，浓密。
- **非无**：并不是没有。
- **脚下浮云**：脚下的浮云。
- **闹**：喧闹。
- **来不相知**：来了却不相知。
- **去不留**：去了也不挽留。

## 译文

兰花生长在千山的最高处，突出的岩石深缝中幽香浓郁。并不是脚下没有浮云喧闹，而是云来时不相知，去时也不挽留。

## 赏析

《题画兰》是郑燮的一首题画诗，借咏兰以言志。"身在千山顶上头，突岩深缝妙香稠"写兰花生长的环境，千山顶上、突岩深缝，是常人难以到达的高处，"妙香稠"三字写兰花虽处幽僻之地，却散发着浓郁的幽香，暗喻君子虽处穷厄，仍有高尚的品德。"非无脚下浮云闹"以"非无"构成让步，脚下并非没有浮云喧闹，浮云喻指世俗的纷扰和功名利禄。"来不相知去不留"写兰花对浮云的态度，浮云来时不相知交，去时也不挽留，写出了兰花超然物外、不为外物所动的高洁品格。全诗借物咏怀，以兰自喻，写出了郑燮清高自守、不慕荣利的人生态度，语言质朴明快，寓意深远，体现了板桥诗清新质朴的艺术风格，是其题画诗中的佳作。

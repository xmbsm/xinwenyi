# 韬钤深处

**[明] [戚继光](/authors/qijiguang)**

## 原文

小筑惭高枕，忧时旧有盟。
呼樽来揖客，挥尘坐谈兵。
云护牙签满，星含宝剑横。
封侯非我意，但愿海波平。

## 注释

- **韬钤**：兵书《六韬》和《玉钤》，代指兵法。
- **小筑**：小屋。
- **高枕**：安卧。
- **盟**：与友人的盟约。
- **呼樽**：呼唤酒杯。
- **揖客**：向客人作揖。
- **挥尘**：挥动拂尘。
- **牙签**：象牙书签，指兵书。
- **封侯**：封侯拜将。
- **海波平**：海疆平定，指平定倭患。

## 译文

在小屋中惭于高枕安卧，忧念时局旧有盟约。
呼唤酒杯来招待客人，挥动拂尘坐谈兵法。
云雾护着满满的兵书，星光映着横放的宝剑。
封侯并非我的心意，只愿海上风波平定。

## 赏析

《韬钤深处》展现了戚继光作为军事家的胸襟抱负。"小筑惭高枕，忧时旧有盟"写虽居小屋而不能安卧，时刻忧念国事。"云护牙签满，星含宝剑横"描绘了满室兵书、宝剑横陈的场景，体现了将军勤于研读兵法、时刻备战的状态。"封侯非我意，但愿海波平"为全诗点睛之笔，明确表达了不求功名利禄、但愿海疆安宁的高尚情怀。全诗格调沉雄，意境壮阔，是爱国将领心声的真实写照。

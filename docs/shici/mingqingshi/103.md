# 浣溪沙·记绾长条欲别难

**[清] [纳兰性德](/authors/nalanxingde)**

## 原文

记绾长条欲别难，盈盈自此隔银湾。便无风雪也摧残。

青雀几时裁锦字，玉虫连夜剪春幡。不禁辛苦况相关。

## 注释

- **浣溪沙**：词牌名。
- **绾**：盘绕，打结。
- **长条**：柳枝，古人折柳赠别。
- **欲别难**：欲别离而难舍。
- **盈盈**：水清澈的样子，借指银河。
- **银湾**：银河，比喻相隔如天上银河。
- **便无**：即使没有。
- **风雪**：风雪之灾。
- **摧残**：摧残折损。
- **青雀**：青鸟，传信的使者。
- **锦字**：锦字回文，指书信。
- **玉虫**：灯蛾。
- **春幡**：春旗，立春日所戴。
- **不禁**：承受不住。
- **况相关**：何况彼此相关牵挂。

## 译文

记得折柳送别时难舍难分，从此如隔银河天各一方。即使没有风雪也令人憔悴。

青鸟何时才能带来你的书信，灯蛾连夜扑向春幡。我自己尚且承受不住辛苦，何况彼此牵挂。

## 赏析

《浣溪沙·记绾长条欲别难》是纳兰性德写离别相思的词作。上片写别后之苦。"记绾长条欲别难"以折柳送别起笔，"绾长条"即折柳赠别，"欲别难"三字写出了离别时的难舍难分。"盈盈自此隔银湾"以银河比喻离别后的相隔，如牛郎织女般天各一方，"盈盈"二字既写银河的清澈，也暗含盈盈泪眼之意。"便无风雪也摧残"写即使没有风雪的摧残，离别本身已足以令人憔悴，以"便无"强调相思之苦甚于风雪。下片写相思之情。"青雀几时裁锦字"以青鸟传书的典故写盼望书信，"几时"二字写出了等待的焦急。"玉虫连夜剪春幡"以灯蛾扑火写自己的不眠，"连夜"写彻夜难眠。"不禁辛苦况相关"以自己尚且不堪辛苦，何况彼此牵挂收束，写出了相思的深重。全词以折柳起笔，以相思收束，用典精切，情致深婉，体现了纳兰词清丽哀婉的艺术风格。

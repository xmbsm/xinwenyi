# 秋柳·其二

**[清] [王士禛](/authors/wangshizhen)**

## 原文

娟娟凉露欲为霜，万缕千条拂玉塘。

浦里青荷中妇镜，江干黄竹女儿箱。

空怜板渚隋堤水，不见琅琊大道王。

若过洛阳风景地，含情重问永丰坊。

## 注释

- **秋柳**：诗题，此为《秋柳四首》中的第二首。
- **娟娟**：美好貌。
- **凉露欲为霜**：寒露将凝为霜，指深秋时节。
- **万缕千条**：形容柳枝繁多。
- **拂玉塘**：拂过如玉的水塘。
- **浦里**：水滨。
- **青荷中妇镜**：青荷如妇人之镜。
- **江干**：江岸。
- **黄竹女儿箱**：黄竹如女儿之箱奁。
- **空怜**：徒然怜惜。
- **板渚**：地名，在今河南，隋炀帝曾在此种柳。
- **隋堤**：隋炀帝所筑的堤岸，多种柳树。
- **琅琊大道王**：指王导，琅琊人，东晋名臣。
- **永丰坊**：洛阳坊名，白居易《杨柳枝词》有"永丰西角荒园里，尽日无人属阿谁"之句。

## 译文

美好的凉露将要凝成秋霜，万千柳条拂过如玉的池塘。水滨的青荷如妇人的明镜，江岸的黄竹如女儿的箱奁。

徒然怜惜板渚隋堤的流水，却再也见不到琅琊大道的王。若经过洛阳那风景之地，含情脉脉重新寻问永丰坊。

## 赏析

《秋柳·其二》是王士禛《秋柳四首》中的第二首，延续了第一首的感伤基调，以秋柳寄托兴亡之叹。"娟娟凉露欲为霜，万缕千条拂玉塘"写深秋时节的柳树，凉露将凝为霜，万千柳条拂过池塘，"娟娟"写露珠之美，"欲为霜"点明深秋时节，柳树在秋意中更显萧瑟。"浦里青荷中妇镜，江干黄竹女儿箱"以青荷比妇人之镜、黄竹比女儿之箱，以闺中之物写水滨景物，联想奇特，"中妇""女儿"的引入使秋景多了几分柔情。颈联"空怜板渚隋堤水，不见琅琊大道王"转写怀古，隋堤柳是著名古迹，琅琊王指南渡的名臣王导，"空怜"与"不见"对举，写出了物是人非的感慨，昔日繁华已成陈迹。尾联"若过洛阳风景地，含情重问永丰坊"用白居易《杨柳枝词》"永丰西角荒园里，尽日无人属阿谁"的典故，以永丰坊的柳树暗喻秋柳的零落，"含情重问"写出了诗人对历史兴亡的深情追问。全诗用典精当，含蓄蕴藉，体现了王士禛神韵说的诗学主张，是清初诗坛的代表作。

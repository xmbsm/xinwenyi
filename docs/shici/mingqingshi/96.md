# 卖花词

**[明] [高启](/authors/gaoqi)**

## 原文

绿盆小树枝枝好，花比人家别开早。

陌头担得春风行，美人出帘闻叫声。

移去莫愁花不活，卖与还传种花诀。

余香满路日暮归，犹有蜂蝶相随飞。

买花朱门几回改，不如担上花长在。

## 注释

- **绿盆**：绿色的花盆。
- **枝枝好**：每枝都好。
- **别开早**：比别家的花开得早。
- **陌头**：街头。
- **担得春风行**：担着花如担着春风行走。
- **出帘**：掀开帘子出来。
- **移去**：移栽花木。
- **种花诀**：种花的秘诀。
- **余香满路**：一路留有余香。
- **朱门**：富贵人家。
- **几回改**：几经变换主人。

## 译文

绿盆中的小树每枝都好，花比人家别处开得早。街头担着春风一路行走，美人掀开帘子听到叫卖声。

移栽去不要愁花不活，卖花时还传授种花的秘诀。日暮归来一路余香弥漫，还有蜂蝶一路相随飞舞。买花的朱门富贵人家几经变换，不如花担上的花长在不变。

## 赏析

《卖花词》是高启写卖花人生活的乐府诗。开头"绿盆小树枝枝好，花比人家别开早"写花的美好，绿盆小树、枝枝皆好、花开早，以朴素的语言写出了花的品质。"陌头担得春风行，美人出帘闻叫声"写卖花的情景，"担得春风"四字极妙，将卖花人担花行走比作担着春风，写出了花的美好与卖花人的自豪，"美人出帘"写买花人的呼应，生动传神。"移去莫愁花不活，卖与还传种花诀"写卖花人的热情和诚信，不仅保证花能成活，还传授种花秘诀，写出了卖花人的淳朴。"余香满路日暮归，犹有蜂蝶相随飞"写日暮归去，余香满路、蜂蝶相随，以景写人，烘托出卖花人生活的诗意。结句"买花朱门几回改，不如担上花长在"以朱门易主、花担长在作对比，写出了富贵无常而卖花人的生活永恒，寓意深远。全诗语言朴素自然，意境清新，体现了高启诗歌关注平民生活的艺术特色。

# 观书

**[明] [于谦](/authors/yuqian)**

## 原文

书卷多情似故人，晨昏忧乐每相亲。

眼前直下三千字，胸次全无一点尘。

活水源流随处满，东风花柳逐时新。

金鞍玉勒寻芳客，未信我庐别有春。

## 注释

- **书卷**：书籍。
- **多情似故人**：多情如同老朋友。
- **晨昏**：早晚。
- **相亲**：亲近。
- **直下**：一目十行地读下。
- **胸次**：胸中，心里。
- **尘**：杂念，世俗之念。
- **活水**：源远流长的流水。
- **随处满**：到处充盈。
- **逐时新**：随时更新。
- **金鞍玉勒**：华贵的马鞍和马勒，指富贵人家的装饰。
- **寻芳客**：游春赏花的人。
- **我庐**：我的书房。

## 译文

书卷多情如同老朋友，早晚忧乐都与我亲近。眼前一气读下三千字，胸中没有一点世俗之尘。

活水源流随处充盈，东风花柳随时更新。那些金鞍玉勒的寻芳客，不信我书房别有春光。

## 赏析

《观书》是于谦写读书乐趣的名篇。首联"书卷多情似故人，晨昏忧乐每相亲"以拟人手法将书卷比作多情的老友，早晚相伴、忧乐与共，写出了与书的亲密关系。颔联"眼前直下三千字，胸次全无一点尘"写读书之乐，一目十行读下三千字，胸中却不沾染一点世俗杂念，写出了读书使人心境澄明的境界。颈联"活水源流随处满，东风花柳逐时新"以活水充盈、花柳时新比喻书中知识源源不断、日日常新。尾联"金鞍玉勒寻芳客，未信我庐别有春"以富贵人家的寻芳游乐反衬自己书房中的别样春光，表达了对读书之乐的珍视。全诗语言明白晓畅，对仗工整，以书卷为春光，写出了读书人独有的精神境界，体现了于谦清正廉洁的品格。

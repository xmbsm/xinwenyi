# 旅夜书怀

**[唐] [杜甫](/authors/dufu)**

## 原文

细草微风岸，危樯独夜舟。
星垂平野阔，月涌大江流。
名岂文章著，官应老病休。
飘飘何所似，天地一沙鸥。

## 注释

- 旅夜：旅行的夜晚。
- 书怀：抒发情怀。
- 危樯（qiáng）：高高的桅杆。
- 独夜舟：夜间孤停的船。
- 星垂：星光下垂，形容平野广阔，星光遥挂天际。
- 平野阔：原野广阔。
- 月涌：月亮随水波涌动。
- 大江：长江。
- 名岂文章著：名声难道是因为文章而著称吗？
- 官应老病休：做官应该因年老多病而退休。
- 飘飘：漂泊不定的样子。
- 沙鸥：一种水鸟。

## 译文

微风吹拂着长着细草的江岸，高高的桅杆耸立在夜间的孤舟上。星光垂挂在广阔的平野之上，月影随波涛涌动在奔流的大江中。名声难道是因为文章而著称吗？做官应该因年老多病而退休。我漂泊不定像什么呢？就像天地间一只孤零零的沙鸥。

## 赏析

这首诗是杜甫永泰元年（765年）携家离开成都沿江东下时所作，抒发了诗人漂泊无依的孤寂和身世飘零的感慨。

首联"细草微风岸，危樯独夜舟"，写旅夜泊舟的情景。微风、细草、江岸、高桅、孤舟，构成了一幅孤寂的旅夜图景。"独"字既写舟之孤，也写人之孤，为全诗奠定了孤寂的基调。

颔联"星垂平野阔，月涌大江流"，是千古传诵的名句。星光垂挂在广阔的平野之上，月影涌动在奔流的大江之中。"垂"字写平野之阔，"涌"字写江流之急，两句气象宏大，境界开阔，将星空、平野、月影、江流融为一幅壮丽的画面。然而这壮阔的景象反衬出诗人的渺小和孤寂。

颈联"名岂文章著，官应老病休"，是诗人的感慨。"名岂文章著"是反问——名声难道只是因为文章而著称吗？言外之意是诗人的抱负不仅在于文章。"官应老病休"是自嘲——做官应该因老病而退休。这两句含蓄地表达了诗人怀才不遇的愤懑。

尾联"飘飘何所似，天地一沙鸥"，以沙鸥自比。诗人漂泊不定，像什么呢？就像天地间一只孤零零的沙鸥。这一比喻形象生动，将诗人的漂泊之感和孤寂之情表现得淋漓尽致——天地之大，却无诗人容身之所，只有一只沙鸥与之相似。

全诗情景交融，以壮阔之景衬孤寂之情，意境深远，是杜甫五律的代表作。

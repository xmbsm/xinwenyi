# 岁暮归南山

**[唐] [孟浩然](/authors/menghaoran)**

## 原文

北阙休上书，南山归敝庐。
不才明主弃，多病故人疏。
白发催年老，青阳逼岁除。
永怀愁不寐，松月夜窗虚。

## 注释

- 岁暮：年终。
- 南山：此处指岘山，在孟浩然家乡襄阳。
- 北阙：古代宫殿北面的门楼，是大臣等候朝见或上书奏事的地方。
- 休上书：不要再上书朝廷。
- 敝庐：破旧的房屋，谦称自己的家。
- 不才：没有才能，自谦之词。
- 明主：英明的君主。
- 多病：体弱多病。
- 故人疏：老朋友渐渐疏远了。
- 白发：白头发。
- 青阳：指春天。
- 岁除：年终，岁末。
- 永怀：深深的感慨。
- 愁不寐：因愁苦而睡不着。
- 松月：松间明月。
- 窗虚：窗户空明。

## 译文

不必再向朝廷上书言事，还是回到南山下的破旧茅庐。我因没有才能被英明的君主弃置，又因多病故交也渐渐疏远。白发催人衰老，春日逼近岁末。满怀愁绪难以入眠，只见松间月光照在空明的窗上。

## 赏析

这首诗是孟浩然仕途失意后归隐南山时所作，抒发了怀才不遇的感慨和归隐的无奈。

首联"北阙休上书，南山归敝庐"，写诗人决定不再向朝廷上书，回归南山下的旧居。"休"字写出了诗人的无奈和决绝，一个"归"字则表明了归隐的决心。

颔联"不才明主弃，多病故人疏"，是全诗的名句，写诗人的处境。"不才明主弃"表面是自谦，实则含蓄地表达了对不被重用的不满；"多病故人疏"则写出了世态炎凉、人情冷暖。这两句语含愤激，却以自嘲的口吻出之，更觉凄凉。

颈联"白发催年老，青阳逼岁除"，写时光的流逝。"催"字和"逼"字，写出了时光的无情和诗人的紧迫感。白发催人老去，春日逼近岁末，年华虚度，功业无成，令人感伤。

尾联"永怀愁不寐，松月夜窗虚"，写诗人的愁苦。"永怀愁不寐"直抒胸臆，写愁深难眠；"松月夜窗虚"以景结情，松间月色照在空窗之上，"虚"字既写窗之空明，也写心境之空虚。

全诗语言质朴，感情深沉，将仕途失意的感慨和归隐后的孤寂融为一体，是孟浩然抒怀诗的代表作。

# 春夜喜雨

**[唐] [杜甫](/authors/dufu)**

## 原文

好雨知时节，当春乃发生。
随风潜入夜，润物细无声。
野径云俱黑，江船火独明。
晓看红湿处，花重锦官城。

## 注释

- 知时节：知道下雨的节气。
- 当春：正当春天。
- 发生：使植物萌发，生长。
- 潜：暗暗地，悄悄地。
- 润物：使万物受到润泽。
- 野径：野外的道路。
- 花重：花因沾雨水而显得沉重。
- 锦官城：成都的别称。

## 译文

好雨知道下雨的节气，正是在春天植物萌发的时候。它伴随着春风悄悄地在夜间下起，无声地滋润着万物。野外的道路和天上的云都是黑沉沉的，只有江船上的灯火独自明亮。等天亮一看，那红花沾满雨水的地方，锦官城里的花都沉甸甸的。

## 赏析

这首诗是杜甫寓居成都时所作，描绘了春夜降雨的景象，抒发了诗人对春雨的喜爱之情。

首联"好雨知时节，当春乃发生"，以拟人手法写春雨。"知时节"三字，将雨拟人化，仿佛雨有知觉，知道春天万物需要滋润而适时降下。"好"字是全诗的诗眼，奠定了喜悦的基调。

颔联"随风潜入夜，润物细无声"，是千古传诵的名句。"潜"字写雨的悄然，"细无声"写雨的细微。春雨伴随春风，在夜间悄悄降下，无声地滋润万物。这两句将春雨的轻柔、细密、无私写得生动传神，表现了诗人对春雨的赞美。

颈联"野径云俱黑，江船火独明"，写雨夜的景色。野外道路和天上云都是黑沉沉的，只有江船上的灯火独自明亮。这一明一暗的对比，写出了雨夜的景象，也暗示了雨势之大、之广。

尾联"晓看红湿处，花重锦官城"，是诗人的想象。诗人想象天亮后，锦官城里红花沾满雨水，沉甸甸地开放。这一想象，将雨后的美景提前展现，表现了诗人对春雨的期待和喜悦。

全诗围绕"喜"字展开，从雨之"好"到雨之"潜"，从雨夜之景到雨后之想，层层展开，将春雨的种种情态写得生动传神。语言精练，对仗工整，意境优美，是咏雨诗中的佳作。

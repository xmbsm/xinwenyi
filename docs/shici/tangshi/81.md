# 咏怀古迹·其三

**[唐] [杜甫](/authors/dufu)**

## 原文

群山万壑赴荆门，生长明妃尚有村。
一去紫台连朔漠，独留青冢向黄昏。
画图省识春风面，环珮空归夜月魂。
千载琵琶作胡语，分明怨恨曲中论。

## 注释

- 咏怀古迹：借咏古迹以抒怀。
- 明妃：即王昭君，名嫱，汉元帝时宫女，后远嫁匈奴呼韩邪单于。晋时避司马昭讳，改称明妃。
- 尚有村：昭君村在今湖北秭归县。
- 紫台：紫宫，天子所居之处，此处指汉宫。
- 朔漠：北方沙漠，指匈奴之地。
- 青冢：昭君墓，在今内蒙古呼和浩特市南，相传墓上草色常青。
- 画图：汉元帝按画图召幸宫女，昭君因不肯贿赂画工毛延寿，被画得丑陋，未得召幸。
- 省识：认识，辨认。
- 春风面：形容昭君的美貌。
- 环珮：妇女佩戴的玉饰。
- 夜月魂：昭君死于匈奴，魂魄在月夜归来。
- 胡语：胡人的乐曲，指琵琶曲。
- 分明怨恨：昭君的怨恨在琵琶曲中分明可闻。

## 译文

群山万壑奔赴荆门，那里还有昭君生长的村庄。她一离开汉宫就远嫁北方沙漠，只留下一座青冢面对着黄昏。汉元帝只能凭画图辨认她的美貌，她的魂魄佩着环珮在月夜空归。千年来琵琶弹奏出胡地的曲调，分明在曲中诉说着她的怨恨。

## 赏析

这首诗是杜甫《咏怀古迹》五首中的第三首，借咏王昭君的古迹，抒发了对昭君命运的同情，也寄寓了诗人自己怀才不遇的感慨。

首联"群山万壑赴荆门，生长明妃尚有村"，写昭君村的所在。群山万壑奔赴荆门，那里就是昭君生长的村庄。"赴"字写山势的雄奇，为昭君的出生地增添了不凡的气势，也暗示了昭君的不凡。

颔联"一去紫台连朔漠，独留青冢向黄昏"，概括昭君的一生。"一去"写她离开汉宫，远嫁匈奴；"独留"写她死后孤坟独对黄昏。"紫台"与"朔漠"相对，"一去"与"独留"相承，将昭君的命运浓缩在十四字中，悲凉而深沉。

颈联"画图省识春风面，环珮空归夜月魂"，写昭君的悲剧根源和死后的魂归。汉元帝只凭画图辨认昭君，错过了她的真容；昭君死后，魂魄在月夜佩环归来。前者写生前的遗憾，后者写死后的哀怨，将昭君的悲剧表现得深沉动人。

尾联"千载琵琶作胡语，分明怨恨曲中论"，写昭君的怨恨流传千载。千年来琵琶弹奏胡曲，分明在诉说着昭君的怨恨。相传昭君在匈奴曾作怨思之歌，这里借琵琶曲表达昭君的怨恨，也寄寓了诗人自己的感慨。

全诗借古咏怀，将昭君的悲剧与诗人的身世之感融为一体，沉郁顿挫，感人至深。

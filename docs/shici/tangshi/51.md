# 登鹳雀楼

**[唐] [王之涣](/authors/wangzhihuan)**

## 原文

白日依山尽，黄河入海流。
欲穷千里目，更上一层楼。

## 注释

- 鹳雀楼：又名鹳鹊楼，故址在今山西永济市蒲州古城西面的黄河东岸，因时有鹳雀栖其上而得名。
- 白日：太阳。
- 依：依傍，沿着。这里指太阳依傍着山峦落下。
- 尽：消失，落下。
- 穷：尽，达到极点。
- 千里目：眼界宽阔，能看到千里之外的景物。
- 更：再。

## 译文

夕阳依傍着西山慢慢地沉没，滔滔黄河朝着大海汹涌奔流。若想把千里的风光景物看够，那就要登上更高的一层城楼。

## 赏析

这首诗是唐代诗人王之涣仅存的六首绝句之一，也是一首脍炙人口的名篇。诗人登临鹳雀楼，俯瞰山河壮丽景色，抒发了积极向上的进取精神和高瞻远瞩的胸襟抱负。

诗的前两句写所见之景。"白日依山尽"写远眺西方，落日依山而尽，景象苍茫辽阔；"黄河入海流"写俯瞰东方，黄河奔腾入海，气势雄浑磅礴。一高一低，一西一东，一静一动，构成了一幅宏伟壮丽的山河图景。这两句已经写尽了鹳雀楼所见的壮阔景象，意境开阔，气魄宏大。

后两句写所感之情。"欲穷千里目，更上一层楼"，由景生情，蕴含着深刻的哲理。诗人不满足于眼前的景色，想要看得更远，就要登上更高的楼层。这两句既写出了登楼的实感，又蕴含着"站得高才能看得远"的人生哲理，鼓励人们不断进取，向更高的境界攀登。

全诗仅二十字，却包容了天地宇宙，融景、情、理于一炉。语言通俗明快，对仗工整，气势磅礴，意境深远，千百年来一直被人们传诵，成为激励人们奋发向上的千古名句。

# 秋兴八首·其一

**[唐] [杜甫](/authors/dufu)**

## 原文

玉露凋伤枫树林，巫山巫峡气萧森。
江间波浪兼天涌，塞上风云接地阴。
丛菊两开他日泪，孤舟一系故园心。
寒衣处处催刀尺，白帝城高急暮砧。

## 注释

- 秋兴：因秋景而引起的感慨。
- 玉露：白露，指秋天的霜露。
- 凋伤：使草木凋零衰败。
- 巫山巫峡：在今重庆巫山县一带。
- 萧森：萧瑟阴森。
- 江间：指巫峡中的长江。
- 兼天涌：波浪连天涌起。
- 塞上：边塞，此处指巫山一带。
- 接地阴：云雾连接地面，阴暗一片。
- 两开：菊花两次开放，指过了两个秋天。
- 他日泪：往日的眼泪。
- 一系：系着，拴着。
- 故园心：思念故乡的心情。
- 催刀尺：催促裁剪新衣。
- 白帝城：在今重庆奉节县。
- 急暮砧（zhēn）：傍晚急促的捣衣声。砧，捣衣石。

## 译文

秋露使枫树林凋零衰败，巫山巫峡气象萧瑟阴森。江间波浪连天涌起，塞上风云接地阴暗。丛菊两次开放，引出往日的眼泪；孤舟系岸，系着思念故园的心情。到处都在催促裁剪寒衣，白帝城高处传来傍晚急促的捣衣声。

## 赏析

这首诗是杜甫《秋兴八首》的第一首，是杜甫寓居夔州时所作组诗的开篇。全诗以萧瑟的秋景为背景，抒发了诗人羁旅漂泊的愁绪和对故园的思念。

首联"玉露凋伤枫树林，巫山巫峡气萧森"，写夔州秋景。白露凋伤枫林，巫山巫峡气象萧瑟——"凋伤"二字既写景物的衰败，也透露出诗人的伤感；"萧森"二字写出了山峡的阴森萧瑟，为全诗奠定了凄凉的基调。

颔联"江间波浪兼天涌，塞上风云接地阴"，写巫峡的壮阔景象。江间波浪连天涌起，塞上风云接地阴暗——"兼天涌"写波浪之高，"接地阴"写云雾之低，两句构成了一幅壮阔而阴暗的图景，既是写景，也象征着时局的动荡。

颈联"丛菊两开他日泪，孤舟一系故园心"，由景入情。菊花两开，意味着诗人流落夔州已经两年，每次见菊开都流泪；孤舟系岸，却系着思念故园的心。"两开"与"一系"相对，"他日泪"与"故园心"相承，将诗人的羁旅之愁和思乡之情表现得深沉含蓄。

尾联"寒衣处处催刀尺，白帝城高急暮砧"，写傍晚的捣衣声。处处都在催促裁剪寒衣，白帝城高处传来急促的捣衣声——这是秋天的典型景象，也勾起了诗人的乡愁。暮砧之声，意味着冬天将至，游子思归，却不能归，愁绪更深。

全诗情景交融，意境深远，将夔州的秋景与诗人的身世之悲、故园之思融为一体，是《秋兴八首》的纲领之作。

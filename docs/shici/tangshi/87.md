# 绝句

**[唐] [杜甫](/authors/dufu)**

## 原文

两个黄鹂鸣翠柳，一行白鹭上青天。
窗含西岭千秋雪，门泊东吴万里船。

## 注释

- 黄鹂：黄莺。
- 翠柳：翠绿的柳树。
- 白鹭：一种白色水鸟。
- 青天：蓝天。
- 窗含：窗户像画框一样框住景色，仿佛"含"在其中。
- 西岭：指岷山，在成都西面。
- 千秋雪：千年不化的积雪。
- 门泊：门前停泊着。
- 东吴：指长江下游一带。
- 万里船：从万里之外东吴来的船。

## 译文

两只黄鹂在翠绿的柳枝间鸣叫，一行白鹭飞上了蔚蓝的天空。窗户里仿佛含着西岭千年不化的积雪，门前停泊着从东吴万里而来的船只。

## 赏析

这首诗是杜甫广德二年（764年）在成都草堂所作，描绘了草堂周围明媚的春光，表现了诗人心情的愉悦和对和平生活的向往。

首句"两个黄鹂鸣翠柳"，写近景。黄鹂鸣于翠柳，黄绿相间，有声有色，写出了春日的生机。次句"一行白鹭上青天"，写远景。白鹭飞上青天，白蓝相映，写出了天空的开阔。前两句一近一远，一静一动，色彩鲜明，构成了一幅明媚的春景图。

第三句"窗含西岭千秋雪"，写远景。窗户仿佛含着西岭的千秋积雪，"含"字将窗比作画框，将远山雪景收入其中，构思巧妙。"千秋雪"写出了时间的久远。

第四句"门泊东吴万里船"，写近景。门前停泊着东吴万里而来的船只，"万里船"写出了空间的广阔——东吴的船能到达成都，说明战乱后水路已通，和平有望。

全诗四句，每句一景，看似各自独立，实则构成一幅完整的画面。诗人以黄、翠、白、青等明丽的色彩，描绘出一幅生机盎然的春景图，表现了诗人心情的愉悦。尤其是"窗含"二字，将窗比作画框，将自然景色化为窗中之画，构思精巧，体现了杜甫诗的艺术魅力。

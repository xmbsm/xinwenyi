# 庐山谣寄卢侍御虚舟

**[唐] [李白](/authors/libai)**

## 原文

我本楚狂人，凤歌笑孔丘。
手持绿玉杖，朝别黄鹤楼。
五岳寻仙不辞远，一生好入名山游。
庐山秀出南斗傍，屏风九叠云锦张，
影落明湖青黛光，金阙前开二峰长，
银河倒挂三石梁。
香炉瀑布遥相望，回崖沓嶂凌苍苍。
翠影红霞映朝日，鸟飞不到吴天长。
登高壮观天地间，大江茫茫去不还。
黄云万里动风色，白波九道流雪山。
好为庐山谣，兴因庐山发。
闲窥石镜清我心，谢公行处苍苔没。
早服还丹无世情，琴心三叠道初成。
遥见仙人彩云里，手把芙蓉朝玉京。
先期汗漫九垓上，愿接卢敖游太清。

## 注释

- **卢侍御虚舟**：卢虚舟，字幼真，范阳人，时任殿中侍御史。
- **楚狂人**：指春秋时楚国狂士接舆，曾唱着歌嘲笑孔子。
- **凤歌**：接舆唱的歌中有"凤兮凤兮"之句。
- **绿玉杖**：镶有绿玉的手杖。
- **黄鹤楼**：在今湖北武汉。
- **南斗**：星名，即斗宿。
- **屏风九叠**：庐山九叠屏，山岭重叠如屏风。
- **云锦**：云彩如锦。
- **青黛光**：青黑色的光影。
- **金阙**：指金阙岩，庐山山峰。
- **三石梁**：庐山三石梁瀑布。
- **香炉瀑布**：庐山香炉峰瀑布。
- **回崖沓嶂**：曲折的山崖和重叠的山峰。
- **琴心三叠**：道家修炼的一种功夫，使心神平和。
- **玉京**：道教称元始天尊居处为玉京山。
- **九垓**：九天，极言其高。
- **卢敖**：秦代仙人，此处借指卢虚舟。
- **太清**：道家以玉清、上清、太清为三清，太清为最高仙境。

## 译文

我本是像楚狂接舆一样的狂士，唱着凤歌嘲笑孔丘。手持绿玉杖，清晨告别黄鹤楼。寻访五岳仙人不怕路远，一生喜欢游历名山大川。庐山秀美地耸立在北斗旁边，九叠屏风如云锦般展开，倒影落在明净的鄱阳湖中泛着青黛色的光。金阙岩前两座山峰并立，三石梁瀑布如银河倒挂。香炉峰瀑布遥遥相望，曲折的山崖和重叠的山峰直插苍穹。翠绿的山影和红色的霞光映照着朝阳，鸟儿飞不到的吴天辽远。登高远望天地之间的壮景，大江茫茫东去不复还。万里黄云随风变幻，九道白波绕着雪山奔流。我喜好作这首庐山谣，兴致因庐山而激发。闲看石镜清我心境，谢灵运走过的地方已长满青苔。早日服食还丹断绝世俗之情，琴心三叠修练道法初成。远远望见仙人站在彩云之中，手执芙蓉花朝拜玉京。早已与汗漫相约于九天之上，愿像接引卢敖那样带你同游太清仙境。

## 赏析

这首诗是李白流放夜郎途中遇赦后游庐山时所作，寄给好友卢虚舟。全诗以雄奇的笔调描绘了庐山的壮美风光，抒发了诗人蔑视世俗、向往仙道的旷达情怀。

开头"我本楚狂人，凤歌笑孔丘"，诗人以楚狂接舆自比，表现出对世俗礼法的蔑视和狂放不羁的性格。接着写自己手持绿玉杖、朝别黄鹤楼、遍游五岳名山的经历，展现出飘逸豪迈的形象。中间描写庐山风光，笔力雄健——秀出的山峰、九叠的云锦、倒挂的瀑布、苍苍的层嶂、映日的红霞，构成一幅气势磅礴的庐山画卷。"登高壮观天地间，大江茫茫去不还"二句，视野更为开阔，由庐山而及长江，写出了天地之大、江水之壮，气魄宏大。

后半部分由写景转入抒情，写诗人窥石镜而清心，服还丹而修道，遥见仙人，愿游太清。全诗浪漫主义色彩浓厚，想象奇特，意境壮阔，充分体现了李白诗歌豪放飘逸的风格。

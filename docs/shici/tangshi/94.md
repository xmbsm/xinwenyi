# 十五夜望月

**[唐] [王建](/authors/wangjian)**

## 原文

中庭地白树栖鸦，冷露无声湿桂花。
今夜月明人尽望，不知秋思落谁家。

## 注释

- 十五夜：指中秋之夜。
- 中庭：庭院中。
- 地白：满地月光，白如霜雪。
- 树栖鸦：树上栖息着乌鸦。
- 冷露：秋夜的寒露。
- 湿桂花：打湿了桂花。
- 人尽望：人人都在望月。
- 秋思（sī）：秋天的思绪，指思念之情。

## 译文

庭院里满地月光，树上栖息着乌鸦；秋夜的寒露无声地打湿了桂花。今夜月光明亮，人人都在望月，不知道那秋天的思念落在了谁家。

## 赏析

这首诗是王建的中秋咏月诗，通过中秋望月的描写，抒发了诗人深沉的思乡之情。

首句"中庭地白树栖鸦"，写中秋之夜的景象。庭院里满地月光，白如霜雪；树上栖息着乌鸦。"地白"二字写月光之明，"树栖鸦"三字写夜之静——乌鸦已经栖息，可见夜已深。这一句营造了一种清冷寂静的氛围。

次句"冷露无声湿桂花"，进一步写夜景。秋夜的寒露无声地打湿了桂花。"冷露"写寒气，"无声"写寂静，"湿桂花"写露水之重。桂花是中秋时节的代表花卉，这一句既写景，也暗示了中秋的时节。

后两句"今夜月明人尽望，不知秋思落谁家"，是全诗的点睛之笔。今夜月光明亮，人人都在望月；不知道那秋天的思念落在了谁家。这里诗人不直说自己思乡，而说"不知秋思落谁家"——仿佛秋思是有形的，会落在某一家。这种拟人化的手法，将诗人的思乡之情表现得含蓄深沉。

全诗以清冷的景色衬托深沉的思乡之情，语言凝练，意境深远。"不知秋思落谁家"一句，将思乡之情化为有形的"秋思"，构思巧妙，成为千古传诵的名句。

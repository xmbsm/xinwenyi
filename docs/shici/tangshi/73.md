# 新婚别

**[唐] [杜甫](/authors/dufu)**

## 原文

兔丝附蓬麻，引蔓故不长。
嫁女与征夫，不如弃路旁。
结发为君妻，席不暖君床。
暮婚晨告别，无乃太匆忙！
君行虽不远，守边赴河阳。
妾身未分明，何以拜姑嫜？
父母养我时，日夜令我藏。
生女有所归，鸡狗亦得将。
君今往死地，沉痛迫中肠。
誓欲随君去，形势反苍黄。
勿为新婚念，努力事戎行！
妇人在军中，兵气恐不扬。
自嗟贫家女，久致罗襦裳。
罗襦不复施，对君洗红妆。
仰视百鸟飞，大小必双翔。
人事多错迕，与君永相望。

## 注释

- 新婚别：新婚夫妇的离别。
- 兔丝：兔丝子，一种蔓生植物，常依附他物生长。
- 蓬麻：蓬草和麻，都比较低矮。
- 结发：古代男子二十岁束发，女子十五岁及笄，此处指成婚。
- 无乃：岂不是。
- 河阳：今河南孟州市，当时是前线。
- 妾身未分明：古代婚礼，女子过门三日，先告庙，后拜公婆，才算名分分明。
- 姑嫜（zhāng）：婆婆和公公。
- 藏：深居闺中。
- 归：女子出嫁。
- 将（jiāng）：顺从，跟随。
- 死地：指战场。
- 苍黄：仓皇，慌张。
- 戎行（háng）：军队。
- 兵气：士气。
- 罗襦（rú）裳：丝绸衣裙。
- 红妆：女子盛饰。
- 错迕（wǔ）：错杂交忤，不如意。

## 译文

兔丝子依附在蓬麻上，藤蔓不会长得长。把女儿嫁给征夫，不如抛弃在路旁。结发成为您的妻子，席子还没暖热您的床。傍晚结婚，清晨就告别，岂不是太匆忙！您此行虽然不远，却是守边奔赴河阳。妾身的名分还未分明，怎么去拜见公婆？父母养育我时，日夜让我深藏闺中。生女儿总要出嫁，鸡犬也得相随。您如今前往死地，沉痛逼迫着心肠。本想发誓随您而去，形势反而会仓皇。不要为新婚而挂念，努力从军作战！妇人在军中，恐怕会影响士气。自叹贫家女子，好容易才置办了丝绸嫁衣。这嫁衣不再穿了，对着您洗去红妆。仰看百鸟飞翔，大小必然成双。人事多有不顺，与您永远相望。

## 赏析

这首诗是杜甫"三吏三别"之一，通过一位新婚少妇的口吻，抒写了新婚即别的悲痛和对丈夫的勉励，反映了安史之乱给人民带来的苦难。

全诗以少妇自述的形式展开。开头以"兔丝附蓬麻"起兴，比喻新婚夫妇的依附关系脆弱，引出"嫁女与征夫，不如弃路旁"的愤激之语。

"结发为君妻，席不暖君床。暮婚晨告别，无乃太匆忙！"写新婚即别的仓促。傍晚结婚，清晨离别，席未暖而人已去，写出了离别的匆忙和无奈。

"君行虽不远，守边赴河阳。妾身未分明，何以拜姑嫜？"写少妇的尴尬处境。婚礼未完成，名分未定，无法拜见公婆，写出了少妇的委屈和困惑。

"父母养我时"以下，回忆父母的教诲，写女子出嫁从夫的传统。"君今往死地，沉痛迫中肠"，表达对丈夫奔赴前线的悲痛。

"誓欲随君去，形势反苍黄"，写少妇想随夫而去却又不能的矛盾。"勿为新婚念，努力事戎行！"是少妇对丈夫的勉励——不要挂念新婚，要努力作战。这一勉励，体现了少妇深明大义的品格。

"妇人在军中，兵气恐不扬"，少妇解释自己不能随军的理由，进一步表明她以国事为重。

"自嗟贫家女"以下，写少妇洗去红妆，表示对丈夫的忠贞。"罗襦不复施，对君洗红妆"，这一举动既是诀别，也是明志。

结尾"仰视百鸟飞，大小必双翔。人事多错迕，与君永相望"，以鸟必双飞反衬人事的乖违，表达了少妇对丈夫的深情和永不相忘的誓言。

全诗以少妇口吻娓娓道来，感情真挚深沉，既有离别的悲痛，又有深明大义的勉励，是杜甫反映民间疾苦的代表作。

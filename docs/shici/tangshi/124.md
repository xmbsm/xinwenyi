# 李凭箜篌引

**[唐] [李贺](/authors/lihe)**

## 原文

吴丝蜀桐张高秋，空山凝云颓不流。
江娥啼竹素女愁，李凭中国弹箜篌。
昆山玉碎凤凰叫，芙蓉泣露香兰笑。
十二门前融冷光，二十三丝动紫皇。
女娲炼石补天处，石破天惊逗秋雨。
梦入神山教神妪，老鱼跳波瘦蛟舞。
吴质不眠倚桂树，露脚斜飞湿寒兔。

## 注释

- **李凭**：唐代著名的梨园弟子，善弹箜篌。
- **箜篌**：古代弦乐器。
- **引**：古代乐曲体裁之一。
- **吴丝蜀桐**：吴地的蚕丝和蜀地的桐木，都是制箜篌的上等材料。
- **张高秋**：在深秋时弹奏。张，调弦弹奏。
- **颓不流**：停滞不流。
- **江娥**：湘妃，舜帝的二妃，传说舜死，二妃哭于湘江，泪洒竹上成斑竹。
- **素女**：传说中的神女，善弹瑟。
- **中国**：指国都长安。
- **昆山玉碎**：昆仑山玉碎裂的声音。
- **凤凰叫**：凤凰的鸣叫声。
- **芙蓉泣露**：荷花上带着露珠如泣。
- **香兰笑**：兰花绽放如笑。
- **十二门**：长安城有十二座城门。
- **二十三丝**：箜篌有二十三根弦。
- **紫皇**：道教中的天帝。
- **女娲炼石补天**：神话中女娲炼五色石补天。
- **逗秋雨**：引落了秋雨。
- **神妪**：神山中的老妇，善弹箜篌。
- **吴质**：即吴刚，传说被罚在月宫伐桂。
- **露脚斜飞**：露水如雨斜飞。
- **寒兔**：月宫中的玉兔。

## 译文

用吴丝蜀桐制成的箜篌在深秋弹奏，空山中的云凝滞不流。湘妃洒泪竹上，素女也发愁，原来是李凭在长安弹奏箜篌。琴声如昆仑山玉碎，又似凤凰鸣叫；如荷花带露如泣，又如兰花绽放似笑。乐声使长安十二门前的冷光消融，二十三根弦震动了天帝。那声音传到女娲补天之处，石破天惊引落了秋雨。琴声梦入神山教神妪弹奏，老鱼跳波瘦蛟起舞。吴刚不眠倚着桂树倾听，露水斜飞打湿了月宫的寒兔。

## 赏析

这首诗是李贺描写音乐的代表作，以奇诡的想象和瑰丽的意象描绘了李凭弹奏箜篌的绝妙乐声，被誉为描写音乐的千古绝唱。

全诗可分为四个层次。前四句为第一层，写箜篌的精良和李凭技艺的高超。吴丝蜀桐，是上等材料；空山凝云不流，以云的凝滞写乐声的动人——连云都被吸引而停滞了。江娥啼竹、素女发愁，以神话人物的反衬写乐声的悲凉。中间四句为第二层，正面描写乐声。"昆山玉碎凤凰叫"以玉碎和凤鸣比喻乐声的清脆高亢；"芙蓉泣露香兰笑"以荷花带露和兰花绽放比喻乐声的悲泣和欢悦——四个意象两两对比，写出了乐声的丰富多变。"十二门前融冷光，二十三丝动紫皇"，写乐声使长安城的冷光消融，震动了天帝——由人间写到天上。

"女娲炼石补天处，石破天惊逗秋雨"为第三层，是全诗的名句。乐声传到女娲补天之处，"石破天惊"四字，写出了乐声的震撼力量——连补天的五色石都被震破，引落了秋雨。这一想象奇绝，前无古人。"梦入神山"以下为第四层，写乐声入神山教神妪，老鱼跳波瘦蛟起舞——连水中的鱼龙都被感动。最后以吴刚不眠、玉兔沾露作结，写月宫中的吴刚和玉兔也被乐声吸引，进一步渲染了乐声的魅力。

全诗想象奇诡，意象瑰丽，以神话传说和自然意象描绘无形的乐声，化听觉为视觉，化无形为有形，充分体现了李贺"诗鬼"独特的艺术风格。

# 别董大

**[唐] [高适](/authors/gaoshi)**

## 原文

千里黄云白日曛，北风吹雁雪纷纷。
莫愁前路无知己，天下谁人不识君？

## 注释

- 董大：指唐代著名琴师董庭兰，在兄弟中排行第一，故称"董大"。
- 黄云：昏黄的云。
- 曛（xūn）：昏暗，指太阳黯淡。
- 北风吹雁：北风送走南飞的大雁。
- 雪纷纷：雪花纷飞。
- 前路：前方的路途。
- 知己：彼此相知而情谊深切的人。

## 译文

千里黄云遮蔽了黯淡的太阳，北风吹送着南飞的大雁，大雪纷纷扬扬。不要发愁前方的路上没有知己，普天之下有谁不认识您呢？

## 赏析

这首诗是高适送别友人董庭兰时所作，是唐代送别诗中的别调。与一般送别诗的凄婉缠绵不同，这首诗格调豪迈，气势雄壮，对友人充满了鼓励和信心。

前两句"千里黄云白日曛，北风吹雁雪纷纷"，写送别时的景色。千里黄云，白日昏暗，北风呼啸，大雁南飞，大雪纷飞——这是一幅凄寒苍茫的边塞冬日图景。这样的景色，本应勾起送别的愁绪，为下文的转折做铺垫。

后两句"莫愁前路无知己，天下谁人不识君"，是对友人的劝慰和鼓励。诗人劝友人不要担心前路无知己，因为以董大的才华和名望，天下谁人不识？这两句一反送别诗的凄婉之态，以豪迈的气概、昂扬的格调，表达了对友人的信心和祝福。

全诗以景衬情，前两句写景凄寒，后两句抒情豪迈，形成强烈对比。诗人不写离愁别绪，而以豪言壮语鼓励友人，体现了盛唐边塞诗人的胸襟气魄，也展现了高适诗"气骨"凛然的特色。

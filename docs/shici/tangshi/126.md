# 逢雪宿芙蓉山主人

**[唐] [刘长卿](/authors/liuchangqing)**

## 原文

日暮苍山远，天寒白屋贫。
柴门闻犬吠，风雪夜归人。

## 注释

- **芙蓉山**：山名，所在不详。
- **主人**：指留宿诗人的山家主人。
- **日暮**：傍晚。
- **苍山**：青色的山。
- **白屋**：贫家的房屋。古代平民房屋不施彩绘，称白屋。
- **贫**：简陋。
- **柴门**：用树枝编成的门。
- **犬吠**：狗叫。
- **夜归人**：夜间归来的人，指诗人自己。

## 译文

傍晚时分青山显得遥远，天寒地冻中简陋的白屋更加清贫。柴门外传来狗叫声，风雪之夜归来的是投宿的行人。

## 赏析

这首诗以凝练的笔触描绘了一幅风雪夜归图，写出了山居的清寒和夜归的情景，意境深远，韵味悠长。

前两句"日暮苍山远，天寒白屋贫"，写日暮投宿所见。傍晚时分，青山在暮色中显得更加遥远；天寒地冻，简陋的房屋更显清贫——"日暮"写时间，"苍山远"写空间的旷远，"天寒"写节候，"白屋贫"写居处的简陋。这两句从大处着笔，勾勒出一幅寒冷、荒凉的山野暮景。

后两句"柴门闻犬吠，风雪夜归人"，写夜归的情景。柴门外传来狗叫声，风雪之夜归来的是投宿的行人——由静转动，以犬吠打破寂静，写出了夜归的生动情景。"风雪夜归人"五字，既写出了归人的艰辛，又含着一种温暖的归宿感——虽然风雪交加，但终于找到了投宿之处。

全诗仅二十字，却从日暮写到夜归，从远景写到近景，从视觉写到听觉，层次分明。"风雪夜归人"一句尤为传神，以白描手法写出了一个生动的画面，成为千古名句。全诗语言凝练，意境深远，体现了刘长卿诗歌"五言长城"的特色。

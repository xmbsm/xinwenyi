# 鹊踏枝·谁道闲情抛掷久

**五代 · 冯延巳**

---

## 原文

谁道闲情抛掷久？
每到春来，惆怅还依旧。
日日花前常病酒，敢辞镜里朱颜瘦。
河畔青芜堤上柳。
为问新愁，何事年年有？
独立小桥风满袖，平林新月人归后。

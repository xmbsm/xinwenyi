# 鹊踏枝·谁道闲情抛掷久

**[五代] [冯延巳](/authors/fengyansi)**

## 原文

谁道闲情抛掷久，每到春来，惆怅还依旧。
日日花前常病酒，不辞镜里朱颜瘦。

河畔青芜堤上柳，为问新愁，何事年年有。
独立小桥风满袖，平林新月人归后。

## 注释

- **鹊踏枝**：词牌名，即《蝶恋花》。
- **闲情**：闲愁。
- **抛掷**：抛弃。
- **病酒**：因饮酒而病。
- **不辞**：不辞，不惜。
- **朱颜瘦**：红颜消瘦。
- **青芜**：青草。
- **何事**：为何。
- **独立**：独自站立。
- **平林**：平远的树林。
- **新月**：初出的月亮。

## 译文

谁说闲情已经抛弃很久，每到春天来到，惆怅依然如旧。
天天在花前常因饮酒而病，不惜镜中红颜消瘦。

河畔青草堤上杨柳，试问新愁，为何年年都有。
独自站在小桥上风满衣袖，平林新月升起在人归之后。

## 赏析

《鹊踏枝·谁道闲情抛掷久》是冯延巳的代表作。"谁道闲情抛掷久，每到春来，惆怅还依旧"以问句起笔，写闲情无法抛弃，每到春天惆怅依旧。"日日花前常病酒，不辞镜里朱颜瘦"以花前病酒、不惜消瘦写闲愁之深，"不辞"二字尤为沉痛。"河畔青芜堤上柳，为问新愁，何事年年有"以青草杨柳写春色，以"何事年年有"问新愁为何年年不绝。"独立小桥风满袖，平林新月人归后"以独立小桥、风满衣袖、平林新月写孤独意境，余韵悠长。全词以闲愁贯穿，意境深远，对北宋词人影响极大。

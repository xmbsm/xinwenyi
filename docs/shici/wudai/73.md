# 柳枝·风情渐老见春羞

**[五代] [李煜](/authors/liyu)**

## 原文

风情渐老见春羞，到处消魂感旧游。
多谢长条似相识，强垂烟态拂人头。

## 注释

- **柳枝**：词牌名。
- **风情**：风流情致。
- **渐老**：渐渐老去。
- **见春羞**：面对春天感到羞愧。
- **消魂**：伤神，形容极度感伤。
- **旧游**：昔日游赏之地或旧日交游之人。
- **多谢**：此处有致意、感谢之意。
- **长条**：指柳枝。
- **强垂**：勉强垂下。
- **烟态**：如烟的姿态，形容柳枝朦胧柔美。
- **拂人头**：拂过人的头顶。

## 译文

风流情致渐已老去，面对春天不禁感到羞愧，每到一处都令人伤神，感念旧日游赏。多谢柳条似乎还认得我，勉强垂下如烟的身姿拂过我的头顶。

## 赏析

《柳枝·风情渐老见春羞》是李煜的一首咏柳抒情之作。首句"风情渐老见春羞"以"风情渐老"写年华逝去，以"见春羞"写面对春光自惭形秽，将老去的感慨与惜春之情融为一体，"羞"字传神，写出了面对春光时的复杂心态。次句"到处消魂感旧游"写每到一处都伤神感旧，"消魂"一词极写感伤之深，"旧游"既指昔日游赏之地，也暗含对故国的思念。后两句"多谢长条似相识，强垂烟态拂人头"是全词的精彩之处，写柳枝似乎还认得词人，特意垂下拂过他的头顶，"多谢"以拟人手法写柳枝的有情，"强垂"二字尤为传神，写出柳枝似乎也带着某种无奈和勉强，与词人老去的境况相呼应。"烟态"形容柳枝如烟如雾的朦胧美，与全词哀婉的情调相协调。全词以咏柳写怀，借柳树的多情反衬人世的沧桑，语言含蓄隽永，情致深沉，是李煜词中别具一格的咏物之作。

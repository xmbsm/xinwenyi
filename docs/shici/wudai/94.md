# 菩萨蛮·杏花含露团香雪

**[五代] [温庭筠](/authors/wendingjun)**

## 原文

杏花含露团香雪，绿杨陌上多离别。

灯在月胧明，觉来闻晓莺。

玉钩褰翠幕，妆浅旧眉薄。

春梦正关情，镜中蝉鬓轻。

## 注释

- **菩萨蛮**：词牌名。
- **含露**：带着露水。
- **团香雪**：簇聚成团，白如香雪。
- **绿杨陌**：绿杨夹道的道路。
- **胧明**：朦胧微明。
- **觉来**：醒来。
- **晓莺**：清晨的黄莺。
- **玉钩**：玉制的帐钩。
- **褰**：揭起，挂起。
- **翠幕**：翠绿色的帷帐。
- **妆浅**：妆容淡薄。
- **旧眉薄**：隔夜的眉黛已淡薄。
- **关情**：牵动情思。
- **蝉鬓**：蝉翼般的鬓发，形容鬓发轻薄如蝉翼。

## 译文

杏花含着露水簇聚成团如香雪，绿杨夹道的陌上多有离别。

孤灯犹在月光朦胧微明，醒来时听到清晨黄莺啼叫。

玉钩挂起翠绿的帷帐，妆容淡薄旧眉已褪。春梦正牵动着情思，镜中蝉鬓轻柔如翼。

## 赏析

《菩萨蛮·杏花含露团香雪》是温庭筠《菩萨蛮》组词中的一首，写闺人伤别之情。起句"杏花含露团香雪，绿杨陌上多离别"以杏花如雪的春景起兴，"绿杨陌上多离别"以绿杨古道多离别之事，奠定了全词伤别的基调。"灯在月胧明，觉来闻晓莺"写清晨醒来的情景，孤灯犹在、月色朦胧、晓莺啼鸣，以清冷的晨景烘托离愁。下片"玉钩褰翠幕，妆浅旧眉薄"写起床梳妆，"妆浅旧眉薄"写隔夜妆容已淡，暗示了女子的慵懒与无心打扮。"春梦正关情，镜中蝉鬓轻"以春梦牵情、蝉鬓轻柔收束，"春梦"点明了梦境中的相思，"蝉鬓轻"既写鬓发之美，也暗含年华易逝的感慨。全词以秾艳精致的笔触写闺情，意象密集，辞藻华美，体现了温庭筠花间词秾艳深密的艺术风格。

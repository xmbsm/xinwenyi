# 临江仙·秣陵江上多离别

**[五代] [冯延巳](/authors/fengyansi)**

## 原文

秣陵江上多离别，雨晴芳草烟深。
路遥人去马嘶沉。
青帘斜挂，新柳万枝金。

隔江何处吹横笛？沙头惊起双禽。
徘徊一向几般心。
天长烟远，凝恨独沾襟。

## 注释

- **临江仙**：词牌名。
- **秣陵**：古地名，今南京。
- **雨晴**：雨后初晴。
- **烟深**：烟雾浓深。
- **马嘶沉**：马鸣声渐渐消失。
- **青帘**：酒旗，青色的布帘。
- **金**：指新柳在阳光下呈金黄色。
- **横笛**：笛子。
- **沙头**：沙洲边。
- **双禽**：成对的鸟。
- **徘徊一向**：徘徊片刻。一向，一晌，片刻。
- **几般心**：种种复杂的心情。
- **凝恨**：愁恨凝聚。
- **沾襟**：泪水沾湿衣襟。

## 译文

秣陵江上多有离别，雨后初晴，芳草间烟雾浓深。路途遥远，离去的人渐行渐远，马鸣声也消失了。青色酒帘斜挂在风中，新柳在阳光下如万枝金色。

隔江何处传来吹笛声？沙洲边惊飞起成双的水鸟。徘徊片刻，心中涌起种种复杂的情绪。天长路远，烟波浩渺，凝聚着愁恨，独自泪沾衣襟。

## 赏析

《临江仙·秣陵江上多离别》是冯延巳的一首送别怀人之作，以秣陵江上送别为背景，抒发了离愁别恨。上片写离别之景。"秣陵江上多离别，雨晴芳草烟深"以秣陵江上频繁的离别起笔，"多离别"三字写出了离别之频繁，"雨晴芳草烟深"以雨后芳草、烟雾浓深渲染迷蒙凄清的氛围。"路遥人去马嘶沉"写行人渐远，"路遥"写距离之远，"马嘶沉"写声音之消失，以听觉的变化写离人渐远。"青帘斜挂，新柳万枝金"以酒帘斜挂、新柳金黄写江边春景，金柳青帘色彩鲜明，却反衬离别之苦。下片写别后之情。"隔江何处吹横笛？沙头惊起双禽"以笛声惊鸟写别后的孤寂，笛声本已令人伤神，又惊飞双禽，更添孤独之感。"徘徊一向几般心"写徘徊不定、心绪纷乱，"几般心"三字写出了离别后复杂的心理活动。"天长烟远，凝恨独沾襟"以天长烟远收束，写愁恨凝聚、泪沾衣襟，"天长烟远"既写空间之辽远，也写愁思之绵长。全词以江上送别为线索，情景交融，语言清丽，意境深远，体现了冯延巳词善于写愁、以景寓情的艺术特色。

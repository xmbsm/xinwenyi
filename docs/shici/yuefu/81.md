# 上山采蘼芜

**汉 · 佚名**

## 原文

上山采蘼芜，下山逢故夫。
长跪问故夫，新人复何如？
新人虽言好，未若故人姝。
颜色类相似，手爪不相如。
新人从门入，故人从閤去。
新人工织缣，故人工织素。
织缣日一匹，织素五丈余。
将缣来比素，新人不如故。

## 注释

- **蘼芜**：香草名，又名江蓠，古人认为佩之可多生子。
- **长跪**：直身而跪，表示恭敬。
- **故夫**：前夫。
- **姝**：美好。
- **手爪**：指手艺，纺织技巧。
- **閤**：旁门，小门。
- **缣**：黄色的绢，质地较粗。
- **素**：白色的绢，质地细密。
- **匹**：量词，一匹为四丈。
- **将**：拿。

## 译文

上山采摘蘼芜草，下山遇见了前夫。长跪着询问前夫：新人怎么样呢？新人虽然说不错，但不如旧人美好。容貌也许差不多，手艺却比不上。新人从正门进来，旧人从旁门离去。新人擅长织缣，旧人擅长织素。织缣一天一匹，织素一天五丈多。拿缣和素一比较，新人不如旧人。

## 赏析

《上山采蘼芜》是一首汉乐府民歌，以弃妇与故夫途中相遇问答的形式，反映了封建社会中妇女被遗弃的悲惨遭遇。全诗以对话构成，巧妙地通过故夫之口，说出"新人不如故"的结论，既表现了弃妇的勤劳善良，也暗示了故夫的悔恨之情。诗中"颜色类相似，手爪不相如"以容貌与手艺作对比，强调劳动妇女的价值；"新人从门入，故人从閤去"以门户之别写出弃妇的屈辱。全篇语言朴素自然，不施雕琢，却将复杂的感情表现得含蓄深沉，是汉乐府中描写婚姻问题的名篇。

# 雉朝飞操

**汉 · 佚名**

## 原文

雉朝飞兮鸣相和，雌雄群飞于山阿。
我独何命兮未有家，时将暮兮可奈何。

## 注释

- **雉朝飞操**：汉乐府琴曲，相传为齐人牧犊子所作。
- **雉**：野鸡。
- **朝飞**：早晨飞翔。
- **鸣相和**：鸣叫声相互应和。
- **山阿**：山谷弯曲处。
- **何命**：什么命运。
- **未有家**：尚未成家。
- **时将暮**：天色将晚，也暗喻年华渐老。
- **可奈何**：无可奈何。

## 译文

野鸡在早晨飞翔鸣声相互应和，雌雄成群飞过山谷。我独有怎样的命运啊至今没有成家，时光将尽无可奈何。

## 赏析

《雉朝飞操》是汉乐府琴曲歌辞，相传为齐人牧犊子年五十无妻，见雉双飞而作。诗歌以雉鸟的双飞群游反衬诗人的孤独无偶，感情深沉动人。"雉朝飞兮鸣相和"以雉鸟朝飞、鸣声相和的欢快景象起笔，"雌雄群飞于山阿"进一步写雌雄成双成对的美好，为反衬蓄势。"我独何命兮未有家"转折陡起，以雉鸟之成双对比自己之孤独，"何命"二字饱含对命运的追问与不平。"时将暮兮可奈何"以日暮喻年迈，表达了韶华易逝、壮志未酬的无奈。全诗以乐景写哀情，以鸟之双飞反衬人之孤独，艺术手法高超。句式仿楚辞，以"兮"字为节奏，音韵悠长，情感深沉，是乐府琴曲中的名篇。

# 陇头流水歌辞

**北朝 · 佚名**

## 原文

陇头流水，流离山下。
念吾一身，飘然旷野。

## 注释

- **陇头流水歌辞**：北朝乐府民歌，属梁鼓角横吹曲。
- **陇头**：陇山之顶，在今陕西甘肃交界处。
- **流离**：水流淋漓的样子，也暗喻人漂泊流离。
- **念**：想到。
- **飘然**：孤独漂泊的样子。
- **旷野**：空旷的原野。

## 译文

陇山顶上的流水，淋漓不断地流向山下。想到我孤身一人，在空旷的原野上漂泊流浪。

## 赏析

《陇头流水歌辞》是北朝乐府民歌，属梁鼓角横吹曲。全诗仅四句十六字，却营造出苍凉辽阔的意境，抒发了游子漂泊异乡的孤独之感。"陇头流水，流离山下"以陇山流水起兴，"流离"一词既写水流的淋漓之态，又暗喻人的漂泊流离，一语双关，构思精巧。"念吾一身，飘然旷野"由景及人，以"一身"对"旷野"，以个体的渺小对衬天地的广阔，更显游子的孤独无依。"飘然"二字既写漂泊之态，又含飘零之悲。全诗语言极简，意象苍凉，以少胜多，充分体现了北朝民歌质朴刚健的风格。陇头流水从此成为后世诗词中羁旅漂泊的经典意象，对唐代边塞诗产生了深远影响。

# 远如期

**汉 · 佚名**

## 原文

远如期，益如寿，处天左侧，大乐万岁，与天无极。
雅乐陈，佳哉纷，单于自归，义如明。

## 注释

- **远如期**：鼓吹曲辞（铙歌）之一。
- **如期**：如期而至。
- **益如寿**：更加长寿。
- **处天左侧**：居于天的左侧，喻指尊贵之位。
- **大乐**：极大的欢乐。
- **无极**：没有穷尽。
- **雅乐**：正统的音乐。
- **陈**：陈列，演奏。
- **佳哉纷**：美好而盛多。
- **单于**：匈奴君长的称号。
- **自归**：自动归顺。
- **义如明**：道义如同日月之明。

## 译文

远方之人如期而至，更加长寿，居于天的左侧，大乐万岁，与天一样没有穷尽。雅乐陈列演奏，美好而盛多，单于自动归顺，道义如日月般光明。

## 赏析

《远如期》是汉乐府铙歌十八曲之一，是一首歌颂汉朝威德、庆祝远人归服的诗歌。全诗充满盛世气象，"远如期，益如寿"以远方之人如期来朝起笔，表达了对国泰民安、万寿无疆的祝愿。"处天左侧，大乐万岁，与天无极"以夸张的手法描绘出天子的尊贵和国家的昌盛，气势恢宏。"雅乐陈，佳哉纷"描写朝廷奏乐庆典的盛况，"单于自归，义如明"点明匈奴单于归顺之事，彰显汉朝的文治武功。全诗语言简练而气魄宏大，充满了汉帝国全盛时期的自信与豪迈，是研究汉代对外关系和铙歌文学的重要资料。

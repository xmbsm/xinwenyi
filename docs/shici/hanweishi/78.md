# 吁嗟篇

**[魏] [曹植](/authors/caozhi)**

## 原文

吁嗟此转蓬，居世何独然。
长去本根逝，宿夜无休闲。
东西经七陌，南北越九阡。
卒遇回风起，吹我入云间。
自谓终天路，忽然下沉泉。
惊飚接我出，故归彼中田。
南当驾南岳，北及以上玄。
夫然岂不怀，时与命固然。
变异在一息，控提忘由缘。
长愁恐如露，衰耗若飞烟。
殷殷如流波，泣下如涌泉。

## 译文

叹息这飞转的蓬草，处世为何偏偏如此。
远远离开本根而去，日夜没有休息。
东西经过七条陌，南北越过九条阡。
忽然遇到旋风起，将我吹入云间。
自以为将终于天路，忽然又沉入深渊。
狂风将我接出，又回到那田中。
向南当驾车南岳，向北以及上达天玄。
如此怎能不怀念，时运与命运本就如此。
变化就在一瞬之间，控制提携忘了缘由。
长久忧愁恐怕如朝露，衰老损耗如同飞烟。
殷殷忧愁如流波，泪下如涌泉。

## 赏析

《吁嗟篇》是曹植的一首咏物抒怀诗，以转蓬自喻，抒发了诗人身不由己、漂泊无定的悲苦。

"吁嗟此转蓬，居世何独然"以叹息开篇，感叹转蓬的孤独命运。"长去本根逝，宿夜无休闲"写蓬草离根远去，日夜飘荡无休。

"东西经七陌，南北越九阡"以东西南北的道路写蓬草漂泊的范围之广。"卒遇回风起，吹我入云间"写蓬草被旋风吹入云间，"自谓终天路，忽然下沉泉"以高飞与沉沦的对比写命运的无常。

"惊飚接我出，故归彼中田"写蓬草被风吹出又落回田中。"南当驾南岳，北及以上玄"以南北之极写蓬草漂泊之远。"夫然岂不怀，时与命固然"感叹时运与命运的无情。

"变异在一息，控提忘由缘"写命运变化在一瞬之间，难以把握。"长愁恐如露，衰耗若飞烟"以朝露飞烟比喻生命的短暂。"殷殷如流波，泣下如涌泉"以流波涌泉写忧愁之深和泪水之多。

全诗以转蓬自喻，反映了曹植在曹丕、曹叡父子猜忌下屡遭徙封、漂泊无定的悲惨处境，是咏物抒怀的佳作。

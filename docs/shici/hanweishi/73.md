# 情诗

**[魏] [曹植](/authors/caozhi)**

## 原文

微阴翳阳景，清风飘我衣。
游鱼潜渌水，翔鸟薄天飞。
眇眇客行士，遥役不得归。
始出严霜结，今来自霏微。
俛仰岁将卒，星辰有安违。
古来皆有然，谁云长短稀。
发言成谕旨，洒涕沾裳衣。

## 注释

- 微阴：薄云
- 翳：遮蔽
- 阳景：日光
- 渌水：清澈的水
- 薄天：迫近天空
- 眇眇：遥远的样子
- 客行士：客居远行的人
- 遥役：远方的徭役
- 严霜结：严霜凝结
- 霏微：雨雪纷飞的样子
- 俛仰：俯仰之间，形容时间短暂
- 岁将卒：一年将尽
- 星辰：星辰运行
- 安违：有何差错
- 古来皆有然：自古以来都是如此
- 长短稀：寿命长短稀少
- 谕旨：明白的意思
- 洒涕：洒泪

## 译文

薄云遮蔽了日光，清风吹飘着我的衣裳。
游鱼潜入清澈的水中，飞鸟迫近天空飞翔。
遥远客行的士人，远方服役不得归来。
出发时严霜凝结，如今归来时霏霏细雨。
俯仰之间一年将尽，星辰运行有何差错。
自古以来都是如此，谁说寿命长短稀奇。
说话便成为明白的旨意，洒泪沾湿了衣裳。

## 赏析

《情诗》是曹植的一首抒情诗，以自然景物起兴，抒发了客行远役、岁月流逝的感慨。

"微阴翳阳景，清风飘我衣"以薄云遮日、清风吹衣开篇，渲染出萧瑟的氛围。"游鱼潜渌水，翔鸟薄天飞"以鱼潜鸟飞写万物各得其所，反衬客行士的不得归。

"眇眇客行士，遥役不得归"点明主题——远役不归的客行士。"始出严霜结，今来自霏微"以出征时的严霜与归来时的霏雨对比，写时间的流逝。

"俛仰岁将卒，星辰有安违"以一年将尽、星辰运行感叹时光的无情。"古来皆有然，谁云长短稀"以自古皆然的感慨，表达对生命无常的达观。

末二句"发言成谕旨，洒涕沾裳衣"以言语道尽心中之意，洒泪沾衣作结，将悲情推向高潮。

全诗情致深婉，感慨深沉，体现了曹植对人生无常的深刻思考。

# 咏怀诗·昔日繁华子

**[魏] [阮籍](/authors/ruanji)**

## 原文

昔日繁华子，安陵与龙阳。
夭夭桃李花，灼灼有辉光。
悦怿若九春，磬折似秋霜。
流盻发姿媚，言笑吐芬芳。
携手等欢爱，宿昔同衣裳。
愿为双飞鸟，百翼不相忘。

## 注释

- 咏怀诗：阮籍组诗，共八十二首
- 繁华子：繁华之时的公子
- 安陵：安陵君，楚宣王宠臣
- 龙阳：龙阳君，魏安釐王宠臣
- 夭夭：茂盛的样子
- 灼灼：鲜艳的样子
- 悦怿：喜悦
- 九春：九十天的春天
- 磬折：弯腰如磬
- 流盻：流盼
- 姿媚：姿态妩媚
- 宿昔：早晚
- 双飞鸟：成双的飞鸟
- 百翼：百对翅膀

## 译文

昔日繁华之时的公子，安陵君与龙阳君。
茂盛的桃李之花，鲜艳地发出光辉。
喜悦如同春日，弯腰如秋霜。
流盼之间姿态妩媚，言笑之间吐出芬芳。
携手等同欢爱，早晚同穿衣裳。
愿为成双飞鸟，百翼也不相忘。

## 赏析

《咏怀诗·昔日繁华子》是阮籍八十二首咏怀诗之一，以安陵君和龙阳君的故事为题材，抒发了对人生宠辱无常的感慨。"昔日繁华子，安陵与龙阳"以战国时期两位以色事君的宠臣开篇，暗喻人世间的繁华荣宠。

"夭夭桃李花，灼灼有辉光"以桃李之花的鲜艳比喻宠臣的荣华，"悦怿若九春，磬折似秋霜"则以春日的喜悦和秋霜的磬折，比喻宠辱的变化无常。"流盻发姿媚，言笑吐芬芳"描写宠臣的妩媚姿态。

"携手等欢爱，宿昔同衣裳"写宠臣之间的亲密无间，"愿为双飞鸟，百翼不相忘"以愿为双飞鸟作结，表达了对永恒情谊的向往。全诗以古代宠臣的故事暗喻当时的政治现实，含蓄而深沉，体现了阮籍咏怀诗"言在耳目之内，情寄八荒之表"的艺术特色。

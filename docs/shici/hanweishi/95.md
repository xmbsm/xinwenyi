# 赠从弟

**[汉] [刘桢](/authors/liuzhen)**

## 原文

亭亭山上松，瑟瑟谷中风。
风声一何盛，松枝一何劲！
冰霜正惨凄，终岁常端正。
岂不罹凝寒？松柏有本性。

## 注释

- 赠从弟：赠给堂弟
- 亭亭：挺立的样子
- 瑟瑟：风声
- 一何：何等
- 劲：坚强有力
- 惨凄：寒冷凄凉
- 终岁：一年到头
- 端正：端正挺立
- 罹：遭受
- 凝寒：严寒
- 本性：天生的本性

## 译文

挺立在山上的松树，瑟瑟吹着谷中的风。
风声何等盛大，松枝何等刚劲！
冰霜正寒冷凄凉，一年到头始终保持端正。
难道不遭受严寒吗？松柏自有其本性。

## 赏析

《赠从弟》是刘桢赠给堂弟的诗，以松柏为喻，勉励堂弟坚守节操。全诗仅六句，却以鲜明的意象和精练的语言，塑造了松柏傲然挺立的形象。

"亭亭山上松，瑟瑟谷中风"开篇即以山上亭亭玉立的松树和谷中瑟瑟的寒风构成对比，渲染出严峻的环境。"风声一何盛，松枝一何劲"以两个"一何"的感叹，突出风之猛烈与松之刚劲，展现了松树在狂风中不屈的姿态。

"冰霜正惨凄，终岁常端正"进一步以冰霜的严酷反衬松树的端正——即使在最寒冷的时候，松树依然保持端正挺立。"岂不罹凝寒？松柏有本性"以反问作结，指出松柏并非不受严寒之苦，而是其本性使之能够坚持。

全诗以松喻人，以松柏的本性比喻人应有的坚贞品格，语言简练而寓意深远，是建安诗歌中托物言志的佳作，体现了刘桢诗歌"真骨凌霜，高风跨俗"的艺术风格。

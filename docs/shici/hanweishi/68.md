# 杂诗·其三

**[魏] [曹植](/authors/caozhi)**

## 原文

西北有织妇，绮缟何缤纷。
明晨秉机杼，日昃不成文。
太息经长夜，悲啸入青云。
妾身守空闺，良人行从军。
自期三年归，今已历九春。
飞鸟绕树翔，噭噭鸣索群。
愿为南流景，驰光见我君。

## 注释

- 织妇：织布的妇人
- 绮缟：丝织品，绮为有花纹的丝织品，缟为白绢
- 缤纷：繁多的样子
- 明晨：清晨
- 秉：持
- 机杼：织布机
- 日昃：日偏西，下午
- 不成文：织不成花纹
- 太息：长叹
- 悲啸：悲凉的长啸
- 妾身：女子自称
- 空闺：空寂的闺房
- 良人：丈夫
- 行从军：远行从军
- 自期：自定期限
- 九春：九年，一春为一年
- 飞鸟：飞鸟
- 噭噭：鸟鸣声
- 索群：寻找同伴
- 南流景：向南流动的日光
- 驰光：驰骋的光辉
- 君：指丈夫

## 译文

西北方向有个织布的妇人，织出的绮缟多么缤纷。
清晨就手持机杼织布，到日偏西还织不成花纹。
长叹度过漫漫长夜，悲啸之声直入青云。
妾身独守空闺，丈夫远行从军。
自定期限三年归来，如今已经历了九个春天。
飞鸟绕着树木盘旋，噭噭鸣叫寻找同伴。
愿化作向南流动的日光，驰骋光辉去见我的丈夫。

## 赏析

《杂诗·其三》是一首思妇诗，以织妇的口吻抒写丈夫从军不归的思念之情。

"西北有织妇，绮缟何缤纷"开篇以织妇起兴，"明晨秉机杼，日昃不成文"写她从早织到晚却织不成花纹，暗示心绪不宁。"太息经长夜，悲啸入青云"写夜半长叹悲啸，思念之情难以抑制。

"妾身守空闺，良人行从军"点明主题——丈夫远行从军。"自期三年归，今已历九春"以三年之期与九年之久的对比，写等待之漫长和失望之深。

"飞鸟绕树翔，噭噭鸣索群"以飞鸟寻群比喻思妇对丈夫的思念。"愿为南流景，驰光见我君"以愿化为日光去见丈夫作结，想象奇特，情感真挚。

全诗语言清丽，情感细腻，是建安思妇诗的代表作品。

# 箜篌引

**[魏] [曹植](/authors/caozhi)**

## 原文

置酒高殿上，亲友从我游。
中厨办丰膳，烹羊宰肥牛。
秦筝何慷慨，齐瑟和且柔。
阳阿奏奇舞，京洛出名讴。
乐饮过三爵，缓带倾庶羞。
主称千金寿，宾奉万年酬。
久要不可忘，薄终义所尤。
谦谦君子德，磬折欲何求。
盛时不再来，百年忽我遒。
惊风飘白日，光景驰西流。
盛时不可再，百年忽我遒。
生存华屋处，零落归山丘。
先民谁不死，知命复何忧？

## 译文

在高殿上设酒，亲友随我游宴。
厨房办了丰盛的菜肴，烹羊宰肥牛。
秦筝何等慷慨，齐瑟和谐而柔和。
阳阿奏出奇妙的舞蹈，京洛出了名的歌手。
欢乐饮酒过了三杯，松开衣带尽情享用美味。
主人以千金祝寿，宾客以万年回报。
旧约不可忘记，薄于终了是为义所责。
谦谦君子之德，弯腰如磬有何所求。
盛年不会再来，百年忽然将尽。
惊风飘动白日，光阴驰向西流。
盛年不可再来，百年忽然将尽。
生存在华丽的房屋中，死后归于山丘坟墓。
先人谁不死？知天命又有何忧？

## 赏析

《箜篌引》是曹植宴饮抒怀之作。前半段描写宴饮的盛大场面——"置酒高殿上，亲友从我游"，烹羊宰牛，秦筝齐瑟，阳阿奇舞，京洛名讴，一派奢华景象。"乐饮过三爵，缓带倾庶羞"写出了宾主尽欢的畅快。

"久要不可忘，薄终义所尤。谦谦君子德，磬折欲何求"由宴饮转入议论，强调交友之道在于始终如一，君子之德在于谦逊无求。这体现了曹植对友道和品德的重视。

后半段转为对人生短暂的感慨。"盛时不再来，百年忽我遒。惊风飘白日，光景驰西流"以时光飞逝、盛年不再的紧迫感，表达了生命短暂的悲哀。"生存华屋处，零落归山丘"对比生前华屋与死后山丘，揭示了人生的终极归宿。末句"先民谁不死，知命复何忧"以达观之语作结，体现了曹植对生死的理性态度。全诗由欢乐到感慨，由叙事到抒情，层次分明，感情深沉。

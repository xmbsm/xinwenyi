# 黎阳作诗

**[魏] [曹丕](/authors/caopi)**

## 原文

奉辞讨罪遐征，晨过黎山巉岩。
千骑万乘星陈，雷震天动地发。
嗟彼黎侯何寓，不修其德失国。
而我悼之恻怛，乃率六师伐叛。
殷殷其雷发声，电曜耀于玄冥。
雨霈霈而四下，云油油而四行。
遵彼西山言还，爰至于兹而休。
夕宿于兹中野，鸟兽鸣相和酬。
视不得见其形，听不得闻其声。
依稀仿佛之中，若有如其所营。

## 注释

- 黎阳：地名，在今河南浚县东
- 奉辞：奉皇帝之命
- 讨罪遐征：讨伐罪人，远征
- 黎山：黎阳之山
- 巉岩：险峻的山岩
- 千骑万乘：形容军容盛大
- 星陈：如星辰般陈列
- 雷震天动地发：雷声震天，地动山摇
- 黎侯：黎国之君
- 寓：寄居
- 恻怛：忧伤
- 六师：天子的军队
- 殷殷：雷声
- 电曜：闪电
- 玄冥：幽暗的天空
- 霈霈：大雨的样子
- 油油：云盛的样子
- 遵：沿着
- 西山：西方之山
- 爰：于是
- 中野：原野之中
- 和酬：唱和应答
- 营：经营

## 译文

奉皇帝之命讨伐罪人远征，清晨经过黎山的险峻山岩。
千骑万乘如星辰陈列，雷声震天动地。
嗟叹那黎侯寄居何处，不修德行而失国。
而我悼念他心怀忧伤，于是率领六师讨伐叛乱。
殷殷雷声震动天空，闪电在幽暗的天空中闪耀。
大雨霈霈从四方落下，乌云油油向四方飘行。
沿着那西山归去，于是到此歇息。
夜晚住宿在原野之中，鸟兽鸣叫相互应和。
看不见它们的形影，听不到它们的声音。
依稀仿佛之中，似乎有它们的活动。

## 赏析

《黎阳作诗》是曹丕随父出征时所作的纪行诗，记录了途经黎阳时的所见所感。

诗的前半部分写行军之盛与讨伐之由。"奉辞讨罪遐征，晨过黎山巉岩"点明出征背景，"千骑万乘星陈，雷震天动地发"以夸张手法描绘军容之盛。接着以黎侯失国的典故自警，表明讨伐叛乱的正义性。

诗的后半部分写行军途中的自然景象。"殷殷其雷发声"以下六句以雷电风雨渲染气势，气象恢宏。"遵彼西山言还"以下转入夜宿原野的描写，"鸟兽鸣相和酬"以动衬静。

末四句"视不得见其形，听不得闻其声。依稀仿佛之中，若有如其所营"写夜色朦胧中难以分辨的景象，意境幽深。

全诗气象雄浑，兼有纪实与抒情，反映了建安诗人戎马生涯的创作特点。

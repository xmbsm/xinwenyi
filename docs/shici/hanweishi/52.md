# 步出夏门行·冬十月

**[汉] [曹操](/authors/caocao)**

## 原文

孟冬十月，北风徘徊，
天气肃清，繁霜霏霏。
鵾鸡晨鸣，鸿雁南飞，
鸷鸟潜藏，熊罴窟栖。
钱镈停用，农收积场。
逆旅整设，以通贾商。
幸甚至哉！歌以咏志。

## 注释

- 步出夏门行：乐府旧题，属《相和歌·瑟调曲》，曹操此组诗共分"艳"（序曲）及四解（四章）
- 孟冬十月：初冬十月
- 徘徊：形容北风回旋不息
- 肃清：寒冷而清朗
- 繁霜：浓霜
- 霏霏：纷飞的样子
- 鵾鸡：一种形似鹤的鸟
- 鸷鸟：猛禽
- 熊罴：熊和罴，皆为猛兽
- 窟栖：在洞穴中栖息
- 钱镈：古代农具，钱为铲类，镈为锄类
- 逆旅：客舍
- 贾商：商贾，商人
- 幸甚至哉！歌以咏志：乐府套语，每章末尾均有此二句

## 译文

初冬十月，北风回旋不息，
天气寒冷清朗，浓霜纷纷飘落。
鵾鸡清晨鸣叫，鸿雁向南飞去，
猛禽潜伏藏匿，熊罴躲入洞穴。
农具停止使用，庄稼堆集在场。
客舍修整设立，以便商贾通行。
真是幸运至极啊！用歌声来咏唱志向。

## 赏析

《步出夏门行》是曹操北征乌桓胜利后所作的一组名篇，全诗由"艳"（序曲）和四解（四章）组成，本章为第二解《冬十月》。

诗中描写了北方初冬十月的自然景象和社会生活。前八句描绘了一幅严冬北国的图景：北风徘徊，繁霜霏霏，鸿雁南飞，鸷鸟潜藏，熊罴窟栖，处处呈现出一派肃杀凛冽的冬日景象。"鵾鸡晨鸣，鸿雁南飞"动静相宜，"鸷鸟潜藏，熊罴窟栖"则写出了万物避寒的本能。

后四句笔锋一转，写农事已毕、商旅通行的社会景象。"钱镈停用，农收积场"反映了丰收后的安定，"逆旅整设，以通贾商"则展现了社会秩序的恢复和经济生活的繁荣。这与当时的战乱背景形成鲜明对比，体现了曹操治国安民的理想。

全诗语言古朴质实，气象开阔，既真实描绘了北方冬日的自然风光，又寄托了诗人希望建立太平盛世的雄心壮志。

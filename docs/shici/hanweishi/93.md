# 当墙欲高行

**[魏] [曹植](/authors/caozhi)**

## 原文

龙欲升天须浮云，人之仕进待中人。
众口可以铄金，谗言三至，慈母不亲。
愤愤俗间，不辨伪真。
愿欲披心自说陈，君门以九重，道远河无津。

## 注释

- 当墙欲高行：乐府曲名，属《杂曲歌》
- 升天：升上天
- 浮云：云彩
- 仕进：做官进身
- 待：依靠
- 中人：皇帝身边的人，指推荐之人
- 众口铄金：众人的议论可以熔化金石，比喻舆论力量之大
- 谗言：毁谤之辞
- 三至：多次传来
- 慈母不亲：慈母也不亲近
- 愤愤：愤懑不平
- 俗间：世俗之间
- 伪真：虚假与真实
- 披心：剖开心意
- 说陈：陈述
- 九重：九重深宫
- 津：渡口

## 译文

龙要升天须借浮云，人要做官进身须靠中人引荐。
众口可以铄金，谗言多次传来，慈母也不亲近。
愤愤于世俗之间，不辨伪真。
愿欲剖开心意自我陈述，君门九重深锁，道远河无渡口。

## 赏析

《当墙欲高行》是曹植抒发怀才不遇、忠而见谤之愤的代表作。"龙欲升天须浮云，人之仕进待中人"以龙升天须借浮云为喻，说明人要仕进必须有中人引荐，揭示了好的人才推荐制度的重要性。

"众口可以铄金，谗言三至，慈母不亲"化用"曾参杀人"的典故——曾参之母本不信谗言，但三人来告，终于投杼下机，逾墙而走。以此说明谗言的可怕力量，即使是慈母也难免被蒙蔽。

"愤愤俗间，不辨伪真"表达了诗人对世俗不辨真伪的愤懑。"愿欲披心自说陈，君门以九重，道远河无津"写出了想要剖白心迹却无路可达的痛苦——君门九重、道远无津，这是何等的无奈与绝望。全诗以比兴手法，借龙浮云、众口铄金等意象，抒发了诗人忠而见疑、报国无门的悲愤，语言精练，感情沉痛。

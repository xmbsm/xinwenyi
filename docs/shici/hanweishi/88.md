# 于玄武陂作诗

**[魏] [曹丕](/authors/caopi)**

## 原文

兄弟共行游，驱车出西城。
野田广开广，川日旦且明。
中坐顾交辟，临川迈并征。
柳垂重荫绿，水清流且平。
双桐生空枝，上有反舌鸟。
置酒此堂中，与客极欢情。
倡女发清歌，丝竹激哀声。
中馈岂云薄？宾主尽恩荣。
遨游快心意，保己得长生。

## 注释

- 玄武陂：玄武池，在邺城（今河北临漳）之西
- 兄弟：曹丕与曹植等
- 西城：邺城西面
- 野田：田野
- 广开广：广阔开阔
- 川日：河上的日光
- 旦且明：明亮
- 交辟：交错
- 并征：并行
- 重荫：浓荫
- 双桐：两棵梧桐
- 空枝：空旷的枝头
- 反舌鸟：百舌鸟
- 中馈：饮食之事
- 恩荣：恩宠荣耀
- 保己：保全自身
- 长生：长生不老

## 译文

兄弟一同出游，驱车出了西城。
田野广阔开阔，河上日光明亮。
坐中环顾交错，临川并行而前。
柳树垂下浓荫翠绿，水清流缓而平。
双桐生于空枝之上，上有百舌鸟鸣叫。
设酒于此堂之中，与宾客尽情欢乐。
倡女婉转清歌，丝竹激荡哀声。
饮食岂能说薄？宾主尽享恩荣。
遨游使心意快乐，保己得以长生。

## 赏析

《于玄武陂作诗》是曹丕与兄弟游玄武池时所作。"兄弟共行游，驱车出西城"开篇点明游伴和目的地，"野田广开广，川日旦且明"描绘郊外田野的开阔和河上日光的明亮，展现了邺城西郊的优美风光。

"柳垂重荫绿，水清流且平"以柳荫浓绿、水清流缓的景象，渲染出宁静优美的意境。"双桐生空枝，上有反舌鸟"以梧桐百舌的意象，增添了自然的生机。"置酒此堂中，与客极欢情"写宴饮之乐，"taxis发清歌，丝竹激哀声"以清歌丝竹的音乐描写，营造出既欢乐又略带哀愁的氛围。

末句"遨游快心意，保己得长生"表明诗人以遨游山水来保养身心的志趣。全诗写景叙事相结合，风格清丽典雅，体现了曹丕诗歌的艺术特色，也反映了建安时期文人雅集的风貌。

# 朔风诗

**[魏] [曹植](/authors/caozhi)**

## 原文

仰彼朔风，用怀魏都。
愿骋代马，倏忽北徂。
凯风永至，思彼蛮方。
愿随越鸟，翻飞南翔。

四气代谢，悬景用周。
嗟我介士，曷罹此忧。
昔同初雁，哀鸣戾天。
今兹伤弓，孤生死还。

行役有期，载离寒暑。
嗟我介士，乃独勤苦。
远离乡党，播此西东。
匪兕匪虎，率彼旷野。

哀彼伤弓，穷困于此。
曾莫敢悲，慷慨以思。
予亲孔怀，邈若山河。
人谁不死，命也如何。

## 译文

仰望那北方的朔风，因而怀念魏都邺城。
愿驰骋代地的良马，忽然向北而去。
南风长久地吹来，思念那南方的蛮荒。
愿追随越地的鸟，翻飞向南飞翔。

四时之气交替更迭，日月的运行周转不息。
嗟叹我这甲士，为何遭受这样的忧愁。
昔日如同初飞的大雁，哀鸣直达天空。
如今却被弓箭所伤，孤身一人死里逃生。

行军服役有期限，经历了寒暑交替。
嗟叹我这甲士，却独自勤劳受苦。
远离乡里，播迁于东西南北。
不是犀牛不是老虎，却行走于旷野之中。

哀伤那被弓所伤的鸟，窘困于此。
竟不敢悲伤，慷慨地沉思。
我的亲人甚为怀念，遥远如山河。
人谁能不死，命运又如何。

## 赏析

《朔风诗》是曹植的一首四言抒情诗，抒发了从军远征、思乡怀亲的深沉感情。

第一章"仰彼朔风"以朔风起兴，引出对魏都邺城的怀念，"愿骋代马"表达了北归的渴望。"凯风永至"以下转入对南方的思念，南北两望，体现了诗人矛盾的心情。

第二章"四气代谢"以时光流逝感叹甲士的忧愁，"昔同初雁"以下以雁自喻，写从壮志到受伤的转变。

第三章"行役有期"写行军之苦，"匪兕匪虎，率彼旷野"以《诗经》成句自况，写从军之苦。

第四章"哀彼伤弓"以下以伤弓之鸟自喻，写穷困不敢悲伤的无奈。"予亲孔怀，邈若山河"写对亲人的深切怀念，"人谁不死，命也如何"以达观之语作结，反映了诗人对命运的思索。

全诗以四言写成，古朴典雅，情感深沉，是曹植四言诗的代表作。

# 却东西门行

**[汉] [曹操](/authors/caocao)**

## 原文

鸿雁出塞北，乃在无人乡。
举翅万余里，行止自成行。
冬节食南稻，春日复北翔。
田中有转蓬，随风远飘扬。
长与故根绝，万岁不相当。
奈何此征夫，安得驱四方！
戎马不解鞍，铠甲不离傍。
冉冉老将至，何时反故乡！

## 注释

- 却东西门行：乐府曲名，属《相和歌·瑟调曲》
- 鸿雁：大雁
- 塞北：长城以北
- 举翅：展翅
- 冬节：冬季
- 转蓬：飞蓬，随风飘转的草
- 征夫：从征的士兵
- 驱四方：奔走四方
- 戎马：战马
- 不解鞍：不解下马鞍
- 铠甲：古代将士的护身服装
- 冉冉：渐渐
- 反：同"返"，返回

## 译文

鸿雁飞出塞北，在那荒无人烟的地方。
展翅飞行万余里，飞行和停歇自然成行。
冬天到南方吃稻谷，春天又向北飞翔。
田中有随风转的飞蓬，远远地随风飘扬。
永远与故根断绝，万年也不能再相逢。
无奈这些征夫，怎能被驱使奔走四方！
战马不解下马鞍，铠甲不离身旁。
渐渐年老将至，何时才能返回故乡！

## 赏析

《却东西门行》是曹操反映战争给人民带来苦难的代表作。全诗以鸿雁和飞蓬两个意象，分别比喻征夫的远行和与故乡的隔绝。

"鸿雁出塞北，乃在无人乡。举翅万余里，行止自成行"以鸿雁远飞塞北、行列有序的景象，暗喻征夫远征的艰辛。"冬节食南稻，春日复北翔"写鸿雁随季节南北迁徙，与征夫常年在外形成对照。

"田中有转蓬，随风远飘扬。长与故根绝，万岁不相当"以飞蓬断根飘转比喻征夫与故乡永别，这一意象极为沉痛，与"戎马不解鞍，铠甲不离傍"的战争生活相呼应，写出了征夫身不由己的苦境。

末句"冉冉老将至，何时反故乡"直抒征夫思乡之情，语极沉痛。全诗以比兴手法写征夫之苦，感情深沉悲凉，体现了曹操诗歌慷慨悲凉的艺术风格，也反映了他对战争给人民带来苦难的同情。

# 杂诗·其六

**[魏] [曹植](/authors/caozhi)**

## 原文

飞观百余尺，临牖御棂轩。
远望周千里，朝夕见平原。
烈士多悲心，小人偷自闲。
国仇亮不塞，甘心思丧元。
拊剑西南望，思欲赴太山。
弦急悲声发，聆我慷慨言。

## 注释

- 飞观：高耸的楼观
- 百余尺：形容极高
- 临牖：靠近窗户
- 御：凭靠
- 棂轩：有栏格的窗
- 周千里：周览千里
- 平原：广阔的平原
- 烈士：有志建功立业的人
- 悲心：悲壮之心
- 小人：指苟且偷安之人
- 偷：苟且
- 自闲：自我安闲
- 国仇：国家的仇敌
- 亮不塞：确实未除
- 甘心：心甘情愿
- 丧元：丧失生命，丧首
- 拊剑：抚剑
- 西南望：向西南远望
- 赴太山：赴泰山，比喻视死如归
- 弦急：弦声急促
- 悲声发：悲壮的声音发出
- 聆：听
- 慷慨言：慷慨激昂的言辞

## 译文

高耸的楼观有百余尺高，靠近窗户凭靠栏格。
远望可周览千里，朝夕都能看见广阔的平原。
烈士多有悲壮之心，小人却苟且偷安。
国仇确实还未消除，我心甘情愿舍命以赴。
抚剑向西南远望，渴望赴泰山视死如归。
弦声急促悲壮之音发出，请听我慷慨激昂的言辞。

## 赏析

《杂诗·其六》是一首抒发报国之志的壮歌，表现了曹植渴望建功立业、为国捐躯的豪情壮志。

"飞观百余尺，临牖御棂轩"以登高远望开篇，"远望周千里，朝夕见平原"以广阔的视野衬托诗人的胸怀。

"烈士多悲心，小人偷自闲"以烈士与小人的对比，凸显诗人忧国忧民的情怀。"国仇亮不塞，甘心思丧元"直抒报国之志——国仇未除，甘愿舍命。

"拊剑西南望，思欲赴太山"以抚剑远望、视死如归的形象，将壮志推向高潮。"弦急悲声发，聆我慷慨言"以弦歌悲壮作结，请人聆听其慷慨之言。

全诗格调悲壮，气势雄浑，体现了曹植"骨气奇高"的诗风，是建安咏怀诗中抒发报国之志的代表作。

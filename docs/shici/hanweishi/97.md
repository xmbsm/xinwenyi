# 侍五官中郎将建章台集诗

**[汉] [应玚](/authors/yingyang)**

## 原文

朝雁鸣云中，音响一何哀！
问子游何乡？戢翼正徘徊。
言我塞北来，将就江南栖。
天地非不广，六翮将安施？
来冲突霜雪，凌寒欲何为？
感子刻意深，欢爱一何迟！
朝云浮四海，日暮归故山。
行旅何时旋？临岐不能言。

## 译文

早晨大雁在云中鸣叫，声音何等哀伤！
问你要飞往何方？收敛翅膀正在徘徊。
你说从塞北而来，将要到江南栖息。
天地并非不广阔，翅膀将往何处施展？
冲冒霜雪而来，冒着严寒要做什么？
深感你刻意深远，欢乐为何来得如此迟！
朝云飘浮于四海，日暮归于故山。
旅途何时能归返？面临岔路说不出话。

## 赏析

《侍五官中郎将建章台集诗》是应玚侍宴曹丕时所作。全诗以雁自喻，抒发了羁旅漂泊、怀才不遇的感慨。"朝雁鸣云中，音响一何哀"以哀鸣的大雁开篇，奠定了全诗悲凉的基调。

"言我塞北来，将就江南栖"以雁的南飞，比喻自己从北方避乱南来。"天地非不广，六翮将安施"以天地虽广而翅膀无处施展，暗喻自己虽有才华却无处用武，这一问句包含了深沉的感慨。

"来冲突霜雪，凌寒欲何为"以雁冒霜雪南飞的艰辛，比喻自己颠沛流离的困苦。"朝云浮四海，日暮归故山"以朝云日暮归山，反衬自己有家难归的悲哀。"行旅何时旋？临岐不能言"以面临岔路说不出话的形象作结，写出了前途迷茫、不知所往的茫然。全诗以雁喻人，语言清丽，感情深沉，体现了建安文学慷慨悲凉的时代风格。

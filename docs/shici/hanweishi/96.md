# 室思

**[汉] [徐干](/authors/xugan)**

## 原文

浮云何洋洋，愿因通我词。
飘飘不可寄，徙倚徒相思。
人离皆复会，君独无返期。
自君之出矣，明镜暗不治。
思君如流水，何有穷已时。

## 注释

- 室思：闺中思妇之辞
- 洋洋：飘飘的样子
- 愿因：希望凭借
- 通我词：传达我的言词
- 飘飘：飘动
- 徙倚：徘徊
- 徒：徒然
- 离：离别
- 复会：重新相会
- 返期：归来的日期
- 自君之出矣：自从你出去之后
- 明镜：铜镜
- 暗不治：蒙上灰尘不去擦拭
- 穷已：穷尽停止

## 译文

浮云飘飘何等自在，愿借浮云传达我的言词。
飘动而不能寄达，徘徊之间徒然相思。
人离别都能再会，唯独你没有归期。
自从你出去之后，明镜蒙尘也不去擦拭。
思念你如同流水，哪里有穷尽的时候？

## 赏析

《室思》是徐干以思妇口吻写就的闺怨诗。"浮云何洋洋，愿因通我词"以天上飘浮的云彩起兴，希望借浮云传达思念之情，想象奇特而自然。"飘飘不可寄，徙倚徒相思"写浮云飘忽不定，无法寄托，思妇只能徒然相思，徘徊不定。

"人离皆复会，君独无返期"以对比手法，写出别人离别都能再会，唯独自己的丈夫没有归期，这一"独"字包含了无尽的悲伤。"自君之出矣，明镜暗不治"以明镜蒙尘不去擦拭的细节，写出思妇无心梳妆的慵懒，生动地表现了思念之深。

末句"思君如流水，何有穷已时"以流水不绝比喻思念无尽，成为千古传诵的名句。全诗语言清新自然，以比兴手法写思妇之情，感情真挚缠绵，是建安时期闺怨诗的代表作，对后世闺怨诗产生了深远影响。
